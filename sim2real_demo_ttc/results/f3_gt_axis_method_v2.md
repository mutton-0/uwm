# F-3 方法说明 v2：GT 危险方向轴 + `arc_full` 主口径

> 生效日期：2026-09-04。**本文件是后续所有场景类型（ghost / 前车路障 / 无保护左转 /
> 十字路口）共用的方法定义**，新场景只需替换"危险类别"与"事件挖矿判据"，
> 归因公式、读数口径、GT 轴、统计纪律一律复用本文，不重新推导。

---

## 1. 语料构造：brake-first 挖矿

**顺序是反的**：不先按几何找"危险"，而是**先找人类真的刹车的片段，再归因**。

1. **减速片段**：逐 scene 扫自车速度曲线，取局部极大 $v_0$ → 后续极小 $v_{min}$，
   要求 $dv = v_{min}-v_0 < -0.5$ m/s **且** $\lvert dv\rvert/v_0 > 0.3$。
   后一条排除"本来就慢的车滑行到停"。
   **查询帧取减速起点** —— 此时车还没开始刹，模型必须自己决定要不要刹。
2. **参考路径**：自车**真实**未来轨迹（已实现段 + 沿窗口末帧真实航向直线外推 20 m）。
   *不用瞬时朝向*：弯道上"前向/横向"的定义会漂移（§FE/A69）。
3. **走廊**：到该路径的**横向**距离 < 2.0 m（半车宽 ≈1 m + 1 m 缓冲）。
4. **刹车需求**：对走廊内每个目标
   $$a_i=\frac{\max(v^{close}_i,0)^2}{2\max(s_i-2.0,\,0.5)}$$
   $s_i$ = 沿路径的弧长位置，$v^{close}_i$ = 自车与该目标沿路径切向的接近速度。
5. **入选判据**（四条全过）：
   * 危险类合计占比 $\sum_{i\in H} a_i / \sum_j a_j > 0.6$
   * **支配性留 1.5× 余量**：$\max_{i\in H} a_i \ge 1.5\max_{j\notin H} a_j$
     （严格不等式不够 —— 分散的几个目标加起来能盖过一辆更近的大车）
   * $\max_{i\in H} a_i / a_{obs} > 0.3$（需求要能解释观测到的减速）
   * 保留区间 $(\mathrm{TTC}\le 5\,\mathrm{s}) \cup (d\le 40\,\mathrm{m})$（取并集）
6. **去重**：同一 (scene, 遮挡组) 只留 $a$ 最大的一条。
7. **主分析集**：$\max_{i\in H} a_i \ge 0.4$。低于此值者**不删**，
   存 `deferred_low_a_req` 段并打 `low_speed_v0` 标签。

### 1.1 危险类 $H$ ——**归因口径 = 遮挡口径**

$H$ 由场景类型决定，但**归因划分 hazard/competitor 与遮挡组必须用同一个集合**。
归因认定"是这些东西触发了减速"，遮挡臂就必须遮掉这些东西，
否则遮完触发物还在，必然测出假 FAIL。

| 场景类型 | $H$ |
| --- | --- |
| ghost（VRU 突现） | `human.` / `vehicle.bicycle` / `vehicle.motorcycle` / **`animal`** |
| 前车 / 静态路障 | `vehicle.*` / `movable_object.*`（见各场景报告的实际取值） |
| 其余新场景 | 在该场景报告中显式声明 |

> `animal` 在 `g1_mine_events.obj_class` 里原本映射为 `other`、在 geo 构造时被丢弃
> （**既不可遮也不当竞争者**）。用 `G1.set_include_animal(True)` 开启，**默认关闭**
> 以保证既有产物逐位不变。

## 2. 三臂：**全部同帧**

| 臂 | 图像 / 点云 |
| --- | --- |
| **origin** | 减速起点原图（危险在场） |
| **clean** | origin + 遮挡组**全部**框涂灰（图像均值色）；吃点云的候选同时删该 3D 框内的点 |
| **ctrl** | origin + **等面积**对照框涂灰；点云侧删**镜像 3D 框**内的点 |

* **为什么必须同帧**：跨帧 clean 臂不可行 —— 实测本语料 13 个 scene 里
  "画面内零危险类目标"的帧占比**中位仅 0.4%**，按走廊判据选出的 clean 帧
  **11/13 图像里仍能看见危险类目标**。城市驾驶数据里"无危险帧"基本不存在。
  同帧设计使两臂图像逐像素相同，唯一差别是那块灰斑，既无跨帧污染也无自车位姿差。
* **遮挡组全遮**：走廊内**全部**危险类实例一起遮。只遮一个、剩下的还在 ⇒ 必测出假 FAIL。
* **对照框**：与遮挡框等面积、同离心率带，与**所有**遮挡框及彼此均不重叠。
  放不下则**跳过该事件**，绝不留一个退化的（$b_{ctrl}\equiv0$）对照臂。
* **三臂共用同一喂入自车速度**（取 origin 帧实测值）。
* 点云删点 margin = 0.25 m（§FM/A56–59 主口径）。

## 3. 读数：**`arc_full` 为主口径**

设规划轨迹 $w_{1..N}$（不含原点，$w_k$ 对应 $t=k\cdot\Delta t$），时域 $T=N\Delta t$。

$$v^{arc} = \frac{\lVert w_1\rVert + \sum_{k=1}^{N-1}\lVert w_{k+1}-w_k\rVert}{T}$$

即**全轨迹弧长 / 时域长度**。GT 侧用**同一定义、同一时域** $T$ 在自车真实位姿上计算。

### 3.1 为什么不用 `cs_0.5s`

各候选原生 `commanded_speed` 只取轨迹的**两个点**：
SimLingo 是 $\lvert w_1-w_3\rvert\times2$（窗口 0.25–0.75 s，`agent_simlingo.py:815`），
DD 家族是 $\lvert w_1\rvert/\Delta t$（窗口 0–0.5 s）。
SimLingo 轨迹本身是 2.5 s、DD 家族 4 s ⇒ **只用了 1/5 ~ 1/8 的时域，且是弦长不是弧长**。

代价已实测：$b^{GT}$ 在 0.25–0.75 s 上是 **0.332**，在 0–4 s 上是 **1.232**（截断约 3.7 倍）。
在 `cs_0.5s` 口径下 SimLingo 的响应比看起来是 **98%**，换成 `arc_full` 是 **15%** ——
**那个 98% 是截断造出来的假象**。

> **`cs_0.5s` 降级为敏感性口径。** 它是模型自身控制回路实际下发的量，
> 有其工程意义（反映短时输出），但**不适合用来判断响应是否充分** ——
> 它只看规划轨迹开头的一小段，而模型的危险响应恰恰可能只存在于开头、不贯穿时域。
> 报告中可并列给出，但**不得作为"响应充分性"的判据**。

### 3.2 坐标系

弧长与弦长都是刚体变换下的不变量 ⇒ GT 轨迹**不需要**转到查询帧 ego 系。
（若将来做**横向/纵向分解**，则必须按 §FE/A69 转到查询帧朝向，否则弯道下定义会漂移。）

### 3.3 跨模型可比性

各候选规划时域不同（SimLingo 2.5 s、DD 家族 4 s）⇒ $b^{GT}$ 本身不同。
**跨模型只能比响应比 $b_{model}/b^{GT}$（各自除以自己的 GT），不能比 $b$ 的绝对值。**

## 4. GT 危险方向轴

* $v^{GT}_{origin}$ = **人类司机真实未来速度**，在与该模型**同一时域** $T$ 上、
  用**同一 `arc_full` 定义**从自车真实位姿算出 ⇒ "危险在场时的正确动作"。
* $v^{GT}_{clean}$ = **查询帧当前速度 $v_0$** ⇒ prompt 是车道保持任务，
  危险移除后的正确动作就是维持当前速度。
* $$b^{GT} = v^{GT}_{clean}-v^{GT}_{origin} = v_0 - v^{arc}_{GT}$$
  **正 = 移除危险后应当提速**；大小 = 这次危险"应该"引起多大的减速。

### 4.1 模型侧与得分

$$b = v^{arc}_{clean}-v^{arc}_{origin},\qquad b_{ctrl}=v^{arc}_{ctrl}-v^{arc}_{origin}$$

| 指标 | 定义 | 判读 |
| --- | --- | --- |
| **响应比** | $\overline{b}/\overline{b^{GT}}$（汇总均值之比） | 1.0 = 幅度正好，0 = 无响应，负 = 反向 |
| 方向一致率 | $\#\{\mathrm{sign}(b)=\mathrm{sign}(b^{GT})\}/n$ | 0.5 = 掷硬币 |
| 配对特异性 | $\lvert b\rvert-\lvert b_{ctrl}\rvert$ | 预期 > 0 |
| err_origin | $v^{arc}_{origin}-v^{GT}_{origin}$ | 危险在场时比人类快/慢多少 |
| err_clean | $v^{arc}_{clean}-v_0$ | 移除危险后是否维持速度 |

> **配对特异性显著 ≠ 对危险有特异响应。** 实测 DDv2 特异性显著为正
> (+0.323 [+0.013, +0.809])，但其 $b=-0.027$（方向错）而 $b_{ctrl}=-0.181$ ——
> **通过是因为对照臂效应更大，不是主效应大**。主效应接近 0 时该检验会给出误导性的"显著"，
> 必须与 $b$ 本身的显著性一起读。

### 4.2 两个必须声明的假设（是建模，不是测量）

1. **"危险移除后 = 维持当前速度"不可观测。** 本方法论**天然支持**它：
   查询帧按定义取在**减速起点（速度局部极大）**，自车此前处于稳态行驶
   ⇒ $v_0$ 是合理的"未受扰动速度"。
   **但**若该帧存在**未标注的交通管制**（信号灯 / STOP —— 两个语料的 geo 都不标注），
   人类即使没有危险也会减速 ⇒ $b^{GT}$ 会**高估**。这是本方法的硬边界，无法用几何量剥离。
2. **归因不是 100%**：$b^{GT}$ 的全部减速未必都该记在危险组头上。
   故并列给出按危险类合计占比缩放的 $b^{GT}_{attr}$。

## 5. 统计纪律（不放松）

* **scene 级 bootstrap**（5000 次），重抽单位是 **scene**，不是帧、不是事件。
  帧级重抽会使 CI 假性变窄 4.8–13.6 倍（实测）。
* **三态判定**：PASS / FAIL / 不可估，门槛相对预注册值。
* **对照臂必需**，且不得退化。
* **预注册单一主读数**：`arc_full` 的响应比。其余（`cs_0.5s`、`chord_full`、
  中位数 / 截尾均值等稳健估计量）一律作**敏感性并列报出**，
  **不得看完结果再挑**。
* **禁止按测量结果筛样本**：不得因某事件"效应弱""是 outlier""方向反了"而删除它。
  分层描述（如反向 vs 同向）可以做，但**子集 CI 不构成有效推断**，须显式标注。

## 6. QA（每个场景类型都要做）

1. **分层目视**：逐候选看 origin / clean / ctrl 三联图，确认
   遮挡框精确覆盖目标、无误盖、对照框不重叠。
2. **拒绝留痕**：QA 阶段的拒绝与"边缘"判定逐条写入产物的 `qa` 字段，含理由。
3. **等面积核验**：遮挡框与对照框总面积比应为 1.000。
4. **已知残留**（每个场景都要报，不影响入池但须在分析时计入）：
   * **走廊外未遮的同类目标**留在画面里 ⇒ $R$ / 响应比**方向性低估**；
   * **未标注交通管制**（信号灯 / STOP）⇒ $b^{GT}$ 高估；
   * **点云删点为 0** 的事件（远距离目标本就没几个点）⇒ 响应弱可能是"没点可删"
     而非"不用该实体"，两者必须区分。
