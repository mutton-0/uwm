# F-3 危险方向轴（GT 版）：用人类行为定义"正确的 b"，把二值判定变成分数

> 工单：2026-09-04（用户提出）。原 F-3 的三臂全是**模型输出**，没有真值参照，
> 只能做"显不显著"的二值判定。本轮引入一条**与模型无关**的 GT 危险方向轴。

## 0. 结论

**GT 轴成立且显著，13/13 个事件方向一致。** 判定随之从"不可估"变成可打分。

| 读数 | 值 [scene 级 CI] | |
| --- | --- | --- |
| **$b^{GT}$（GT 危险方向轴）** | **+0.3321 [+0.2128, +0.4620]** | **显著，13/13 全为正** |
| $b^{GT}$ 按归因缩放 | +0.3113 [+0.2057, +0.4250] | 显著 |
| $b_{model}$（SimLingo） | +0.3262 [−0.2375, +0.9116] | 跨 0 |

**SimLingo 的平均响应幅度几乎正好等于应有值**——汇总均值之比 **+0.9822**（98%）。
**但逐事件方向一致率只有 7/13 = 53.8%**。

> ⇒ **那个漂亮的 98% 是正负抵消出来的，不是每个事件都对。**
> 这正是 GT 轴的价值：没有它，$b_{model}=+0.326$ 看起来像"响应幅度正常"；
> 有了它才能看出总量对而逐事件几乎是掷硬币。

## 1. 定义

* $v^{GT}_{origin}$ = **人类司机的真实未来速度**，在**与该模型 `commanded_speed` 完全相同的
  时间窗**上、由自车真实位姿算出 ⇒ "危险在场时的正确动作"。
* $v^{GT}_{clean}$ = **查询帧当前速度 $v_0$** ⇒ prompt 是车道保持任务，
  危险移除后的正确动作就是维持当前速度。
* $$b^{GT} = v^{GT}_{clean} - v^{GT}_{origin} = v_0 - v_{GT}$$
  正 = 移除危险后应当提速，大小 = 这次危险"应该"引起多大的减速。

模型得分与 F-3 主读数同符号约定（$b = v_{clean}-v_{origin}$）：
方向分 $\mathrm{sign}(b)\cdot\mathrm{sign}(b^{GT})$；比值分 $b/b^{GT}$；
逐臂误差 $v_{origin}-v^{GT}_{origin}$ 与 $v_{clean}-v_0$。

### 1.1 时间窗必须逐模型对齐

各候选 `commanded_speed` 定义不同：SimLingo 是 $|wp_0-wp_2|\times2$，
而 $wp_k$ 对应 $t=(k{+}1)\times0.25$ s ⇒ 窗口 **0.25–0.75 s**；DD 家族是第一步 / PRED_DT=0.5 s。
GT 必须在**同一窗口**上算，否则比的是两个不同的量。`READOUT_WINDOW` 逐模型登记。

### 1.2 两个必须声明的假设（是建模，不是测量）

1. **"危险移除后 = 维持当前速度"不可观测。** 本语料**天然支持**该假设：
   brake-first 的查询帧按定义取在**减速起点（速度局部极大）**，
   即自车在该帧之前处于稳态行驶 ⇒ $v_0$ 是合理的"未受扰动速度"。
   **但**若该帧还存在**未标注的交通管制**（信号灯 / STOP，见 `brake_first_report` §3.2），
   人类即使没有行人也会减速 ⇒ $b^{GT}$ 会**高估**危险应引起的响应。
2. **归因不是 100%**：$b^{GT}$ 的全部减速未必都该记在危险组头上，
   故并列给出按 `vru_class_share` 缩放的 $b^{GT}_{attr}$（本池 13/13 的 share 都很高，两者差别小）。

### 2.1 scene-0862 不再是"不可估"，而是一个有分数的异常

| | 值 |
| --- | --- |
| 人类实际 | 4.72 → **0.0 m/s**（斑马线前完全停住，9.35 s 内只前进 8.25 m） |
| $b^{GT}$ | **+0.635**（应当：移除危险后可提速 0.635） |
| 模型 $b$ | **−1.803**（实际：移除危险后**反而减速** 1.80） |
| $v_{origin}-v^{GT}$ | **+2.477**（危险在场时比该开的**快 2.48 m/s**，也比自车当前速度 4.72 还快） |
| $v_{clean}-v_0$ | **+0.039**（危险移除后几乎完美维持当前速度） |
| $b_{ctrl}$ | −0.095（等面积灰斑贴别处几乎无效应 ⇒ 该反应**位置特异**） |

**这个事件上模型的行为是：危险在场时打算加速，把危险遮掉反而恢复正常。**
方向错、幅度大、且位置特异。有了 GT 轴，它是一个**可量化的失效案例**，
而不是被"不可估"吞掉。

## 3. 一个新的分解：绝对速度偏差 vs 危险响应

| 读数 | 值 [scene 级 CI] |
| --- | --- |
| err_origin（危险在场时的绝对误差） | +0.7136 [−0.8791, +2.0393] |
| err_clean（危险移除后的绝对误差） | +0.7077 [−0.8814, +2.0603] |

**两者几乎相等（+0.714 vs +0.708）**，而逐事件范围高达 −4.9 ~ +3.9。
⇒ 模型的绝对速度误差是一个**两臂共有的逐事件偏置**，
**不来自危险响应**；危险响应（两者之差 = $b$）叠在这个大偏置之上。

这解释了为什么原 F-3 的信噪比一直很差：**被测的量（±0.3）比它所在的偏置（±4）小一个量级。**

## 4. 读数窗口的影响

$b^{GT}$ 的量级强依赖窗口，但**方向在所有窗口上都是 13/13 全正**：

| 窗口 | $b^{GT}$ 均值 | scene 级 CI |
| --- | --- | --- |
| **0.25–0.75 s（SimLingo 口径）** | **+0.3321** | [+0.2128, +0.4620] |
| 0–1 s | +0.3319 | [+0.2268, +0.4468] |
| 0–2 s | +0.6964 | [+0.5156, +0.9159] |
| 0–3 s | +1.0066 | [+0.8042, +1.3021] |
| 0–4 s | +1.2324 | [+0.9721, +1.5741] |

⇒ **人类减速的大头在 1 s 之后**，而 `commanded_speed` 只看 0.25–0.75 s。
标量读数把 GT 响应截断了约 **3.7 倍**（1.232 / 0.332）。
这不影响本轮的比较（模型与 GT 用同一窗口），但指向一个自然的扩展：
**用完整规划轨迹对比完整 GT 轨迹**，而不是只比第一步标量。

## 4b. 全轨迹读数：那个 98% 是截断造出来的（用户 2026-09-04 追问）

现行 `commanded_speed` 只用了规划轨迹的**两个点**（$wp_0$、$wp_2$，即 0.25–0.75 s），
而 SimLingo 的轨迹是 **10 点 × 0.25 s = 2.5 s** ⇒ **只用了 1/5 的时域，且是弦长不是弧长**。
把模型与 GT **都**换成全时域读数后：

| 读数 | $b^{GT}$ [scene CI] | $b_{model}$ [scene CI] | 方向一致 | **均值比** |
| --- | --- | --- | --- | --- |
| `cs_0.5s`（现行） | +0.3321 [+0.2128, +0.4620] | +0.3262 [−0.2375, +0.9116] | 7/13 | **+0.982** |
| **`arc_full`（全轨迹弧长 / 2.5 s）** | **+1.0553 [+0.6929, +1.5700]** | +0.1587 [−0.3190, +0.6654] | 7/13 | **+0.150** |
| `chord_full`（终点弦长 / 2.5 s） | +1.0576 [+0.6950, +1.5714] | +0.1732 [−0.2917, +0.6730] | 6/13 | +0.164 |

**两边同时朝相反方向动**：
* **GT 响应大 3.2 倍**（+0.332 → +1.055）—— 人类减速的大头在 1 s 之后；
* **模型响应小 2 倍**（+0.326 → +0.159）—— 模型的轨迹差异**集中在头 0.5 s、之后不延续**。

⇒ **均值比从 98% 掉到 15%。** SimLingo 在完整规划时域上，
对"危险被移除"的响应只有应有幅度的 **15%**。

**稳健性**：
* $b^{GT}$ 在三种读数下**都是 13/13 全正** —— 方向轴不依赖读数选择；
* $b_{ctrl}$ 三种都很小（+0.130 / +0.072 / +0.050）—— 对照臂正常；
* 逐事件方向一致率三种都是 6–7/13（掷硬币），**不随读数改变**；
* `arc_full` 下 `err_origin` = **+1.674** —— 危险在场时模型规划比人类实际开的快 1.67 m/s。

**坐标系说明**：弧长与弦长都是刚体变换不变量，GT 轨迹无需转到查询帧 ego 系。
（将来若做横/纵分解，则必须按 §FE/A69 转到查询帧朝向。）

**建议**：主口径改用 `arc_full` —— 它用满模型输出的全部信息，
且与 GT 在同一时域上可比；`cs_0.5s` 降为敏感性（它是模型自身控制器的口径，
有其意义，但**不适合用来衡量"响应是否充分"**）。
