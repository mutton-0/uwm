## Tip G｜候选总体可枚举时，零分布必须枚举，不得用尾部外推

**主张。** 在"N 个候选里取 max"的场景中（权重空间投影、字典特征筛选、逐层逐单元扫描），
用观测量的方差 + 高斯尾外推极值阈值是**不安全**的。只要候选总体是可枚举的，
就应当直接枚举总体、取经验分位，而不是外推。

**本轮反例。** Stage A1 在 SimLingo 的 24 层 × 4864 个 FFN value vector（共 116,736 条）上做
logit-lens 概念打分，Stage C 再把入选候选与数据驱动方向算余弦。首版用 3000 条随机抽样估零分布、
按 Bonferroni 高斯尾定阈值，得到 **11/950 条"双重印证"**。但实测该零分布的经验千分位
（0.100–0.154）**高于**高斯尾给出的阈值（0.071–0.084）——阈值比零分布自己的 q99.9 还低。
改为**全总体枚举**（116,546 条，α = 0.05/950 = 5.26 × 10⁻⁵ 对应总体第 ~6 名，可直接取经验分位）后，
双重印证 **0 条**，H2 由"成立"变为"不成立"。（修正案 DV/A14）

**尾部有多重，可以量化。** 五条比较基的结构匹配零分布 sd 都在 0.020–0.028 之间，
按高斯尾外推给出的阈值约 **0.085**；而全总体枚举给出的经验阈值是
0.139 / 0.144 / **0.641** / **0.688** / 0.139。
其中 $v_{domain}$ 与 $v_{danger}^{lang}$ 两条轴上，零分布的 α 分位比高斯外推**高出近一个数量级**——
因为权重空间里确实存在与它们几乎平行的 value vector，而这件事完全无法从二阶矩（sd）看出来。

**适用范围。** 任何在高维权重/激活空间里"扫描一大批候选取最大相似度"的工作。
权重空间的余弦分布因各向异性而尾部显著重于高斯，高斯外推会系统性地制造假阳性。
附带一条：**结构匹配零分布**（从同一批 value vector 里抽）与**各向同性零分布**（随机高斯）
应并列报告，两者之差本身就是各向异性强度的度量。

## Tip F｜"没测出效应"必须先过仪器侧自检，才能说成标本侧结论

**主张。** 当一个共线性/相关性检验给出零结果时，必须并报一条**仪器侧读数**：
被检验的那条方向本身，在 held-out 上对它声称的目标量究竟有没有预测力。
没有这条，"零结果"无法区分"标本没有这个性质"与"这条方向根本没拟合出来"。

**本轮反例。** T-F 从人类驾驶员真实减速 $a_{brake}$ 回归出观测法刹车方向 $v_{brake}^{obs}$，
与已过 steering 四件套的注入法 $v_{brake}$ 算余弦，得 +0.014（随机零分布内，$p$ = 0.645）。
**若只有这一个数**，读者无法判断这是"两条方向确实正交"还是"回归压根没拟合出方向"。
补上仪器侧自检后：$v_{brake}^{obs}$ 在 scene 级 GroupKFold 上的 held-out CV $r$ = +0.074
（scene 级置换零分布 $p$ = 0.040），以 TTC 为目标时 $r$ = +0.320（$p$ < 1.0 × 10⁻³）——
**方向确实拟合出来了**，因而"正交"是标本侧结论。据此还能给出效应量上界：
两条方向的共线性 $\lvert\cos\rvert \le 0.064$（95% CI 上界），即至多共享 0.4% 方差。

**适用范围。** 任何以"某两个内部量正交/无关"为结论的可解释性工作。
零结果的信息量完全取决于仪器灵敏度是否被独立标定；不标定的零结果不可引用。

## Tip I｜跨域稳定性必须同时报表征端与行为端，二者可以给出相反的排序

**主张。** 域不变性判断不能只报表征相似度（两域激活像不像），也不能只报行为差异；
必须**并列**报告，且必须准备好二者互相矛盾的情况——它们是两个独立的命题，
"表征稳定"不蕴含"因果耦合稳定"，反之亦然。

**本轮反例。** T-I 在同一条渲染域配对（CARLA 引擎渲染 ↔ 世界模型真实感重绘，
同场景同几何、唯一变量是渲染风格）上同时量两个模型：
表征端 $D_{L^*}$ = 0.394（SimLingo）vs 0.797（DiffusionDrive）⇒ SimLingo 更稳；
行为端 $\mathbb{E}|\Delta v_{cmd}|/\overline{v_{cmd}}$ = 0.346 vs 0.115 ⇒ DiffusionDrive 更稳。
**两个排序方向完全相反，且两组 scene 级 bootstrap CI 都不重叠**。
只报任一端，都会得到一个看起来干净、实则被另一端直接推翻的结论。

**适用范围。** 任何跨域鲁棒性声明（sim2real、天气/光照迁移、传感器换代）。
推论：论文里"我们的表征更 domain-invariant"这类主张，若不附行为端读数，
不能被当作部署鲁棒性的证据。

## Tip C｜可分性、散度、因果责任是三个不同的量，不能互相代替

**主张。** "哪一层变化最大"（散度）、"哪一层最能把好/坏样本分开"（可分性）、
"哪一层对后果负因果责任"（干预恢复）是三个不同的量。定向修复的位点必须由**干预**决定，
不能用散度或可分性代替；三者的 argmax 可以互不重合。

**本轮反例。** T-C 在同一批 DiffusionDrive 域配对数据上算了三种量：
注意力散度 JS 峰在 **L7**（0.288）；特征散度 1−CKA 峰也在 **L7**（0.775）；
t-SNE 可分性（silhouette）峰在 **L5**（0.112）；而激活修补的因果恢复峰在 **L6**
（mean recovery 0.380，12 个场景中 5 个 argmax 落此），且 L6 的 JS 近全层最低（0.009）。
按"改变化最大的层"去放 LoRA，会放到 L7/L0——**症状最明显但因果贡献不是最强**的位置。

**适用范围。** 任何"定位—修复"型工作（模型编辑、定向微调、LoRA 放置、失效归因）。
配套纪律：corruption 用**配对真实输入互换**（不用噪声破坏）、指标用**连续量**（不二值化）；
且"定位到责任层"与"修复该层就够了"是两个强度不同的主张，后者需要换成**后果相关的评分口径**
（碰撞余量/安全分）再验一次，不能只看轨迹 L2 恢复了多少。

# 附：本轮另外四条执行层教训（不足以升格为轴级 tip，但同样可迁移）

**A｜证伪地板必须与主读数共享同一条方向。**
对每个负类各自重新拟合一条方向，量到的是"能不能找到一条分开它们的方向"，系统性偏高，
且与已发表数字不可比。本轮此处的口径错误一度把 T-G 的判定从"不可估"抬成"H1 成立"
（+0.047 [−0.028, +0.122] 被误算为 +0.093 [0.004, 0.174]）。（DV/A16）

**B｜held-out 必须正负两侧都干净。**
"用从未见过的正例类别"不等于 held-out——若负例类别参与过方向拟合，负例侧被系统性压低，
AUC 依然虚高。直接证据：冻结方向在自己的拟合集上得 AUC = 1.000，而其 4 折 CV-AUC 只有 0.547；
把负例换成同样未参与拟合的类别后，跨类别 held-out 由 0.847/0.769 降到 0.543/0.501。（DV/A17）

**C｜层选择的可识别性要报，不能只报 argmax。**
本轮 CARLA 臂的逐层选择剖面在 0.747–0.797 之间近乎平坦（$L^*$ = 0 与 $L^*$ = 8 只差 0.001），
"峰层"实际不可识别；而首版的"逐折 argmax 取众数"规则在 2-2 平局时退化为"取层号最小者"，
恰好命中该退化。规则改为**逐折层剖面均值取 argmax**，并要求报告剖面本身。（DV/A12）

**D｜交叉验证的折分配漂移要量化，它常与效应量同量级。**
同一读数在不同折分配 seed 下可漂 ±0.02–0.08 AUC。本轮 T-G 的主读数−证伪地板在 10 个 seed 上为
+0.025 ± 0.025（DiffusionDrive）与 +0.002 ± 0.024（SimLingo）——**sd 与效应本身同量级**，
这一事实本身就是"本实验分辨率不足"的直接证据，比任何单次运行的 $p$ 值更能说明问题。

# 一句话总结（论文方法论贡献段落的候选表述）

> 我们在一条完整的诊断链（G 奠基 → F 忠实 → I 不变 → C 集中）上逐轴做了效度验证，
> 并从执行过程中提炼出四条不依赖具体场景的设计原则：
> **(G) 可枚举总体的极值零分布必须枚举而非外推；
> (F) 零结果必须配仪器侧灵敏度自检才能解读；
> (I) 跨域稳定性必须表征端与行为端并列，二者可给出相反排序；
> (C) 可分性、散度、因果责任三者不可互相代替，修复位点只能由干预决定。**
> 这四条原则的证据是本工作的数值结果，而原则本身才是贡献。
