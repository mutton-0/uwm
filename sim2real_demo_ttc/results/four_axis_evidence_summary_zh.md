## 1. 命题与本轮的证明责任

本工作的核心主张是：**公开榜单排名（如 nuScenes/NAVSIM 开环分数）与真实部署效果排名可能脱节，
而 G（语义奠基性）/ F（感知—动作忠实度）/ I（域不变性）/ C（失效集中度）四轴刻画的是这个脱节
具体发生在因果链的哪一环**——是感知未奠基（G），还是奠基了但未驱动动作（F），
还是驱动了但跨域不稳（I），还是失效弥散难修（C）。

该主张的完整证明需要三条线的对比（选型协议 §6 验收 0）：公开榜单排名、本框架排名、
真实 post-train 结果排名。**本轮不提供第三条线**，因此本轮的证明责任被限定为一个更窄、
但可以在当前资产上完成的问题：

> **四个轴是否各自可测、互不冗余，并且能给出任何单一标量分数在结构上无法给出的信息？**

下面的证据全部服务于这个被限定的问题；凡超出它的推断，均在 §5 明确标注为待证。

## 3. 三条支撑核心主张的实证结论

### 3.1 单一标量分数在结构上无法同时承载表征端与行为端（I 轴）

在**同一条**渲染域配对（CARLA 引擎渲染 ↔ 世界模型真实感重绘；同场景、同几何、同 actor、
同 ego 真值，唯一变量是渲染风格）上，两个模型的表征端与行为端读数给出**完全相反的排序**：
表征端 $D_{L^*}$ 判 SimLingo 更稳（0.394 vs 0.797），行为端域敏感度判 DiffusionDrive 更稳
（0.115 vs 0.346），且两组 scene 级 bootstrap CI 均不重叠。任何把"域鲁棒性"压成一个数的做法，
都必然在这两个排序中选一个而丢掉另一个。**这是"单一分数不足以刻画部署鲁棒性"的一个直接、
可复现的实例，且它不依赖任何关于榜单的假设。**

### 3.2 信息在表征里，但不驱动动作（F 轴）

SimLingo 的 driving query 表征**线性携带**了碰撞时间信息：以 TTC 为目标的岭回归在 scene 级
GroupKFold 上得到 held-out $r$ = +0.320（scene 级置换 $p$ < 1.0 × 10⁻³）。
然而这条方向与该模型自己的刹车驱动轴 $v_{brake}$ 的余弦为 −0.005，落在随机零分布正中；
以人类真实减速 $a_{brake}$ 为目标提出的观测法方向，与 $v_{brake}$ 的余弦为 +0.014
（95% CI [−0.049, +0.064]，即共线性上界 $\lvert\cos\rvert \le 0.064$，至多共享 0.4% 方差）。
与此同时 $v_{brake}$ **本身是因果有效的**：注入它引起的剂量斜率为 −0.0468 [−0.0517, −0.0421] m/s per α，
且该效应被通过动作头 Jacobian 的**解析预测**独立复现——在同口径的 ±α 全阶梯斜率上，
解析 −0.0432 ± 0.0084 vs 实测 −0.0405 [−0.0451, −0.0366]（比值 1.07，差 7%；逐事件 Pearson $r$ = +0.526），
另一条深层方向 $v_{hazard}^{clean}$@L23 的比值为 0.98、逐事件 $r$ = +0.993。
**即"能开动作的轴"与"编码危险的轴"在几何上互不相干**——这正是 causal confusion
（de Haan et al. 2019）在表征层的签名，也是开环分数在结构上看不见的一环：
开环分数只检验动作是否接近参考轨迹，不检验动作由什么驱动。

（限定：单帧模型对目标运动结构性全盲，TTC 含速度量，故 $r$ = +0.320 中相当一部分应归于
TTC 与**距离**的相关。此限定不影响论证——无论该方向携带的是 TTC 还是距离，它都与刹车轴正交。）

### 3.3 修复成本与性能指标无关，且只能由干预读出（C 轴）

DiffusionDrive 在渲染域迁移下的轨迹退化，其因果责任高度集中：
$C_m$ = 0.858 [0.771, 0.939]，远高于弥散基线 0.250，top-1 层单独占 0.618，
责任层众数为编码器深层融合段 **L6**（12 个退化场景中 5 个）。
但三种"看起来都能定位"的量给出**三个不同的峰层**：注意力散度 JS 峰 L7、特征散度 1−CKA 峰 L7、
t-SNE 可分性峰 L5、而因果恢复峰 L6（且 L6 的 JS 近全层最低）。
**"退化了多少"（榜单能给）与"退化从哪进入、修它多贵"（榜单给不了）是两个正交的问题**，
而后者只能由干预（配对输入互换的 activation patching）回答，不能由散度、CKA 或与下游分数的相关代替。

## 4. 一条必须并列陈述的负结果：G 轴当前的分辨率不足以支撑"是否奠基"的断言

T-G 是本组唯一的方法学正向校准实验，问的是"G 轴的尺子在一个大概率真有 grounding 的模型上
能不能读出'有'"。结论是**不可估**：DiffusionDrive 的"主读数 − 自身 D2cV 证伪地板"
= +0.009，scene 级 bootstrap 95% CI [−0.047, +0.065]，跨 0；10 个折分配 seed 上为 +0.012 ± 0.032，
**sd 大于效应本身**。四条口径（两模型 × 两种池化）的该差值两两之间都在 1 个 sd 以内，
且每一个都与 0 不可区分，没有任何一对呈现决判规则所要求的"质的差异"。
（本段数字为**刺激集补齐后**的版本：首轮 DiffusionDrive 侧 D2cV 只有 141 条而 SimLingo 侧 212 条，
补齐 116 个缺失事件后两侧 D2a = 283、D2cV = 212、D2bV = 78 完全一致，见 `amendments.md` §FA/A19。）

更强的一条限制是：连"感知端信号强弱"的排序本身也不稳健——
相对置换零分布的超出量在 `vision_mean` 上是 DiffusionDrive +0.065 vs SimLingo +0.021，
而在 `region_mean` 上是 DiffusionDrive +0.024 vs SimLingo +0.056，**两个口径给出相反的排序**。
据此，本文对 G 轴读数的使用被限定为：**只能在指定池化口径内报告单模型的信号强弱，
不能跨模型排序**，更**不能单独支撑"该模型是否真正奠基于危险概念而非任意 VRU 的存在"的断言**——
后者要求 D2cV 证伪地板可区分，本轮未达到。瓶颈已定位为 D2cV 负例的样本量（141 条匹配负例），
而非池化选择或模型选择。

**该限制在换触发判据后依然成立。** 把 SimLingo 侧的正例从 A（VRU 突现）换成
B（近距 cut-in）或 C（通用 TTC 骤降），其余口径一律不动：三条判据的读数都高于各自的置换零分布
（+0.179 / +0.056 / +0.026），但**没有一条能与自身的 D2cV 证伪地板区分开**
（差值 −0.022 [−0.082, +0.043] / +0.003 [−0.062, +0.060] / +0.023 [−0.045, +0.091]，全部跨 0）。
即：这不是某一种场景类型的特例，而是当前 G 轴口径的一般分辨率上限
（详见 [`direction_validity_report.md`](direction_validity_report.md) §5.3）。

跨分布复测（Table 2）进一步收紧了这一限定：**唯一一条具有强 in-domain 读出力的方向
$v_{hazard}^{carla}$（CARLA in-domain CV-AUC 0.808），跨到 nuScenes 后 AUC = 0.490，
恰在同层随机方向地板上（超出 −0.001）**。即：in-domain 判别力强 ≠ 该方向编码了可迁移的危险概念。
这条负结果本身支持核心主张的方向——**在一个域上测出来的高分不保证跨域仍然成立**——
但它同时也说明，本框架 G 轴目前给出的是"在该域上读得出/读不出"，还不是"是否奠基"。

**同一条方向在操纵端给出第三重否定。** 把 $v_{hazard}^{carla}$ 注入 SimLingo 处理 nuScenes 帧：
① 整条 ±α 阶梯斜率为 **+0.0142 [+0.0077, +0.0216]**，即注入这条"危险方向"使模型**加速**而非减速，
符号与因果预期相反；② 特异性检查给出 |Δ横向|/|Δv_plan| = **1.06**（对照：$v_{brake}$ 为 0.11、
$v_{hazard}^{clean}$@L23 为 0.17），即横向被推动的幅度与纵向相当——
它不是一条"反向的危险轴"，而是**一条非特异的扰动方向**。
读取端 AUC 0.808、跨域 AUC 0.490、操纵端符号相反且不特异：
**三条独立证据一致指向"高 in-domain 判别力可以完全不含可迁移的危险语义"。**

## 5. 尚未证明的部分（明确列出，避免过度声明）

1. **三线对比未完成。** 本轮不含真实 post-train 结果排名（选型协议 §6 验收 0 的第三条线），
   也未在本轮重新测量两个模型的公开榜单分数。因此"榜单排名 ≠ 部署排名"这一命题在本轮
   **仅被证明为可测量、可分解**，未被证明为**已发生**。
2. **F 与 C 各只在一个模型上测得**（F 仅 SimLingo，C 仅 DiffusionDrive），
   故 Table 1 的四轴不构成一个完整的跨模型对比矩阵。
3. **域配对不是 3DGS 重建**，而是世界模型真实感重绘；I 轴结论的适用范围写作
   "CARLA 渲染 ↔ 世界模型真实感渲染"，最终以麦迪逊阶段的 real↔3DGS 版本为准。
4. **DiffusionDrive 的原生训练域未经独立核实**，一切依赖"谁是 in-domain"的解读均为条件结论。
5. **C 的判定限于"定位成立"**，不含"修复该层就够了"——后者需换成后果相关的评分口径
   （伪闭环 PDM 式 margin）再验一次，本轮未做。
