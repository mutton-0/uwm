## Motivation／动机

本工作的核心主张是：**公开榜单排名与真实部署效果排名可能脱节，
而 G/F/I/C 四轴刻画的是这个脱节具体发生在因果链的哪一环。**
完整证明需要三条线并置：①公开榜单分数、②本框架的四轴矩阵、③真实 post-train 结果。
本报告把这三条线放进同一张表，并逐格标注**可比性**——
因为本工作线在执行中发现，"可比性"本身就是最强的一条论据。

---

## Method／方法

**第一条线（公开榜单）** 采用用户提供的已公开分数，原样引用，不做任何换算：
SimLingo 在 CARLA Leaderboard 2.0 的 Driving Score = 6.87；
DiffusionDrive 在 NAVSIM navtest 的 PDMS = 88.1。
本报告**不**尝试把两者归一化或映射到同一量纲——不可比正是要报告的事实。

**第二条线（四轴矩阵）** 全部读数在**同一份 nuScenes 鬼探头刺激集**
（G1 语料 + N1 的 D2a/D2b/D2c/D2cV 负例体系）与**同一套统计口径**
（scene 级三分或 K 折、scene 级 bootstrap、三态判定、逐层零分布）下对两个模型分别测出。
每一格另标一列**跨模型可比性**，并在不可比时给出可比的替代量。

**第三条线（pilot post-train）** 见 `pilot_posttrain_report_zh.md`：
针对 SimLingo，固定预算（只训 229k 参数的 `speed_wps_head`），三臂设计
（基线 / 纯任务微调 / 任务 + 耦合），held-out scene 上同时读行为分与耦合量本身。

## Discussion／讨论

**1. 第一条线最重要的信息不是"谁分高"，而是"排名这件事在公开分数上无法定义"。**
6.87 与 88.1 之间不存在有意义的大小关系：基准不同（CARLA Leaderboard 2.0 vs NAVSIM navtest）、
域不同（仿真 vs 真实数据重放）、协议不同（闭环 vs 非反应式伪闭环）、
指标定义不同（Driving Score = 路线完成度 × 违规惩罚的连乘 vs PDMS = 若干子分的加权组合）。
把两者并排放，唯一能读出的信息是：**公开分数体系连"排名"都排不出来。**
这不是本工作的一条局限，而是**核心主张的第一个论据**——
若两个候选连排名都排不出来，那么"榜单排名与部署排名脱节"这句话里的"榜单排名"根本不存在，
选型就只能靠别的东西。而第二条线的四轴，是在**同一份刺激集、同一套口径**下对两个模型测出来的，
因而可以逐格对齐——**这正是本框架相对公开分数的第一个、也是最基本的增量。**

**2. 第二条线的结论是：四轴可以对齐，但本轮只有 C 轴给出了跨模型的实质区分。**
G 轴在两个模型上都判不可估（差值 CI 都跨 0，且两种池化口径给出相反排序）；
F 轴的可比读数（行动层反事实）在两个模型上也都不可估。
唯一给出实质区分的是 **C 轴**：两个模型的域失效**进入位置完全不同**——
SimLingo 的恢复剖面自 L0 单调递减（Spearman −0.997），即失效在**视觉编码到 LLM 的接口处**就已进入，
把第 0 层的 vision token 换成 sim 侧的，行为完全回到 sim 侧（patch-ALL recovery = +1.004）；
DiffusionDrive 的剖面则有**内部峰**（Spearman +0.881，L0/L1 的 recovery 近 0，责任集中在 L6）。
**同一套诊断给出了两个完全不同的修复处方：一个改视觉前端，一个在深层融合段挂 LoRA。**
这是公开分数在任何情况下都给不出的信息——6.87 与 88.1 都不含"坏在哪、修哪里"。

**3. 第二条线还给出了一条方法学结论：四轴的操作化方式不是全部可移植的。**
F 轴若以 steering 效应量操作化，在连续回归头上可测、可解析预测（解析/经验比 0.98–1.07），
在 anchored 扩散头上**在 ±32σ 内完全不可测**——连按构造必然有效的 $v_{brake}^{dd}$ 都推不动。
C 轴若以 top-2 层占比操作化，在内部峰剖面上成立，在级联剖面上**前提不成立**。
因此本表把这两行标为不可比，并**拒绝**用任何权重把它们与其余格子合成一个数。

**4. 为什么不给一个总分。** 四个轴的单位、判定状态与可比性都不同：
G 与 I 是模型内归一化、可跨模型对齐的读数；F 的 steering 口径在两个模型间不同量纲；
C 的 top-2 占比公式在 SimLingo 上前提不成立。
把这四格加权成一个数，等于**把"不可比"和"不可估"当作 0 或当作中位数来处理**，
而这两种处理都会让最终排名的来源无法追责——
一旦有人问"为什么 A 排在 B 前面"，答案会落在权重上，而不是落在证据上。
本工作宁可交付一张有空格、有"不可比"标注的矩阵，也不交付一个看起来干净但不可追责的标量。

**5. 第三条线把主张收紧到了它应有的强度。**
pilot 证明 F 轴诊断指向的是一个**可干预、可测量、可被确证改变**的内部量（耦合量改动 3.3 倍），
这是"四轴定位到因果链某一环"这一主张的最强形式的证据之一。
但同一实验也证明：**改变那一环并不自动带来部署行为的改善**
（A2 − A1 = +0.001 [−0.004, +0.007]，三个并列行为读数一致）。
故本工作的准确主张是：**四轴定位脱节发生在哪一环**，
而**不是**"四轴分数可以预测 post-train 收益"。
后者需要三条线的第三条真正闭合（更大预算 / 闭环后果指标），本轮未做。

**6. 三线并置后的整体图像。**
公开分数：无法排名。四轴矩阵：G、F 不可估，C 给出两个不同的修复处方。
pilot post-train：诊断所指的环节可以被修好，但固定小预算下不产生行为收益。
三条线合起来支持的，是一个比原始主张更谨慎、也更可辩护的版本：
**公开分数不足以给出选型排名，四轴可以在同一口径下给出可追责的分环诊断；
但"诊断 → post-train 收益"这一步，本轮尚未建立。**

   本轮没有重跑 CARLA Leaderboard 2.0 或 NAVSIM navtest。
   本报告对这两个数字的唯一使用方式是论证它们**不可比**，
   该论证只依赖两个基准的定义差异，不依赖数值本身的准确性。
3. **第三条线只覆盖 SimLingo**。DiffusionDrive 未做 pilot post-train，
   原因是本轮已确证其 steering 仪器无分辨力（§HL/A25），
   而耦合损失的定义依赖可测的注入响应 $\Delta_{1\sigma}$；
   在该模型上该量恒为 0，耦合项没有梯度信号。这是架构决定的，不是预算决定的。
