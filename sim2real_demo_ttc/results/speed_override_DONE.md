**在 F-3 上不成立，方向与预期相反**。旧结果未改未删，新结果 `_spdctrl` 后缀。

- **合理性检查**：AutoVLA **未通过**（唯一值 24→20→10→5，floor8 时 14/24 塌到 3 个取值，
  源于其 token 化的纵向动作词表），按工单条件**未重跑 F-3**。
  DD/DDv2 在 floor11 图像驱动变异暴涨（0.72 / 3.27）亦属分布外 ⇒ 三个候选值里只有 8 稳。
- **F-3 重跑**：LTF 由 **FAIL 变不可估**（门由开变关）；SimLingo 标签未变但**门也由开变关**；
  DD/DDv2 门本就关、仍关但符号翻转。**四候选效应量一律缩到 0.30–0.41 倍。**
- **机制**：方向一致率全部塌向 50%，**信噪比降到 0.24× / 0.27× / 0.32× / 0.58×**。
  退化随速度抬升量单调加重（LTF：未抬高 1.00× → 抬>7m/s 2.11×）。
- **前提有误**：b_ghost 是同事件配对差、两臂共用同一喂入速度 ⇒
  跨事件背景速度差异**在配对时已抵消**，从未进入 b_ghost。覆盖反而制造跨模态矛盾输入。
- **内置对照**：真实速度已≥8 的 46 个事件四臂输出**逐位相同**（四候选均 46/46，最大差 0），
  证明唯一变量确实只有喂入速度。
