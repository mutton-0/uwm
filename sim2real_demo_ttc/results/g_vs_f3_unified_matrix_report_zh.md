## 0. 为什么换掉旧的 G/F（动机，不是功能需求）

三个语料（G1 / 前车急刹 / NAVSIM）上的多轮实验反复给出同一个模式：
**围绕"危险"这个语义构念构造的 G/F 读数，天然依赖挖掘管线对"什么算危险"的人工判据，
因而跨场景、跨数据源都不稳定。**

| 旧读数 | G1 | 换场景（前车急刹） | 换数据源（NAVSIM） |
| --- | --- | --- | --- |
| G（主读数 − D2cV 地板） | LTF **+0.070 PASS**，其余不可估 | 全部不可估 | **全部不可估，含 LTF**（功效相当） |
| F①（b-AUC） | LTF、DDv2 **PASS** | 全部不可估 | 仅 SimLingo 逐位复现，两个 PASS 全掉 |

G-VS 与 F-3 的设计目标就是把这两件事换成**有客观 GT / 不需要语义判据**的检验：

* **G-VS**：模型表征能否对应真实场景结构（SAM 分割伪 GT）——**可验证的感知正确性**，
  不涉及"危险"这个主观判断；
* **F-3**：拿掉真实存在的关键实体，动作会不会跟着消失——**输入层的因果操作**，
  不需要构造匹配负例。

文献锚点：Embodied Interpretability（arXiv 2605.00321）的 blind action / spurious correlation /
post-hoc rationalization 三分法（本轮只做 blind action 对应的必要性检验）；
Causal Imitative Model（Samsami et al. 2021, arXiv:2112.03908）的 causal inversion 框架与
inertia / collision 两种失效签名；Hewitt & Liang 2019 的探针 selectivity 纪律。

## 2. G-VS：两个候选通过，但绝对 mIoU 都很低

**通过的两个**：DiffusionDrive（selectivity +0.038）与 SimLingo（+0.027），
两者的 scene 级配对 CI 下界都 > 0，即**表征里确有可线性读出的物体性信息**。
LTF（+0.019）与 DiffusionDriveV2（+0.016）的 CI 擦着 0，判不可估。

**但必须同时报告一个限制**：四个候选的 trained mIoU 都在 **0.35 ~ 0.40** 之间，
而 `position_only` 地板（只用 token 坐标）就有 **0.333**。
也就是说，**绝对 mIoU 的绝大部分来自空间先验，模型表征的净贡献只有 0.02 ~ 0.04。**

这个净贡献之所以仍然可信，是因为它是**配对差**：
同一份图像、同一层、同一网格、同一个探针，只换模型权重是否训练过。
但"净贡献小"这件事本身要如实写出来，不能只报 selectivity 显著就完事。

**低 mIoU 的归因有一个独立锚点**（见可行性报告 §1.1）：
三个 TransFuser 系候选的**原始训练目标里就带 BEV 语义分割头**，
所以它们的表征里一定含有分割信息。既然如此，探针只拿到 +0.02 ~ 0.04 的净增益，
问题更可能在**读出侧**而不是**表征侧**：

* **token 网格太粗**：TransFuser 系是 8×32，一个 token 覆盖原图约 50×50 px，
  行人在中远距离往往不足一个 token；
* **线性探针的容量下限**：这是刻意的（Hewitt & Liang 的纪律），代价就是读数偏保守；
* **BEV vs 图像空间**：它们被训练去做 **BEV** 分割，图像空间的物体性未必以线性可读的形式保留。

**因此 G-VS 的正确读法是"表征里有可线性读出的物体性信息，量不大"，
而不是"这些模型看不清场景"。** 这个区分对下一版的设计是关键的。

## 3. F-3：这一轮最干净的结果，也是最负面的

**六个候选没有一个通过必要性检验。** 但"没通过"分成两类，诊断意义完全不同：

### 3.1 LTF：**FAIL** —— 有响应，但响应不是这个实体驱动的

| 量 | 值 |
| --- | --- |
| $b_{ghost}$（危险帧引起的动作变化） | **−0.0245 [−0.0384, −0.0102]，显著** |
| $b_{occ}$（遮住该实体后） | −0.0170 [−0.0303, −0.0032]，**仍然显著** |
| **必要性比 $R$** | **+0.113 [+0.044, +0.191]** ⇒ 只移除 11% |
| 对照臂 $R_{ctrl}$（涂别处） | +0.029 [−0.031, +0.081]，与 0 不可区分 |

**ctrl 臂让这个判定站得住**：涂一块同样大小的灰斑在别处，动作几乎不变（3%）；
涂在危险实体上，也几乎不变（11%）。**即"遮挡"这个操作本身不是无效的，
无效的是"遮住**这个实体**"。** 这正是 Embodied Interpretability 讲的 **blind action** 签名：
动作看起来对危险场景有反应，但驱动它的不是危险实体本身。

驱动源是什么，本轮没有回答——那是 Future Work 的 F-2（虚假相关/注意力分析）要做的。
Causal Imitative Model 提示的两个候选是 **inertia**（跟着自车历史速度走）
与 **collision**（跟着场景整体统计走）。

### 3.2 其余四个：**不可估** —— 压根没有可供检验的响应

DiffusionDrive、DiffusionDriveV2、Alpamayo-R1、AutoVLA 的 $b_{ghost}$ 本身与 0 不可区分。
必要性检验的前提是"先有一个响应"，前提不成立时**不能判 FAIL**。

**为什么这个区分是实质性的**：
* **FAIL（LTF）**：有响应但接错了线 ⇒ 修复方向是**查驱动源、把动作接到正确的证据上**；
* **不可估（其余四个）**：连响应都没有 ⇒ 修复方向是**先让它对危险帧产生响应**。

把两者都写成"没通过"，会把两种完全不同的修复处方压成同一个数字——
这与本文一贯拒绝合成综合分的理由是同一条。

### 3.3 对照臂全部行为正常，说明设计有效

六个候选的 $R_{ctrl}$ 全部落在 **[−0.086, +0.155]** 且 CI 跨 0，
即"在别处涂灰斑"不会让动作退回基线。**这条把 occ 臂的两个效应成功分开了**，
是 F-3 判定可信的前提（§GF/A51）。

## 4. 两个新轴之间的关系：G-VS 通过不蕴含 F-3 通过

| Policy | G-VS | F-3 |
| --- | --- | --- |
| SimLingo | **PASS** | 不可估（$R$ = 0.461，最接近通过） |
| DiffusionDrive | **PASS** | 不可估（无基线响应） |
| LTF | 不可估 | **FAIL** |
| DiffusionDriveV2 | 不可估 | 不可估（无基线响应） |

**DiffusionDrive 是最清楚的一格**：它的表征里**确有**可线性读出的物体性信息
（G-VS selectivity 全表最高 +0.038），但它的动作**对危险帧根本没有响应**。
**"看得见"与"据此行动"是两件独立的事**——这与旧 G/F 体系反复给出的
"信息在表征里但不驱动动作"是同一条结论，
**但这次是用有客观 GT 的感知检验 + 输入层因果操作得到的，不依赖任何"危险"判据。**

这是本轮相对旧体系的核心增量：**同一条结论，换了一套不依赖语义构念的证据。**

## 5. 局限

1. **G-VS 只覆盖 4/6**（§GF/A50）。AutoVLA 的 token 布局已解出、卡在实现；Alpamayo 未解。
2. **G-VS 的绝对 mIoU 低、净贡献小**（0.02 ~ 0.04），归因偏向读出侧（网格粗 + 线性探针），
   已给出 BEV 分割头这个独立锚点，但**未做网格分辨率的消融**。
3. **G-VS 是二类物体性，不是语义分割**。"认得出这是行人还是锥桶"没有被测，留给 G-VL。
4. **F-3 的遮挡是灰斑填充，不是 inpainting**。灰斑本身是分布外的；
   ctrl 臂控制了"加灰斑"这一效应，但没有控制"灰斑改变了全局图像统计"。
5. **两个 VLA 的 F-3 事件数受限**（Alpamayo 99、AutoVLA 119，其余 282），
   慢模型控成本所致；且 Alpamayo 另受覆盖预筛（186/288）与采样噪声影响。
6. **只做了 G1 一个语料**。按工单 §3，前车急刹 / NAVSIM 上的复现是加分项，本轮未做。
