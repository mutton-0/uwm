# T1-L 语义配对臂 + T1-Q 寻轴 v2 报告

> 日期：2026-08-05  依据：`docs/demo_guide_v3_repe_mainline.md` 附录 A（T1-L 执行卡）与 §T1-Q
> 模型：SimLingo，目标域：nuScenes v1.0-trainval
> 前置：T1/T2/S1 见 `results/t1_t2_s1_report.md`（E1 FAIL、E2 FAIL、E-S1 PASS 带警告）

## 0. 一句话

**危险概念在模型里是存在的、语言可及的、可 steering 的；视觉危险事件也确实（微弱地）激活它——
但这条概念轴与行为轴近正交，且激活量与实际刹车行为反号。结论落在 guide 四格表的"概念→动作断"一格。**

同时得到一个**推翻此前判定口径的方法学结果**：随机方向零分布的中心与离散度**随注入层大幅变化**，
"随机方向应零效应"不是跨层通用的判据；而且按构造必然真实的 $v_{brake}$ 在自己层上也没通过该对照。
此前 T2 只用 5 个单点 +α 随机种子就下的"随机零效应 ✗"，在方法上不成立，需重判（§4.4）。

## 1. Step 1｜语言对定义危险轴

刺激集 198 帧（9 种事件类型分层混采）× 6 组措辞 × 2 条件 = **1188 个 δ**；
读取位置 = driving query token（30 个位置的均值）；轴 = 未去均值 PCA 的 PC1。

> 实现要点（踩过的坑）：δ 的均值方向**就是**概念方向，先去均值再取 PC1 会把要找的东西减掉。
> 另：不去均值的 SVD 对逐行符号翻转严格不变，所以 **EVR₁ 不能做置换检验**
> （冒烟跑到的置换零分布 0.766 恒等于观测 0.766 就是这个数学事实）。
> 改用配对一致性 $r=\|\overline{\delta}\|/\overline{\|\delta\|}$ 与 held-out 投影。

| 读数 | 值 |
|---|---|
| 选层（held-out 投影 cos 最大） | **L\*=10** |
| held-out 投影 cos | **0.613** |
| held-out 投影**正比例** | **1.000**（对半 split，另一半的 δ 无一例外投在正侧） |
| 配对一致性 r | **0.644** |
| EVR₁ | 0.461 |

**对照①（置换配对 selectivity，5 seed）**：r = 0.037 / 0.042 / 0.030 / 0.024 / 0.025
→ 观测 0.644 **高出零分布一个数量级**，轴的存在性无可争议。

**对照②（语义特异性）**：cos($v_{danger}^{lang}$, $v_{weather}$) = **+0.473**。
判在阈值边缘——**近一半是"任意语义变化"的共同成分**，不是危险特异的。
已另存对天气轴正交化的版本 `v_danger_lang_orth_query_mean.npy`
（与原轴 cos=0.881，保留主要成分），留作敏感性。

**对照③（措辞稳定性）**：6 组措辞两两 cos 中位 **+0.443**，范围 [+0.131, +0.670]。
方向一致（全为正）但不紧致——轴随措辞有可观漂移。

**Step 1 判定：✅ 轴存在且选择性极强；⚠️ 危险特异性与措辞稳定性都只是勉强。**

## 2. Step 2｜轴的因果自证（中性 prompt + clean 帧，注入 query 位置）

α 以该层激活 σ 为单位，扫 ±{0.5, 1, 2, 4}；S_test A 事件 n=61。

| α | Δv_plan [m/s] | 95% CI |
|---|---|---|
| +0.5 / +1 / +2 / +4 | −0.013 / −0.026 / −0.046 / −0.086 | 每档 CI 均不含 0 |
| −0.5 / −1 / −2 / −4 | +0.009 / +0.025 / +0.044 / +0.092 | −1 起 CI 均不含 0 |

- **预注册主读数（正向 α 斜率）= −0.0211 m/s per σ，95% CI [−0.029, −0.012]**；
- 全阶梯（±α）斜率 = −0.0224 [−0.033, −0.011]；
- 剂量**单调且反对称**：注入危险方向减速、反向注入加速，幅度对称。

**特异性**：α=4 时 Δ横向 +0.031 vs Δ速度 −0.086，斜率比 **0.30**
（视觉判别式轴同口径是 0.75，$v_{brake}$ 是 0.11）。

**Step 2 判定：✅ 剂量单调 + 反对称 + 特异性中等；随机方向对照见 §4（该对照已失效）。**

## 3. Step 3｜核心读取实验（全程中性 prompt，零额外前向）

危险措辞只存在于 Step 1 的离线刺激集，此后绝不出现（"测量不污染"红线）。
本步直接吃 G2 缓存（schema v3 新增 `query_mean`），clean/ghost 两条件 prompt 逐字一致。

**主读数（预注册）**：A 类 δ=(ghost−clean) 在 $v_{danger}^{lang}$@L10 上的投影差

```
均值 = +0.0475   95% CI [+0.0119, +0.0828]   n=287   单样本 t p=7.8e-4
归一化（除以 ‖δ‖）= +0.0254   95% CI [+0.0037, +0.0466]
```

**✅ 视觉危险事件确实激活了语言定义的危险概念轴。** 但要看清三件事：

1. **效应极小**：归一化后只有 δ 模长的 **2.5%**；
2. **不具类别判别力**：AUC(A vs D2a)=**0.523**（p=0.35）——
   对几何匹配的静物读不出差别，即"它激活的不是'这个目标危险'";
   （D2b 0.569 p=0.005，D2c 0.532 p=0.19）
3. **与行为的关联是反号的**：Spearman ρ(投影差, b) = **−0.161**（p=0.006）。
   b>0 = 模型在 ghost 帧刹了车。**危险轴激活越强、实际刹车越少**——
   与 Step 2 的因果方向（注入危险方向 ⇒ 减速）**相反**。

第 3 条是本轮最硬的负面证据：观察到的激活与因果通路对不上号。

## 4. T1-Q｜$v_{brake}$ 参照轴、夹角矩阵，以及一个仪器诊断

### 4.1 $v_{brake}$ 存在

标签 = 模型自身刹不刹（逐条件 pred_speed 对 ego_speed 回归后的残差，低残差=刹得多；
不扣 ego_speed 主效应的话提到的是"车速轴"而非"刹车轴"）。
query 位置提取，S_dir 提方向 / S_sel 选层：**L\*=22，S_sel |ρ(投影, v_plan)| = 0.463**。

### 4.2 关键测试：视觉危险**不**推动行为中介态

A 类 ghost−clean 在 $v_{brake}$@L22 上的归一化投影差 = **+0.0034，95% CI [−0.0010, +0.0074]**
（全部 287 个 A 类；test 折 n=56 时 CI 更宽，属"不可估"）。
对比同口径的 $v_{danger}^{lang}$ 的 **+0.0254 [+0.0037, +0.0466]** —— 差一个数量级。

### 4.3 夹角矩阵：概念轴与行为轴近正交

```
cos(v_danger_lang, v_brake)  = +0.022 @L10（语言轴峰层）   +0.065 @L22（刹车轴峰层）
全层 |cos| 中位 0.016，最大 0.065      896 维随机基线 = 1/√896 = 0.033
cos(v_brake, 视觉判别式)      = −0.042
cos(v_danger_lang, 视觉判别式) = +0.015
```

**三条轴两两的夹角都在随机基线上下** —— 语言概念轴与行为轴不共享方向。
这是 guide §T1-Q 要的"概念→动作断"的几何证据。

### 4.4 ⚠️ 仪器诊断：E2 的随机方向对照在 query 位置失效

按 guide，$v_{brake}$ 的 steering "应平凡通过"，用作站内上界标定。实测：

按 guide，$v_{brake}$ 的 steering "应平凡通过"，用作站内上界标定。
两层各跑 **20 个随机种子**的完整 ±α 阶梯零分布：

| 轴 | 注入层 | 全阶梯斜率 | 同层随机零分布 (n=20) | 零分布居中? | 置换 p（单侧） |
|---|---|---|---|---|---|
| $v_{danger}^{lang}$ | L10 | −0.0224 [−0.033, −0.011] | 均值 −0.0058，**sd 0.0129**，范围 [−0.031, +0.020] | 是（p=0.060） | **0.095**（1/20），z=−1.29 |
| **$v_{brake}$**（按构造必然真实） | L22 | **−0.0405** [−0.045, −0.037] | 均值 −0.0092，**sd 0.0253**，范围 [−0.053, +0.031] | 是（p=0.12） | **0.190**（3/20），z=−1.24 |

> **一处自我更正（保留记录）**：本报告初稿依据 5 个种子写过"L22 零分布明显不居中、
> 随机方向系统性压低规划速度"。扩到 20 个种子后该结论**不成立**——5 个种子碰巧全为负是
> 小样本假象，20 个种子的均值=0 检验 p=0.12。**对照不是有偏，是功效极低。**

**真正的方法学结论：这个 steering 斜率统计量没有分辨力。**

- 随机零分布的**离散度**（sd 0.013–0.025）与待测轴的效应量（0.022–0.041）**同量级**；
- 按构造必然为真的 $v_{brake}$ 只拿到置换 **p=0.190**，3/20 个随机方向的斜率比它更大；
- 即：**在 61 事件 × 20 种子的分辨率下，该检验连一条保证为真的行为轴都认证不了。**

因此此前 T2（视觉轴 @L1、@L12）与本臂 Step 2 的 "随机零效应 ✗"，
**都不能当作"该轴无效"的证据** —— 但理由是**功效不足**，不是对照有偏。

一个反直觉的附带观察：语言轴的置换 p（0.095）**好过** $v_{brake}$（0.190），
因为 L10 的零分布比 L22 紧一倍 —— 再次说明**零分布必须逐层自带**，跨层比较无意义。

**要让 E2 可判，需要改造检验**（三选一或组合）：
①提高事件量（61 → 数百，零分布的 sd 不变但轴效应的 CI 收紧，仍解决不了零分布宽的问题）；
②换统计量（不依赖注入幅度的量，如注入前后**行为排序**的改变）；
③把随机方向改为**激活流形内**采样（真实激活两两之差），使零分布代表"同样真实但语义无关"的扰动，
而非各向同性高斯——当前的高斯零分布很可能高估了"随机"扰动的破坏力。

附带一个候选判别量：横向/速度斜率比 —— $v_{brake}$ 0.11 < $v_{danger}^{lang}$ 0.30
< 视觉判别式 0.75，排序与"轴的真实程度"一致；但同跑随机方向的该比值中位 0.33–0.46、
范围宽到 [0.03, 1.78]，n=5 时分不开，**目前不能当结论**。

## 5. 四格判定（guide 附录 A）

| Step1 | Step2 | Step3 | guide 给的结论 | 本轮 |
|---|---|---|---|---|
| ✅ | ✅ | 投影差显著 | 有效危险轴找到 | 部分符合：显著但效应仅 2.5%、无类别判别力 |
| ✅ | ✅ | 无差 | 视觉→概念断 | — |
| ✅ | ✗ | — | 概念→动作断 | **实际落在这里**（见下） |

**本轮不落在任何单一格里，需要合并陈述**：

- Step 1 ✅（轴存在，选择性极强）；
- Step 2 ✅（剂量单调、反对称、特异性中等）——**但其随机对照失效，因果强度的量级无法定标**；
- Step 3 **投影差显著但极小、无类别判别力、且与行为反号**；
- T1-Q 补的两条独立证据（$v_{brake}$ 不被视觉危险推动 + 概念轴⊥行为轴）
  **共同指向"概念→动作断"**。

**综合结论：SimLingo 内部有一条语言可及、可操纵的危险概念轴；视觉危险事件对它只有
~2.5% 量级的、不区分类别的、且与实际刹车反号的激活；这条轴与模型的行为轴近正交。
即：概念在，但视觉→概念的通路极弱，概念→动作的通路断开。**
