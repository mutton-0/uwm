# T-F：感知—动作忠实度（F 轴）——观测法刹车方向与注入法 $v_{brake}$ 的共线性检验

> 轴名依据 2026-08-29 定稿的 G/F/I/C/D 命名（映射见 [`axis_naming_alignment.md`](axis_naming_alignment.md)：
> **历史文件中的 S 轴 = 本报告的 F 轴**）。预注册见 [`amendments.md`](amendments.md) §FA.0、
> 设计偏离见 §FA.1 偏离 2。数值产出物：`f_axis_ttc_gradient.json`（主）、
> `f_axis_ttc_gradient_sens_{ttc,clean,both}.json`（敏感性）、`f_axis_abrake.json`（真实行为真值）。

---

## Motivation／动机

F 轴（Faithfulness）问的是：策略的连续控制输出，是否由 G 所奠基的**同一组特征**因果驱动，
还是经由另一条与正确行为在训练分布内偶然相关、但因果上独立的路径生成
（理论谱系：Causal Confusion in Imitation Learning, de Haan et al. 2019）。
它在因果链上排在 G 之后：看对了不等于看对的东西驱动了动作。

本项目此前已有一条**注入法**的 F 轴方向 $v_{brake}$：用模型**自己**的刹车残差当标签，
在 driving query 位置提出，且已通过 W1 完整 steering 四件套。但它有一个结构性弱点——
标签来自模型自身输出，存在自证风险：它可能只是"模型输出速度的主成分"，
与"真实世界里该不该刹车"没有关系。

本实验用一条**完全独立的观测法**去检验它：从**人类驾驶员在同一批事件里的真实减速强度**
（nuScenes ego_pose 重算）回归出一条隐空间方向 $v_{brake}^{obs}$，再问它与 $v_{brake}$ 是否共线。
两条路径唯一的共同点是模型的隐状态；标签来源一个在模型内、一个在模型外。
若共线，F 轴获得双方法互证；若正交，说明模型内部那条"刹车轴"与真实刹车严重程度无关，
**这正是"榜单分数（拟合模型自身输出分布）与真实部署（要求对真实危险作出真实减速）脱节"
在表征层的直接证据。**

## Method／方法

**真实行为真值（强 ground truth）。** 事件账本只存了 clean/ghost 各 2 帧的 `ego_speed_mps`，
不足以刻画"探头出现后人类踩了多重的刹车"。故回到 nuScenes `ego_pose` 原始位姿序列
（CAM_FRONT 全部 sample_data，含 sweeps，约 12 Hz），二次中心差分求纵向加速度并各做一次
3 点滑动平均，取窗口 $[t_{emergence},\, t_{emergence}+3\,\mathrm{s}]$ 内的**最小值**为 $a_{brake}$。
覆盖全部 **7003** 个事件；分布：p5 = −6.83、p25 = −1.42、p50 = −0.84、p75 = −0.19、p95 = +0.18 m/s²。
**这是人类驾驶员的真实行为，不是模型自身输出的代理量**，满足方向发现计划 Stage E 红线 2。

**特征。** 与 $v_{brake}$ **同一位置、同一池化**：driving query 段均值 `query_mean`，逐层 24 层。
条件取 **ghost**（与 $a_{brake}$ 的测量窗口时间对齐）；clean 与 both 作敏感性。
可用事件 n = 2285（677 个 scene），其余因缓存 schema 较旧无 `query_mean` 而排除。

**目标与去混淆。** 回归目标为 $-a_{brake}$（取负使"数值大 = 刹得狠"，与 $v_{brake}$ 标签 1 = "刹得多" 同号），
并**先回归掉 $v_{at\,emergence}$**：不扣掉的话拟合到的是"车速轴"（快车刹得狠是平凡事实，
且 prompt 里明写 `Current speed`，车速信息本就在激活里）。实测车速主效应
$\beta$ = +0.252 per (m/s)，解释 8.3% 方差，已扣除。

**回归器。** 逐层岭回归；$\alpha$ 由 **scene 级 GroupKFold（4 折）在训练折内**选，不看主读数。
主层 L = 22（$v_{brake}$ 自己的校准层，`t1q_axes.json: brake_layer = 22`）。

**预注册主读数（唯一）。** $\cos(v_{brake}^{obs},\, v_{brake})\big|_{L=22}$，
对 200 个随机单位方向的余弦零分布报 z 与双侧 p，并以 **scene 级 bootstrap（500 次，
每次重采样后重拟合方向）** 给 95% CI。其余（其他层、其他条件、以 TTC 为目标）一律敏感性分析。

**仪器侧效度自检（跑数前登记）。** 若 $v_{brake}^{obs}$ 本身对 $a_{brake}$ 没有 held-out 预测力，
则"cos 不显著"就不是标本侧结论（方向不存在），而是仪器侧结论（方向根本没拟合出来）。
故并报 L22 上的 held-out CV 相关 $r$ 及其 **scene 级置换零分布**（100 次）。

**三态判据（跑数前登记）。** 显著高于零分布 → PASS；不显著但方向一致 → 不可估；
方向相反或落在零分布内 → FAIL。

> **仪器侧**：观测法方向在 held-out 上对**真实人类减速**有显著（虽弱）的预测力
> （CV $r$ = +0.074，scene 级置换 $p$ = 0.040），以 TTC 为目标时预测力强得多（$r$ = +0.320，$p$ < 1.0 × 10⁻³）——
> 说明"方向没拟合出来"这一仪器侧解释被排除，**"cos 不显著"是标本侧结论**。
> 随机零分布 sd 与理论 $1/\sqrt{d}$ 吻合，余弦检验的零分布口径正确。
> 主读数 CI 上界 = +0.064 ⇒ 两条方向的共线性**上界为 $\lvert\cos\rvert \le 0.064$，即至多共享 0.4% 的方差**。
> **标本侧**：SimLingo 内部存在一条能线性读出真实减速强度的方向，也存在一条能推动模型刹车的方向，
> **但这两条不是同一条**。模型的 driving query 表征甚至相当好地线性编码了 TTC（$r$ = +0.320），
> 而这条 TTC 方向同样与刹车轴正交（cos = −0.005）。

## Discussion／讨论

**1. 对四轴因果链画像的更新：F 轴的"双方法互证"未能建立，且这是标本侧事实。**
预注册主读数给出 $\cos$ = +0.014，落在随机零分布内；按预注册判据记 **不可估**（同号但不显著）。
但与一般意义上的"功效不足"不同，本实验的仪器侧自检**是通过的**：观测法方向确实拟合出来了，
且对真实人类减速有显著的 held-out 预测力。因此更准确的表述是：
**在本样本量下，可以排除两条方向之间存在中等以上共线性（$\lvert\cos\rvert \le 0.064$，95% 置信），
但不能排除极弱共线。** 这比单纯的"没测出来"信息量高得多。

**2. 最尖锐的一条：模型线性编码了 TTC，但这条编码与它的刹车轴正交。**
以 TTC 为目标时，held-out CV $r$ = +0.320（置换 $p$ < 1.0 × 10⁻³），即 driving query 表征**确实**
线性携带了"目标有多近／多快撞上"的信息；而这条方向与 $v_{brake}$ 的余弦是 −0.005，在零分布正中。
这正是 causal confusion 在表征层的签名：**信息在里面，但驱动动作的不是它。**
翻译到核心贡献：一个模型完全可能在开环榜单上拿到不错的分数（因为它的动作在训练分布内
与正确行为相关），同时其动作**并不由它已经编码的危险信息驱动**——
榜单分数无法区分这两种情况，F 轴可以。
（**必须限定**：单帧模型对目标运动结构性全盲，TTC 含速度量，故这条 $r$ = +0.320 中相当一部分
应归于 TTC 与**距离**的相关，而非模型真的"算出了 TTC"。此限定不影响上述论证——
无论那条方向携带的是 TTC 还是距离，它都与刹车轴正交。）

**3. 与 T1-L 既有负结果的关系：同一断裂的第三次独立复现。**
既有工作已报告 $v_{danger}^{lang}$（语言概念方向）与 $v_{brake}$ 近正交、
且投影与行为量 $b$ 的相关**符号与因果方向相反**（$\rho$ = −0.161，$p$ = 0.006）。
本实验把"概念端"从**语言**换成**真实世界行为真值**，断裂依然存在。
两次的共同点只有 $v_{brake}$ 一端，因此这不是某一种概念方向提取方式的问题，
而是**该模型的 driving query 表征里，"刹车驱动轴"与"危险/减速语义"之间确实缺乏几何联系**。

**4. 敏感性分析的一致性。** 四条臂（ghost/clean/both × $a_{brake}$/TTC）的 cos 全部落在
零分布内，绝对值最大者 0.061，且符号不一致（+0.014 / −0.061 / −0.032 / −0.005）——
符号在零附近随口径翻转，本身就是"无共线"的直接表现，不是"某个口径下有信号"。

**5. 本读数不能声称的东西。** ① 本实验**没有否定 $v_{brake}$ 的因果地位**：$v_{brake}$ 已过 W1
四件套，注入它确实能推动行为（本轮 Stage D 解析臂进一步给出 $d\Delta v/d\alpha$ = −0.0432 ± 0.0084，
与同口径实测（±α 全阶梯）−0.0405 [−0.0451, −0.0366] 的比值为 1.07）。被否定的是"它与真实刹车严重程度共线"这一更强的主张。
② $a_{brake}$ 由 ego_pose 二次差分得到，含量化噪声；已用两次 3 点滑动平均抑制，
但仍会稀释相关，故 CV $r$ = 0.074 应视为下界。③ 事件集以鬼探头挖掘判据筛出，
不是自然驾驶的随机样本。

**6. 三态判定结论。** **不可估**（预注册判据：同号、不显著）。
并附效应量上界：$\lvert\cos\rvert \le 0.064$（95% CI 上界）。

## 自我更正记录

1. **回归目标"真实 $a_{brake}$"在事件账本里没有现成字段**，已回到 nuScenes `ego_pose` 重算，
   算法与窗口在 `amendments.md` §FA.1 偏离 2 登记于跑数之前。
2. **首版脚本缺少仪器侧效度自检**，只报了 cos 与其零分布。若只看那一版，
   "不可估"无法区分"方向不存在"与"方向没拟合出来"两种解释。执行中补入 held-out CV $r$
   与 scene 级置换零分布，并把 $v_{brake}$ 投影对 $a_{brake}$ 的相关作为**支持性读数**
   （明确标注非主读数，不替代预注册主读数）。此为设计补强，未改变任何已产出的数字。
3. **以 TTC 为目标的那一臂给出了远强于主臂的仪器侧预测力（$r$ = 0.320 vs 0.074），
   但它仍被保持为敏感性分析，未被提为主读数**。理由：工单 §3 步骤 2 明文"预注册主读数用 $a_{brake}$"。
   把它换成主读数会是典型的事后择优，尽管那样做会让 Discussion §2 的论证更有力。

## 对因果链画像的更新（一句话）

> F 轴的读数把因果链上"奠基→动作"这一环从"未验证"改写为**"已验证为断开"**：
> 模型内部既有一条能线性读出真实刹车严重程度的方向（held-out CV $r$ = +0.074，$p$ = 0.040），
> 也有一条能真实推动刹车的方向（剂量斜率 −0.047），但两者的共线性上界仅 $\lvert\cos\rvert \le 0.064$ ——
> 开环榜单分数按定义看不见这一环，因为它只检验动作像不像参考轨迹，不检验动作由什么驱动。
