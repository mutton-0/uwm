# Tier-M 主读数预注册

> **本文件写于 Tier-M 的 G2 缓存尚未跑完、任何 Tier-M 指标都还没算出来的时刻**（cache 目录当时 1623/2275 个 h5）。
> 目的：把「用哪套设定报数」在看到结果之前钉死，避免事后挑选。

## 为什么需要这份预注册

Tier-S 上我为了解混淆试了 **2(间隔) × 2(解混淆) × 2(方向法) × 2(池化) 共 16 种组合**。
在 n=36 的 held-out 上，这个数量的尝试足以靠运气刷出 p<0.05。
因此 Tier-S 的全部结果只能当作**探索性的方法选择**，不能当证据。

Tier-M 的角色是**确证**：估计集 502 / 真值集 1773 事件，真值集从未参与任何提方向、选层、调参。
只要主读数在跑之前冻结，Tier-M 上的读数就是一次干净的检验。

## 冻结的主读数设定

| 项 | 取值 | 在 Tier-S 上择优的依据（truth holdout, n=36） |
|---|---|---|
| clean/ghost 间隔 | **短间隔** clean [-0.75,-0.25]s / ghost [0,0.5]s | 机制上自车位移更小；PCA 口径下 AUC(正例 vs D) 0.303 → 0.576 |
| v_hazard 提取 | **supervised**（正例 δ vs D 类 δ 的线性判别方向） | ρ_TTC −0.173(p=0.33) → **−0.465(p=0.001)**；AUC(正例 vs D) 0.576 → 0.663 |
| 时间基线回归 | **不做**（deconfound=none） | 判别式方向对「两类共有的漂移」本就不敏感；且 Tier-S 上回归无稳定收益 |
| 池化口径 | **vision_mean** | last_token 在两种方向法下都更差（AUC 0.319 / 0.390） |
| 主判定集合 | S_test（手册口径，129 事件）+ truth holdout（1773 事件）并列报 | S_test 是手册指定；truth 功效高且同样完全 held-out |

## 预先声明的判读规则

1. **主读数 = 上表设定**。其余 15 种组合一律作为敏感性分析列出，**不得替换主读数**。
2. V3 判定沿用手册：S_test 上 selectivity 置换 p<0.05 **且** AUC(正例 vs D) 显著 >0.5。
3. **有监督方向的自证风险**：S_dir 上训练集 AUC = 1.000（25 个样本、896 维，必然完美可分）。
   因此训练集 AUC 不作任何解读，**只看 S_sel 选层、S_test/truth 报数**。
4. 若主读数不显著，而某个次要组合显著，结论写「未通过」，并把该次要组合列为**待 Tier-L 检验的假设**，
   不改写主结论。
5. 若 Tier-M 主读数显著：这是对「Tier-S 上观察到的有监督方向优势」的一次独立确证，
   但仍受限于 nuScenes 的场景构成（日夜 2014/261、单一城市对），不能外推到其他域。

## 补充条款：长间隔对照臂（**事后追加**）

> 写于 Tier-M 主臂结果已出、长间隔臂的 G2 缓存刚跑完（2174/2174）**但尚未计算任何指标**的时刻。
> **这一条不是原始预注册的一部分**，是看到主臂结果后追加的诊断，必须按事后分析对待。

**追加的动机（一个具体的替代解释）**：主臂在 truth holdout(n=1773) 上得到
「模型对真危险的减速不比对无害出现更多」(正例 vs D 的 b 差异 AUC=0.469, p=0.029)。
但主臂用的是短间隔（clean −0.75~−0.25s / ghost 0~0.5s），抽检图里两帧肉眼几乎无差别。
因此存在替代解释：**不是模型不响应，而是短间隔把危险出现的视觉对比也一起削掉了**。
长间隔臂（clean −1.5~−0.5s / ghost 0~1.0s，即手册 §5.2 原设定）就是用来分辨这两者的。

**在算指标之前定死的判读规则**：

1. 长间隔臂**只回答一个问题**：行为端的正例/D 差异（b 的 AUC）是否比短间隔臂明显更大。
   - 若长间隔臂的 b-AUC 仍 ≈ 0.5 → 支持「模型在该开环口径下确实不响应」，主臂结论成立。
   - 若长间隔臂的 b-AUC 明显 > 0.5 → 主臂的「不响应」结论**不成立**，需改写为
     「短间隔设定削掉了行为信号」，并说明解混淆与行为信号之间存在直接权衡。
2. 长间隔臂的**表征端读数（V3/V4）一律不用于改写主结论**。原因：Tier-S 的消融已表明
   长间隔下 v_hazard 被时间漂移污染（AUC 倒挂到 0.303），该臂的表征读数本就不可信。
   它们只作为记录列出。
3. 主结论仍以短间隔臂 + 预注册主读数为准。长间隔臂的任何显著结果都只能当作
   **待 Tier-L 检验的假设**，不得替换主读数。
