# 预注册：注入方向能否在**空场景**里造出刹车

写于 2026-09-07，正式跑批之前。已有的探索性结果（DD/L6/n=40/10 随机方向：
斜率 −0.0161、比随机强 27 倍、但 p=0.200、效应几乎全在 α=4 一档、横偏同步劣化）
**只作为设计依据，不计入检验**。

## 为什么主轴换成 v_decel

$v_{\text{faith}}$ 提自 brake-first 池 —— 低速鬼探头、人已在减速的事件。
拿它注入**匀速巡航**场景，刺激与方向不同源。

$v_{\text{decel}}(\text{band}) = \text{mean}(h\,|\,\text{brake}) - \text{mean}(h\,|\,\text{cruise})$
提自**同一个巡航池**的 cruise / brake 两组，且**按速度段分层**。
注入它 = 把这个巡航场景推向刹车组，同源同分布，且速度混杂已由分层消掉。

  主轴　 v_decel（**速度段与场景匹配**）
  对照轴 v_faith（同一套流程，量它作为"非同源方向"的表现）

## 设定（写死，事后不得调）

| 项 | 值 |
|---|---|
| 注入 | $Z' = Z + \alpha\,\sigma_L\,\hat v$，图像 token 段 |
| 层 | **因果可达性**最高且过 PR≥3 / 地板≤30° 门的层（表征侧判据不保证能影响输出：实测 DD 的 L7 可达性精确为 0，三重门原选的 L5 只有 L6 的 1/10） |
| α 阶梯 | ±{1, 2, 4, 8, 16} |
| 场景 | 120 个左舵巡航空场景（挖矿时已要求前方 15 m 无物、匀速、视野开阔），**按速度段与方向匹配** |
| 随机方向对照 | **50**（p 分辨率 0.02） |
| 候选 | dd / ltf / ddv2 |
| 读数 | $y=\text{arc\_full}$（规划速度）；主量 = 整条阶梯最小二乘斜率 |

## 判定：四条**全过**才算证实

- **C1 显著**　斜率为负，且 |斜率| 在 50 个随机方向的零分布里 p < 0.05
- **C2 单调**　α>0 段与 α<0 段斜率同号，比值落在 [1/3, 3]
- **C3 特异**　横向偏移的 |斜率| ≤ 速度斜率 |斜率| 的 1/3
- **C4 剂量**　效应在 α ≤ 8 已出现（不能只靠最大档；防止"把模型推坏"被当成方向效应）

**读法**
- 四条全过 ⇒ 该方向**因果驱动**刹车。
- C1 过、C2/C4 不过 ⇒ 只有超大剂量才有反应，属"推坏模型"，不算方向效应。
- C1 不过 ⇒ 该方向能描述响应但不驱动响应。

## 已知限制（先写下，事后不得当辩解）

1. 加性平移会被下游归一化部分吸收（实测 DD 在 L5 注入 64%，传到 L6 只剩 2.3%）。
   选可达性最高的层是为了缓解，但不能消除。**因此 C1 不过不能直接读成"无因果"**，
   只能读成"沿单一方向的平移不足以驱动"。
2. 真实遮挡在 L5 只造成 27% 的表征扰动却带来 4.8% 的速度变化，
   而 α=4 注入造成 89% 扰动只带来 3.4% —— 遮挡走的通路与单向平移不同。
3. 巡航池的图只有 test split 在盘上（7848 → 1527），故场景来自这 1527 个。

## 追加（2026-09-07，跑批中途，speed 轴尚未跑过任何一格）

新增第三根轴 **speed = $-\hat s$**（速度降低方向），$\hat s$ 由巡航样本的激活
对 $v_0$ 做线性回归得到。**不能用 band 均值差分**：实测其 split-half 地板
81–86°（= 随机方向），估计量方差太大；回归用全部 390 个样本，地板降到 19.5–25.4°。

**它的角色是本套注入方法的阳性对照。** 速度是模型的显式标量输入，
其表征方向若连它都推不动，说明「加性平移 + 单层注入」这条路径整体不通，
届时 $v_{\text{faith}}$ / $v_{\text{decel}}$ 的阴性结果**无法区分**
「轴不驱动行为」与「方法测不出驱动」。

**预测（写在跑之前）**：
- **S1**　注入 $-\hat s$ 使 arc_full 下降（斜率 < 0，p < 0.05）
- **S2**　符号可逆：$+\hat s$ 使其上升。若只有一个方向有效，是"推坏模型"而非方向效应
- **S3**　$-\hat s$ 的效应量应**大于** $v_{\text{decel}}$ 与 $v_{\text{faith}}$
  （速度是显式输入，理应最容易推动）

若 S1 不成立 ⇒ 方法不通，前两根轴的注入结果一律不可解读，只能退回相关性证据。
