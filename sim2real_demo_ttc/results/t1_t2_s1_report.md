## 2. T1｜重造方向后的读数（E1）

预注册主读数 = **AUC(A vs D2a) @ region_mean**，4 折 scene 级 CV，287 个正例全部当过 held-out。

| 池化 | 主读数 D2a | 95% CI | p | 证伪地板 D2cV | 主读数−地板 |
|---|---|---|---|---|---|
| **region_mean（预注册）** | **0.515** | [0.468, 0.562] | 0.54 | 0.513 | **+0.002** |
| vision_mean | 0.549 | [0.502, 0.596] | 0.044 | 0.575 | −0.026 |
| last_token | 0.437 | [0.390, 0.484] | 0.009 | 0.510 | −0.074 |

**随机方向地板（region_mean，同一 CV + 选层流程，3 个 seed）：0.573 / 0.521 / 0.582。**

两件事同时成立,结论只有一个：

1. 有监督方向 0.515 **低于**随机方向地板（0.52–0.58）；
2. 物理上不可判别的 D2cV（同类别 VRU、同几何，唯一差异是速度，单帧不可见）读到 0.513，
   与主读数**无法区分**。

**E1 = FAIL**（不是"不可估"：n=287/283 时 CI 半宽 ±0.047，能排除 AUC>0.562）。
M3 的 region 池化没有把 N1 的空结果翻过来 —— 它在 in-domain（M1，AUC 0.814）有效，
在 OOD 上并不能凭池化口径救回信号。

各折峰层 `[16, 0, 4, 8]` 完全不稳，与 N1 报告"24 层 argmax 本身造 ±0.09 偏差"一致。

### 2.1 三条零算力对照（回答"0.515 到底是什么"）

**① 标签置换 selectivity（guide §1.4 要求项）** —— 只在提方向的拟合集里打乱 pos/neg 标签，
选层与报数仍用真标签，10 个 seed 走完整同一条管线：

```
零分布 0.513 0.468 0.438 0.483 0.557 0.496 0.499 0.521 0.469 0.454
均值 0.490  sd 0.035  95 分位 0.541  最大 0.557
观测 0.515  ->  置换 p(单侧) = 3/11 = 0.27,  z = +0.72
```

**结论:0.515 落在标签置换零分布正中,是纯噪声。** 这条把 E1 的 FAIL 从"不显著"
升级为"有正面证据表明该读数不含信息"。

注意零分布均值 0.490(该在 0.5 附近)**低于**随机方向地板 0.52–0.58 —— 两者测的不是一回事:
置换零分布测"方向不含信息时管线能造出多少",随机方向地板额外含了"固定方向 + 24 层 argmax"
的乐观偏差。**两个地板都要报,主读数被两者同时压过。**

**② PCA-PC1 主成分式对照臂（guide §1.3 要求项）**

| 提取法 | D2a 主读数 | p | 证伪地板 D2cV | 主读数−地板 |
|---|---|---|---|---|
| 判别式（程序化标签 logistic 法向量） | 0.515 | 0.54 | 0.513 | +0.002 |
| **主成分式（PC1）** | **0.546** | 0.057 | 0.536 | **+0.010** |

两法都在地板上，差值 +0.002 / +0.010 都无意义。
按 §1.3 的说法"方向质量上限由配对与负例设计决定，提取方式只决定能否吃满上限"——
**两法收敛到同一个空结果，说明瓶颈不在提取方式**，在配对/负例设计或模型本身。

**③ 配对覆盖审计（查"是不是把信号最强的近距正例筛掉了"）**

| d_long 箱[m] | 正例 n | D2a 匹配存活 | 存活率 |
|---|---|---|---|
| 0–10 | 8 | 4 | 0.50 |
| 10–15 | 19 | 19 | 1.00 |
| 15–20 | 44 | 44 | 1.00 |
| 20–25 | 60 | 60 | 1.00 |
| 25–30 | 43 | 43 | 1.00 |
| 30–40 | 52 | 52 | 1.00 |
| 40–50 | 65 | 61 | 0.94 |

**主读数的正例没有被系统性删失**：291 个 A 正例存活 283 个（97%），
10 m 以上逐箱存活率 1.00；缓存覆盖 288/291。
被淘汰的 8 个确实 TTC 更小（中位 1.66 vs 3.99，p=0.004），但 n=8，改变不了结论。

**近距样本稀少是挖掘规则的产物，不是匹配的产物**：A 类总共只有 291 个，其中 d_long<10 m 的只有 8 个
（判据 = VRU 突现 + TTC<5 s + 前后各留 1.6/1.1 s 窗口，天然筛掉贴脸样本）。

有系统性删失的是 **D2cV**（存活 212/291，被淘汰者更近、更大、更偏心，p≈1e-7），
但它是证伪地板，删失只会让地板估计**偏保守**——即真实地板可能比 0.513 更高，主读数更站不住。

## 3. T2｜Manipulation（E2）—— demo 的灵魂，这次真跑了

新增能力：`simlingo_runner.set_steering()`，在指定 decoder layer 的输出上做
`add / project_out / recover` 三种改写（forward hook 返回值即新输出）。
冒烟自检：**α=0 与不注入逐位相同**，α 增大效应单调增大，`project_out` 生效。

注入位置 = vision token（方向就是从 vision token 池化的 δ 上提的）；
σ_L = 本次前向被注入 token 的激活标准差，逐帧自归一化。
S_test A 事件 n=61，注入层 L*=1（S_sel 选出，AUC 0.656）。

### 主读数：剂量斜率

| α | Δv_plan [m/s] | 95% CI | Δ横向 [m] |
|---|---|---|---|
| +0.5 / +1 / +2 / +4 | −0.006 / −0.011 / −0.022 / −0.027 | α=2 时 [−0.047, −0.002] | +0.005 → +0.043 |
| −0.5 / −1 / −2 / −4 | +0.009 / +0.021 / +0.043 / +0.095 | α=−4 时 [+0.055, +0.150] | −0.005 → −0.049 |

- **预注册主读数（只用正向 α 的逐事件 OLS 斜率）= −0.0068 m/s per σ，95% CI [−0.019, +0.004]** → 不显著；
- 敏感性（全阶梯 −4…+4，标注为非预注册）= **−0.0155，CI [−0.028, −0.006]** → 显著。

也就是说，注入**确实**按预期方向推动行为（加危险方向→减速，减→加速），且剂量有序。
但两个对照把它判死：

### 对照①随机方向：**不通过**

同模长随机方向 5 个 seed 的 Δv_plan：+0.047 / +0.067 / −0.022 / −0.048 / −0.066。
**随机方向的效应量（最大 0.067）比危险方向（0.022）还大。**

### 对照②特异性：**不通过**

同口径全阶梯斜率：速度 −0.0155，**横向 +0.0116**，比值 **0.75**。
注入把横向轨迹搞坏的程度与减速幅度同量级 —— 这是无差别扰动，不是特异的"危险响应"。

### 对照③termination：**不通过**

ghost 帧剔除方向后 Δv_plan = **−0.0076** [−0.0147, −0.0012]，
方向与预期**相反**（预期剔除危险方向应让减速响应减弱，即 >0）。

### 选层敏感性：不是"注错层"

L*=1 是很早的层，RepE 通常在中后层操纵。补跑 **L=12**（明确标注为敏感性）：
剂量斜率 +0.0036 [−0.007, +0.014]（无效应），随机方向仍达 0.071。
**换中层没有救回来，E2 的 FAIL 不能归因于选层。**

**E2 = FAIL**（剂量单调 ✗ / 随机零效应 ✗ / termination ✗）。

## 4. S1｜观察性剂量-响应曲线（E-S1，§4.5 S 线）

纯离线重分析，零算力。剂量代理取 **d_long**（Q6：SimLingo 单帧盲于速度，TTC 不可当剂量轴）。
n=2281 事件 / 646 scene，8 个等频箱，scene 级 bootstrap 1000 次。

| d_long [m] | n | 平均 b [m/s] | 达标率 P(b≥0.5) |
|---|---|---|---|
| 5.8–20.4 | 284 | +0.220 | 0.250 |
| 20.4–26.8 | 286 | +0.150 | 0.325 |
| 26.8–32.7 | 285 | +0.065 | 0.246 |
| 32.7–38.3 | 285 | +0.136 | 0.235 |
| 38.3–43.9 | 284 | +0.097 | 0.250 |
| 43.9–49.5 | 285 | −0.043 | 0.221 |
| 49.5–59.2 | 286 | +0.073 | 0.203 |
| 59.2–131.6 | 286 | −0.045 | 0.203 |

- **① 单调性**：Jonckheere–Terpstra z=−2.155，**p=0.031** —— 越近越刹，方向正确且显著。
  但 **isotonic R² = 0.0045** —— 曲线几乎不解释任何方差。
- **② 阈值/斜率**：达标率**从未穿过 50%**（最高 0.325）→ 响应阈值 **不可估**；斜率 −0.0042 (m/s)/m。
- **③ 悬崖**：最大跃变在 41→47 m（Δb=−0.14），但两箱置信带相交 → **不构成悬崖**。
- **④ 大小集一致**：500 事件子集与 2k 集**相容度 0.943**（见下方口径修正）→ 通过。

**E-S1 = PASS，但带一个硬警告**：趋势方向对、显著性勉强过线，而曲线本身几乎没有解释力，
达标率阈值不可估。作为产品坐标是否有用，必须由 **E-S3 增量价值**裁决（需 ≥2 模型，与 T3 共用资产）。

### 一处判据口径修正（必须记录）

§4.5 ③ 的字面写法是"500 集曲线是否落在 2k 集置信带内"。直接算得 **0.685**，
但这个数**有机械偏差**：500 集自身抽样误差约是 2k 置信带宽的 √(2281/500)≈2.1 倍，
两条曲线即使完全一致，落入比例也到不了 0.95 —— 字面判据没有区分力。
主判据因此改为**统计相容性**（小集与大集之差是否落在小集自身 95% 误差内）= **0.943**。
两个数都写进 `s1_curve_d_long.json`，字面版保留但标注不单独采信。

### 另一处规范偏离

§4.5 写的趋势检验是 **Page's L**，但它要求完全区组（每个 scene 在每个剂量箱都有样本），
实测完全区组 scene 数 <5 → 记 **不可估**，主检验改用 **Jonckheere–Terpstra**
（独立样本的有序替代检验，不要求区组完整）。两者都在输出里。

## 6. 判定表

| 判据 | 结果 | 依据 |
|---|---|---|
| **E1 语义** | **FAIL（有正面证据）** | AUC 0.515 落在标签置换零分布正中（p=0.27, z=+0.72）；< 随机方向地板 0.52–0.58；证伪地板 D2cV 0.513 与主读数无法区分；PCA 对照臂同样为空（0.546 vs 地板 0.536）。几何回归控制**已无意义**——AUC 本身不存在，无从"控制后消失" |
| **E2 因果** | **FAIL** | 剂量斜率不显著（预注册口径）；随机方向效应更大；横向/速度斜率比 0.75；termination 反向 |
| **E3 仪器** | **未执行** | 本机无 nuScenes 原生规划器，见 §5 |
| **E4 行为挂钩** | 未执行 | 依赖 E3 |
| **E-S1 单调** | **PASS（带警告）** | JT p=0.031，小集相容 0.943；但 isotonic R²=0.005、阈值不可估 |
| **E-S2 / E-S3** | 未执行 | S2 依赖 T4；E-S3 需 ≥2 模型（与 T3 共用资产） |

**已被排除的三种解释**（各由一条零算力对照钉死）：

| 假说 | 判决 |
|---|---|
| "0.515 只是没到显著，信号也许存在" | ✗ 置换零分布 p=0.27、z=+0.72 —— 它就是噪声 |
| "是判别式提取法不行，换 PCA 就有" | ✗ 主成分式同样为空（0.546 vs 地板 0.536） |
| "几何匹配把最强的近距正例筛掉了" | ✗ 正例存活 283/291（97%），10 m 以上逐箱 1.00 |

**关键推论**：E1 与 E2 是两条独立证据，指向同一件事 ——
在 SimLingo × nuScenes 上提取的"危险方向"**在读取端与操纵端都与随机方向不可区分**。
但按 guide §3 的逻辑，这**尚不能**判定"评价指标无效"：
**E3 缺席时，"仪器有病"与"这个模型确实没有危险表征"无法分离。**
M1 的 in-domain 结果（同一管线 AUC 0.814、超出地板 +0.118）是仪器可用的间接证据，
但它用的是不同对照（同类别车辆 危险 vs 非危险），不构成 apples-to-apples。

**因此本轮的正确结论是：E1/E2 在 SimLingo 上 FAIL，指标效度悬而未决，裁决权在 E3。**
