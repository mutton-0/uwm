## Methods

### 预注册假设（测量前登记）

> 若某候选是"反应但不特异"（$b(A)$ 显著非零，但与 $b$(D2a) 同量级），
> 预期它在 A 类事件**内部**响应幅度 $b$ **不随接近速度显著分级**；
> LTF（反应特异）预期显示更强的分级关系。

### 剂量坐标与一处必须先讲清楚的设计张力（§SG/A41）

工单指定**主读数用接近速度 $v_{close}$**。但本轮三个主对比候选
（SimLingo / LTF / DiffusionDriveV2）**全部是单帧模型**，
而"相对速度对单帧模型结构性不可观测"正是 D2cV 证伪地板赖以成立的**同一条前提**（§CE/A34）。
因此"$b$ 不随 $v_{close}$ 分级"对单帧模型是**按构造预期**的，
它单独不能支持"该候选缺乏分级机制"这个结论。

我们不改工单的主读数，而是补一条**必需对照**：

| 剂量坐标 | 角色 | 单帧可观测 | 预期符号 |
| --- | --- | --- | --- |
| $v_{close}$ = $d_{long}$ / TTC | **主读数（工单指定）** | **否** | + |
| $d_{long}$（纵向距离） | **必需对照（本报告新增）** | 是 | − |
| TTC | 敏感性分析（混杂距离与速度） | 否 | − |

只有并读前两条，才能区分两种完全不同的情形：

* $v_{close}$ 无分级 **且** $d_{long}$ 有分级 ⇒ **有分级机制，只是盲于速度维**；
* 两者都无分级 ⇒ **分级机制本身缺失**（这才是工单假设想说的）。

$d_{long}$ 作为单帧模型剂量代理是既有纪律，不是本轮新发明：
早期 S1 曲线已登记"SimLingo 严格单帧、实测盲于速度 ⇒ TTC 不可当剂量轴，改用 $d_{long}$"。

$v_{close}$ 由挖掘管线自己的量精确还原：管线里 $\mathrm{TTC} = d_{long} / v_c$，
故 $v_{close} = d_{long} / \mathrm{TTC}$ 即 $v_c$ 本身，不是新的近似。

### 统计口径

scene 级 bootstrap（同场景多事件不独立，5000 次）；
剂量坐标按预注册的 99% 分位双侧缩尾（$v_{close}$ 上尾有 2 个 >50 m/s 的轨迹估计伪影，
**只压剂量坐标、不删样本**）；三态判定：斜率 CI 不含 0 且方向正确 → 显示分级；
CI 含 0 → **不可估**（不得据此宣称"无分级"）；方向错误 → 如实报告。
敏感性分析：Spearman $\rho$、isotonic $R^2$、Jonckheere–Terpstra 趋势检验（复用早期 S1 方法论）。

### 混杂控制（本报告新增，见 Results §3）

$v_{close}$ 与若干**单帧可见**量相关：$d_{long}$ ($r$ = +0.25)、
$\log$ 成像面积 ($-0.18$)、$|lat|$ ($-0.25$)、离心率 ($-0.15$)、ego 速度 ($+0.25$)。
因此任何 $v_{close}$ 上的单变量关系都必须先排除"这些可见量经相关性泄漏"。
我们报告两个多元规格：

* **基本**：$b \sim v_{close} + d_{long} + v_{ego}$；
* **全控**：再加 $\log$ 成像面积、$|lat|$、离心率、二轮车类别指示。

### 1. $v_{close}$ 上的"反向分级"在全控之后消失，一个都没剩下

SimLingo 与 LTF 在 $v_{close}$ 上都给出 **CI 不含 0 的负斜率**——
字面读是"**接近得越快，反而刹得越轻**"，正是早前 S1 曲线上"越紧迫越不刹"的同一签名。
但这条读数**不能按字面接受**，因为 $v_{close}$ 与多个单帧可见量相关。

**Table 2. 多元回归的 $v_{close}$ 偏系数（scene 级 bootstrap CI）。`*` = CI 不含 0。**

| Policy | 基本规格 $v_{close}$ | 95% CI | 全控规格 $v_{close}$ | 95% CI | 全控后结论 |
| --- | --- | --- | --- | --- | --- |
| SimLingo | **−0.0837*** | [−0.1661, −0.0027] | −0.0781 | [−0.1752, +0.0132] | **CI 含 0** |
| LTF | −0.0038 | [−0.0097, +0.0015] | −0.0047 | [−0.0119, +0.0032] | CI 含 0 |
| DiffusionDriveV2 | +0.0377 | [−0.0297, +0.1127] | +0.0466 | [−0.0411, +0.1341] | CI 含 0 |
| DiffusionDrive | −0.0104 | [−0.0222, +0.0007] | −0.0110 | [−0.0256, +0.0032] | CI 含 0 |

* **LTF**：只控距离与自车速度，$v_{close}$ 就已经掉进 0 —— 单变量上的"反向分级"完全由
  $d_{long}$ 经相关性泄漏而来。
* **SimLingo**：基本规格下 $v_{close}$ **存活**（−0.0837，CI 不含 0），
  但加入成像面积 / $|lat|$ / 离心率 / 类别之后 CI 含 0。
  **即那条"越快越不刹"最终可由单帧可见的成像几何解释**，
  不需要（也不应当）假设模型感知了速度。
* 四个候选**没有一个**的 $v_{close}$ 偏系数在全控后存活。

**这与结构性预期一致**：单帧模型对相对速度结构性全盲，本来就不应当在速度维上有独立响应。
若有任何一个存活，才是需要追查的异常。

### 2. 在**可观测**剂量上，只有 LTF 显示分级

$d_{long}$ 是唯一对单帧模型可观测的剂量坐标，结果非常干净：

| Policy | F① 特异性（既有结论） | $d_{long}$ 分级 |
| --- | --- | --- |
| **LTF** | **特异**（b-AUC 0.583 [0.519, 0.639]，唯一 CI 全高于 0.5 的单帧候选） | **显示分级**（斜率 CI 不含 0、方向正确、isotonic $R^2$ = 0.091、JT $z$ = −4.62） |
| SimLingo | 不特异（b-AUC 0.534 [0.469, 0.592]） | 不可估（CI 勉强含 0，$R^2$ = 0.037） |
| DiffusionDriveV2 | 不特异（b-AUC 0.556 [0.501, 0.613]，b(A) 大） | 不可估（$\rho$ = +0.018，$R^2$ = 0.003，JT $z$ = +0.04 —— 完全平线） |
| DiffusionDrive | b(A) 本身不显著 | 不可估 |

### 3. 对工单核心问题的回答：**特异性与分级响应共现**

工单问的是"'特异性'和'按严重程度分级响应'是不是同一个机制缺陷的两个侧面"。

**在本候选池上，是共现的**：唯一在 F① 上"反应特异"的候选（LTF）也是唯一在可观测剂量上
"显示分级"的候选；两个"反应但不特异"的候选（SimLingo、DiffusionDriveV2）在可观测剂量上
都判不可估，其中 DiffusionDriveV2 是**完全平线**（$\rho$ = +0.018，JT $z$ = +0.04）。

**但必须限定强度**：这是 $n$ = 3（外加一个平线基线）上的共现，不是一条已建立的规律。
"共现"也不等于"同一机制"——本设计不能区分
「一个机制同时产生特异性与分级」与「两个机制恰好在这三个候选上同向」。

一个值得注意的**反例方向**：DiffusionDriveV2 的 $b(A)$ = +0.201 是全表第二大
（仅次于 SimLingo 的 +0.307），即它**反应很强**，却在剂量上**完全平线**。
**反应幅度与分级能力是两件事**，这一格是最直接的证据。

## Discussion

**方法学上，本任务最有价值的产物不是那几条斜率，而是"$v_{close}$ 不能单独作主读数"这条判定。**
工单指定 $v_{close}$ 是因为它直接对应"高速窜出"这个问题的问法，这个动机是对的；
但对单帧候选，它同时也是 D2cV 证伪地板赖以成立的那个"结构性不可见量"。
在这两件事之间保持一致，要求我们把 $d_{long}$ 对照升为必需项而不是可选项。
**同一条纪律在两个任务上给出同一个约束，这正是纪律而非临时决定的标志。**

**与早期 S1 结论的关系**：早期在 SimLingo 上得到"方向正确但 isotonic $R^2$ 几乎为零"。
本轮在新框架下复现了 $R^2$ 极低这一点（$d_{long}$ 上 0.037，$v_{close}$ 上 0.002），
并进一步给出了原因的一半：SimLingo 在**可观测**剂量上的分级本身就判不可估。
早期那条"越紧迫越不刹"的观察在本轮**部分保留、部分被解释掉**——
单变量上仍然成立且显著，但在控制单帧可见几何后不再独立成立。
这是一次**解释性修订**（不是数值修订：单变量数字逐位未变）。

**局限**：
1. 三个主对比候选全是单帧模型，故本任务实际只检验了"分级 vs 可观测剂量"，
   "分级 vs 速度维"在本候选池上**结构性不可测**。多帧候选（Alpamayo-R1、AutoVLA）
   本可以做这件事，但它们的 $b(A)$ 与 0 不可区分（§4.2.7），剂量分析无从谈起。
2. isotonic $R^2$ 全部 ≤ 0.091，即便"显示分级"的 LTF，剂量也只解释了不到 10% 的方差。
   **"显示分级"是关于斜率符号与显著性的陈述，不是关于预测力的陈述。**
3. $b$ 逐事件只有一个数（clean/ghost 两帧平均），没有事件内的重复测量，
   故无法把残差方差拆成"模型的随机性"与"事件间真实差异"。

## 自我更正记录

1. **工单主读数与既有纪律的张力，未静默处理**（§SG/A41）：
   工单指定 $v_{close}$ 作主读数，但本轮候选全为单帧、结构性盲于速度。
   我们**执行了工单的主读数**，同时把 $d_{long}$ 对照列为必需项并在正文中并读，
   而不是替换主读数——替换会让本报告与工单不可对齐。
2. **单变量结果一度支持"SimLingo 越紧迫越不刹"这条更抢眼的结论**，
   加入全控规格后 CI 含 0。**我们报告全控后的结论**，
   并把单变量数字原样留在 Table 1 供核查，不删。
3. **$v_{close}$ 上尾有 2 个 >50 m/s 的轨迹估计伪影**（nuScenes 2 Hz 标注差分噪声）。
   预注册按 99% 分位缩尾**剂量坐标**而非删样本；缩尾影响的事件数随结果落盘
   （`n_winsorized`）。
