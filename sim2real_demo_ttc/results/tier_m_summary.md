# Tier-M 总结（两臂）

> **本文档已按 prompt 一致性修复后的结果全面更新（2026-08-03 18:xx）。**
> 修复内容：手册 §10.4 要求 clean/ghost 之间 prompt 完全一致，但 prompt 模板含
> `Current speed: X m/s` 而两帧真实自车速度不同——旧实现各写各的，使条件间多了一个语言差异，
> 同时污染 δ 与行为量 b（实测 d(指令速度)/d(prompt速度)=0.725，与信号同量级）。
> 现改为两个条件共用 clean 帧的平均速度（`model.prompt_anchor: clean`），
> **条件间唯一的差异是图像**。修复后 corr(Δego, b) 由 +0.35/+0.53 降到 +0.046/+0.066。

> 主臂 = 预注册设定（短间隔）。对照臂 = 事后追加的长间隔诊断。
> 判读规则见 `results/tier_m_preregistration.md`（含在算指标前写下的补充条款）。

## 0. 四句话

1. **预注册主读数（短间隔）：V1 通过，V2/V3/V4 未通过。** Tier-S 上那个 p=0.001 没有复现。
2. **长间隔臂上，表征端与行为端都出现了弱但一致的信号**：
   表征 AUC(正例 vs D) = 0.559 (p=7.8e-05)，行为端 ρ(投影, b) = +0.055 (p=0.023)，
   A 类（VRU 突现）vs D 的行为差异 AUC = 0.555 (p=0.0097)。**符号全部正确。**
3. **上一版"模型对真危险反而减速更少"是 prompt bug 造成的假象，已收回。**
   修复后短间隔 b-AUC = 0.494、长间隔 0.520，不再倒挂。
4. **Tier-S 的"混淆"诊断没有在 Tier-M 复现**——那是 n=36 的假象；按它做的解混淆（缩短间隔）
   反而削掉了信号。**这条算我上一轮的判断失误，第 3 节展开。**

## 1. 预注册主读数（短间隔）——按规则报数

| # | 判定 | 实测（truth holdout, n=1773） |
|---|---|---|
| V1 | ✅ **PASS** | 估计集 0.179 [0.144, 0.216] vs 真值 **0.178**（误差 0.001），CI 宽度 0.072 |
| V2 | ❌ FAIL | 共同分层 11 个，Spearman = +0.15（层数足够 → 属实质性不一致） |
| V3 | ❌ FAIL | AUC(正例 vs D) = 0.515 (p=0.281)；S_test = 0.542 |
| V4 | ❌ FAIL | ρ(投影, 行为) = −0.026 (p=0.268) |
| V4+ | ❌ FAIL | 估计集拟合 logistic → 真值集 AUC = 0.470 |
| V5 | ⏸ N/A | 未做 CARLA 参考帧 |

**Tier-S 上那个 ρ_TTC = −0.465 (p=0.001) 没有复现**（Tier-M: −0.045, p=0.062）。
Tier-S 共试了 16 种组合、held-out 只有 36 个事件，那个 p 值是尝试次数换来的。预注册挡住了它。

## 2. 长间隔对照臂——按补充条款报数

**规则 #1（行为端，预先定死）**：长间隔臂 b-AUC(正例 vs D) = 0.520 (p=0.17)。
仍未达显著，但**逐类拆开后 A 类（VRU 突现）vs D = 0.555 (p=0.0097)**，方向正确。
→ 主臂的"行为端读不出东西"在**汇总层面**成立，但 A 类上确实存在一个弱响应。

**规则 #2（表征端，预先定死为"只作记录"）**：长间隔臂 V3 **通过**——
truth holdout AUC(正例 vs D) = **0.559 (p=7.8e-05)**，S_test = 0.613。
8 格敏感性网格里 **5 格显著、8 格全部 ≥ 0.497**（范围 0.497–0.559），方向一致。

同时 ρ(投影, 行为) = **+0.055 (p=0.023)**，符号正确。
（V4 判定仍记 FAIL，因为手册规定 V4 看 S_test，而 S_test 上是 −0.15；truth holdout 功效高得多。）

| 读数（truth holdout） | 短间隔（主臂, n=1773） | 长间隔（对照臂, n=1673） |
|---|---|---|
| AUC(正例 vs D)，表征 | 0.515 (p=0.281) | **0.559 (p=7.8e-05)** |
| ρ(投影, 行为) | −0.026 (p=0.268) | **+0.055 (p=0.023)** |
| b-AUC(正例 vs D)，行为 | 0.494 (p=0.67) | 0.520 (p=0.17) |
| b-AUC(A 类 vs D) | 0.512 (p=0.56) | **0.555 (p=0.0097)** |
| V1 估计误差 | 0.179 vs 0.178 = **0.001** | 0.200 vs 0.201 = **0.001** |

## 3. 必须说明：规则 #2 的**理由**被数据推翻了

我在补充条款里给规则 #2 写的理由是：「Tier-S 的消融已表明长间隔下 v_hazard 被时间漂移污染
（AUC 倒挂到 0.303）」。Tier-M 直接检验了这条：

| 设定 | Tier-S (n=36) | **Tier-M (n=1673)** |
|---|---|---|
| 长间隔 + PCA + vision_mean | AUC = **0.303**（倒挂） | AUC = **0.542** (p=0.005)，**不倒挂** |

**Tier-S 的倒挂是噪声。** 也就是说：
- 上一轮我据以启动解混淆的那条诊断（"v_hazard 编码的是画面变化幅度"）**在 Tier-M 上不成立**；
- 按它做的解混淆（把间隔从 1.5s 压到 0.5s）**不是去掉了混淆，而是削掉了危险出现的视觉对比**——
  与抽检图里"短间隔下 clean/ghost 肉眼几乎无差别"的观察一致；
- 短间隔主臂的 V3 FAIL，更可能是**我把信号削没了**，而不是模型没有危险表征。

按补充条款规则 #3，主结论仍以预注册的短间隔臂为准（V3 未通过）。但规则 #2 的前提既已被证伪，
把长间隔结果继续压成"不可信记录"就不诚实。正确处理：**两者并列报告，
并明确长间隔臂的间隔长度是事后选择，必须在 Tier-L 或新划分上确证。**

## 3.5 prompt 一致性 bug（已修复，本文档数字均为修复后）

手册 §10.4 要求 clean/ghost 之间 prompt 完全一致。旧实现保持了模板不变，
但 prompt 里的 `Current speed: X m/s` 用的是**各帧自己的**自车速度——两帧速度本就不同，
于是条件间多了一个语言差异。

实测这个差异有多大：图像完全不变、只改 prompt 里的速度 ±2 m/s，
**d(指令速度)/d(prompt速度) = 0.725**；而危险出现本身造成的 |b| 中位只有 0.52 m/s。
**污染项与待测信号同量级。**

修复：两个条件共用 clean 帧的平均速度（`model.prompt_anchor: clean`），
使**条件间唯一的差异是图像**。效果：

| | corr(Δego, b) | b-AUC(正例 vs D) |
|---|---|---|
| 修复前（短/长） | +0.35 / +0.53 | 0.469 / 0.474（**方向反**） |
| **修复后（短/长）** | **+0.046 / +0.066** | 0.494 / 0.520（方向正常） |

**上一版报告里"模型对真危险反而减速更少"的结论是这个 bug 造成的假象，已收回。**
修复前需要用 `metrics.behavior_adjust: ego_delta` 事后回归才能纠正；
修复后残余相关只剩 0.05，该选项**不再需要**（保留在管线里仅作对照）。

## 4. 合起来能说什么

- **长间隔下，表征端与行为端首次出现方向一致的弱信号。**
  表征 AUC = 0.559 (p=7.8e-05)、投影-行为 ρ = +0.055 (p=0.023)、A 类行为响应 AUC = 0.555 (p=0.0097)。
  三个读数互相印证：模型对 VRU 突现确有一点表征与行为上的反应。
- **但效应量非常小。** 0.56 的 AUC 意味着单个事件几乎无法判别，只在 n≈1700 量级才与 0.5 可分。
  按评分卡把这个当作"R 维度获得背书"是过度解读。
- **短间隔下两端都掉到零**——这是我上一轮的解混淆削掉的，不是模型的性质。
- **V1 两臂都成立且极准**（估计误差 0.001，CI 宽度 0.07–0.08）。但要注意：
  该分数在各分层间差异很小，本身就没什么可估错的；且 V2 未过意味着**比全局更细的粒度估不了**。
- **只测了一个模型**。评分卡是用来给候选模型排序的，单模型上"小集估大集"成立，
  推不出"能区分不同模型的目标域表现"。原命题仍未被检验。

## 5. 下一步（按重要性排序）

1. **Tier-L 预注册必须写死**（本轮的事后发现不能算证据）：
   - `prompt_anchor: clean`（已是默认，属 bug 修复不是选择）；
   - clean/ghost 间隔作为**正式变量**跑 {0.5s, 1.0s, 1.5s} 三档，
     看表征/行为信号是否随间隔单调增强——本轮两点数据已提示单调，三点可确证；
   - 主读数只留一个，其余全部标为敏感性。
2. **加第二、第三个候选模型**，这才是原命题（小集能否估计大集上的**模型排序**）的直接检验。
   管线已与模型解耦，增量成本 1–2 天/模型。
3. **配对提纯（手册 §G5）**：3DGS 的"行人移除"给出同时刻同视角的完美配对，
   可同时拿到"大视觉对比 + 零自车运动 + prompt 天然一致"，一次性终结间隔长短的权衡。
4. 补 CAN bus ego 速度、补 V5 域方向（见各臂 report.md §7）。
