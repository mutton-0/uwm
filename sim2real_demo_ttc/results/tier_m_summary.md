# Tier-M 总结（两臂）

> 主臂 = 预注册设定（短间隔）。对照臂 = 事后追加的长间隔诊断。
> 判读规则见 `results/tier_m_preregistration.md`（含在算指标前写下的补充条款）。

## 0. 四句话

1. **预注册主读数（短间隔）：V1 通过，V2/V3/V4 未通过。** Tier-S 上那个 p=0.001 没有复现。
2. **表征端确实有一点危险信号，但只在长间隔下露得出来**：长间隔 8 格敏感性网格里 7 格给出
   显著且方向一致的 AUC(正例 vs D)（0.538–0.572）；短间隔只有 2/8 显著、范围压到 0.499–0.541。
3. **行为端读数本身有个方法学缺陷**：模型 prompt 里明写 `Current speed: X m/s`，
   而 clean/ghost 两帧的自车速度不同，于是 b 有 12%（短间隔）~28%（长间隔）的方差
   只是在反映"自车这两帧之间快了还是慢了"。**扣掉这一项之后，行为端的正例/D 差异由"方向反"翻成"方向对"。**
4. **Tier-S 的"混淆"诊断没有在 Tier-M 复现**——那是 n=36 的假象；按它做的解混淆（缩短间隔）
   反而削掉了信号。**这条算我上一轮的判断失误，第 3 节展开。**

## 1. 预注册主读数（短间隔）——按规则报数

| # | 判定 | 实测（truth holdout, n=1773） |
|---|---|---|
| V1 | ✅ **PASS** | 估计集 0.251 [0.209, 0.295] vs 真值 0.244；**CI 宽度仅 0.086**，是一次有意义的通过 |
| V2 | ❌ FAIL | 共同分层 11 个，Spearman = −0.13（层数足够 → 属实质性不一致） |
| V3 | ❌ FAIL | AUC(正例 vs D) = 0.515 (p=0.281)；S_test = 0.542 (p=0.434) |
| V4 | ❌ FAIL | ρ(投影, 行为) = −0.04 (p=0.130) |
| V4+ | ❌ FAIL | 估计集拟合 logistic → 真值集 AUC = 0.527 |
| V5 | ⏸ N/A | 未做 CARLA 参考帧 |

**Tier-S 上那个 ρ_TTC = −0.465 (p=0.001) 没有复现**（Tier-M: −0.045, p=0.061）。
Tier-S 共试了 16 种组合、held-out 只有 36 个事件，那个 p 值是尝试次数换来的。预注册挡住了它——
这正是预注册的用处。

## 2. 长间隔对照臂——按补充条款报数

**规则 #1（行为端，预先定死）**：长间隔臂 b-AUC(正例 vs D) = 0.486 (p=0.33)，仍 ≈ 0.5。
→ **主臂"模型不响应"的结论成立**，短间隔并没有削掉真实的行为信号。

**规则 #2（表征端，预先定死为"只作记录"）**：长间隔臂 V3 **通过**——
truth holdout AUC(正例 vs D) = 0.559 (p=7.7e-05)，S_test = 0.613 (p=0.043)。

## 3. 必须说明：规则 #2 的**理由**被数据推翻了

我在补充条款里给规则 #2 写的理由是：「Tier-S 的消融已表明长间隔下 v_hazard 被时间漂移污染
（AUC 倒挂到 0.303）」。Tier-M 直接检验了这条：

| 设定 | Tier-S (n=36) | **Tier-M (n=1673)** |
|---|---|---|
| 长间隔 + PCA + vision_mean | AUC = **0.303**（倒挂） | AUC = **0.542** (p=0.005)，**不倒挂** |

**Tier-S 的倒挂是噪声。** 也就是说：
- 上一轮我据以启动解混淆的那条诊断（"v_hazard 编码的是画面变化幅度"）**在 Tier-M 上不成立**；
- 按它做的解混淆（把间隔从 1.5s 压到 0.5s）**不是去掉了混淆，而是削掉了危险出现的视觉对比**——
  这与抽检图里"短间隔下 clean/ghost 肉眼几乎无差别"的观察一致；
- 所以短间隔主臂的 V3 FAIL，更可能是**我把信号削没了**，而不是模型没有危险表征。

按补充条款规则 #3，主结论仍以预注册的短间隔臂为准（V3 未通过）。但规则 #2 的前提既已被证伪，
把长间隔结果继续压成"不可信的记录"就不诚实了。正确的处理是：
**两者并列报告，并明确长间隔臂的间隔长度是事后选择，必须在 Tier-L 或新划分上确证。**

## 3.5 行为量 b 的自车速度校正（**事后发现，未预注册**）

诊断链条：
1. b 的方差不是帧级抖动造成的——同条件相邻两帧的 pred_speed 标准差中位仅 0.17–0.25 m/s，
   而 b 的 sd 达 1.4–1.7 m/s（比值 0.30）。**多平均几帧修不了。**
2. 那方差从哪来？模型 prompt 第一句就是 `Current speed: X m/s`，而 clean 与 ghost 两帧
   本来就处在自车速度不同的时刻。实测 corr(Δego_speed, b)：短间隔 r=+0.35、长间隔 r=+0.53，
   即 **12% / 28% 的 b 方差只是自车速度变化的回声**。
3. 在**估计集上**拟合 b ~ Δego 并把这一项扣掉（系数 0.87–0.92，接近 1，符合"规划速度基本跟着当前速度走"）：

| | b-AUC(正例 vs D)，原始 | 扣掉 Δego 后 |
|---|---|---|
| 短间隔 | 0.469 (p=0.013，**方向反**) | 0.497 (p=0.78，零) |
| 长间隔 | 0.474 (p=0.045，**方向反**) | **0.526 (p=0.043，方向对)** |

**原先"模型对真危险反而减速更少"的结论，是这个未校正的偏差造成的假象。** 校正后的真实情况是：
短间隔下没有响应；长间隔下有一点点响应（AUC 0.526，勉强显著）。

进一步，长间隔 + 校正后，**V4 也翻成通过**：ρ(投影, 行为) = +0.053 (p=0.031)，符号终于对了。
V1 ✅ / V3 ✅ / V4 ✅ 同时成立——**但请注意这是"事后选间隔"叠"事后加校正"的路径，
ρ=0.053 在 n=1673 上 p=0.031 只是刚过线，在我这一轮跑过的分析总数面前非常脆弱。
它是一条待检验的假设，不是结论。**

管线里已把它做成正式选项 `metrics.behavior_adjust: none | ego_delta`（默认 none，
回归系数只在估计集上拟合以避免真值集泄漏），供 Tier-L 预注册使用。

## 4. 合起来能说什么

- **表征里有一点危险信号；行为端在校正后也有一点点，但弱到几乎没有实用价值。**
  长间隔下表征 AUC ≈ 0.54–0.57 稳定显著（7/8 格）；行为端扣掉 Δego 后 AUC = 0.526 (p=0.043)。
  两端都指向"有信号但极弱"。短间隔下两端都掉到零——**这是我上一轮的解混淆削掉的**。
- **效应量很小。** 0.56 的 AUC 意味着单个事件几乎无法判别；它只在 n≈1700 的量级上才与 0.5 可分。
  按当前评分卡把这个当作"R 维度获得背书"是过度解读。
- **V1 成立**：小集（500）估计大集（1773）的行为达标率，CI 宽度 0.086，真值落在里面。
  「小 TD 估计大 TD」在**行为分数**这一层站得住——但要注意，站得住的原因之一是
  该分数在各类事件间几乎没有差异（都在 0.23–0.32），本身就没什么可估错的。

## 5. 下一步（按重要性排序）

1. **Tier-L 预注册必须写死这三条**（都是本轮事后发现，因此本轮不能算证据）：
   - `behavior_adjust: ego_delta`（在估计集上拟合，见 §3.5）；
   - clean/ghost 间隔作为**正式变量**跑 {0.5s, 1.0s, 1.5s} 三档，看表征信号是否随间隔单调增强
     （若单调，则"视觉对比 vs 自车运动混淆"的权衡首次被量化）；
   - 主读数只留一个，其余全部标为敏感性。
2. **行为读出口径仍有改进空间。** 即便校正后 b-AUC 也只有 0.526。其余可查的原因：
   (a) 目标点/指令固定为"直行"，缺少 CARLA 训练时的路由上下文；
   (b) nuScenes 与 CARLA 的相机 FOV 差异使目标尺度系统性偏小；
   (c) 开环单帧本就不该有强响应，应改多帧滚动或闭环。
3. **配对提纯（手册 §G5）**：DriveStudio 3DGS 的"行人移除"给出同时刻同视角的完美配对，
   是同时拿到"大视觉对比 + 零自车运动"的唯一干净做法，可一次性终结这个权衡。
4. 补 CAN bus ego 速度、补 V5 域方向（见各臂 report.md §7）。
