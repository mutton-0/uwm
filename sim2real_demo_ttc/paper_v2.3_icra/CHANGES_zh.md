## 6. 主要结论（对应正文）

1. **LTF 的危险响应在域边界上变号**：benchmark $+0.245$（显著正）→ deployment $-0.070$（显著负），
   $\Delta r=+0.316$，$p<10^{-4}$，**唯一通过 Bonferroni 的对比**。
2. **SimLingo 的弱点是类别特异的**：对车辆达人类量级（$+2.081$ / $+1.506$），
   对 VRU 两个语料上都不可区分于 0；ghost−lead 对比在两语料上独立复现（$p=0.0088$ / $0.0060$）。
3. **DD 家族在所有格子里响应比不超过 $+0.25$**：不依赖任何跨格对比，不受多重比较影响。
4. **官方分数与响应轴不一致**：唯一有人类量级响应的候选在危险事件上 PDM 最低（0.330）。
   最简单的解释（协议惩罚刹车）经逐事件检验**不成立**（$\rho=+0.339$，$p=0.058$），故只报现象不报机制。

## 10. 收敛性分析（2026-09-06 追加）

新增 `scripts/fig_convergence.py`：对每个 $n$ 随机抽 $n$ 个 scene、**从逐单元原始量重算**
各轴、重复 200 次，跟踪 $[10,90]$ 分位带。用随机子集而非"前 $n$ 个"——池的排列顺序是任意的。

为此给 I 轴补了逐 pair 的 $D$ 落盘（`D_per_pair` / `pair_scenes`），此前只存聚合值。
C 轴的重算与 `c_axis_hazard_patch.py:356` 逐字对齐（**逐事件先算 top-2 占比再取均值**，
不是先平均剖面再取 top-2；两者不等，后者会低估约 0.14）。

### 两张图

* `convergence.pdf` —— 6 候选 × 4 轴小多图，各格自己的量纲，看**取值**是否趋平。
* `convergence_need.pdf` —— 每候选一格、四轴叠加，纵轴是**归一化带宽** $w(n)/w(n_{\min})$。
  四轴原始量纲差 20 倍以上，只有尺度无关量才可合法共轴（直接叠加等于隐性双轴）。

### 结果

| 候选 | 四轴都稳所需 scene | 瓶颈轴 |
| --- | --- | --- |
| SimLingo | 38 | G-VS |
| DiffusionDrive | 37 | F-3 |
| LTF | 37 | F-3 |
| DiffusionDriveV2 | 37 | F-3 |
| Alpamayo-R1 | 36 | F-3 |
| AutoVLA | 35 | F-3 |

1. 六候选需求几乎一致（35–38）⇒ **收敛速度由协议决定，不由被测模型决定**。
2. F-3 最贵（六中五个的瓶颈）—— 三臂配对干预，方差高于单臂读数。
3. **实际样本量远超需求**：lead 池 304 scene ≈ 8×，ghost 池 49 也够。
   故 ghost 上跨 0 的格子**不是未收敛**，是效应本身近 0 ——
   两种情形给出相同的区间却指向相反结论，只有重采样曲线能把它们分开。

## 11. 收敛判据修正（重要，推翻了 §10 的数字）

**问题**：原来用「无放回子采样，看 |θ̂_n − θ̂_N| 何时降到全量精度 h 以下」，
报出"118–149 个场景就够"。这个数是**循环的**：

    n@1h / N = 0.413–0.474  （18 个格子，4 轴 × 6 候选，池子 72 与 316 同比例）

无放回子采样自带有限总体修正 Var = σ²/n·(1−n/N)，而 h ∝ σ/√N 不含它，
于是 err_q/h ≈ (z_q/1.96)·√(N/n − 1)，**只依赖 n/N**。池子有 1000 个，
这个判据就会说"要 450 个"。它答的是"抽掉一半数据答案变不变"（有用的自洽检验），
不是"要采多少数据"。

**修正**：新增 `scripts/sample_size.py`，用 σ = SE_N·√N（每场景尺度，与池大小无关）
外推 SE_n = σ/√n（不含 FPC）。分辨相邻候选（间隔 Δ）需 n ≥ (1.96√2·σ/Δ)²。

| 轴 | Δ | 排名所需 n | 现有 |
|---|---|---|---|
| I $I_m$ | 0.374 | 1–2 | 72 |
| C $C_m$ | 0.023 | 202–282 | 313 |
| F-3 $r$ | 0.070 | 81–6073 | 303 |
| **G-VS** | 0.0069 | **730–1378** | 316 |

**结论变化**：G-VS 在本语料上**支持逐候选报值，但不支持排名**（差 4–5 倍数据）；
高方差候选的 r 同理。主线结论（benchmark/deployment 排名倒置）不受影响 ——
那些效应远大于 Δ。§4 收敛小节已重写，新增 tab_samplesize。

**为什么不用"相对标准误差 < 1%"**：几个关键读数就在 0 附近
（Alpamayo r = −0.003），相对 SE 达 487%，到 1% 需 7×10⁷ 个场景。
判据不能在结论最有意思的地方失效。
