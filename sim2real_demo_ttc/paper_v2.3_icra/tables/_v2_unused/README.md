# v2 叙事的表格（未被 v3 正文引用）

v2 的主张是「benchmark 排名不能预测域迁移后的排名」，由四轴（G/F/I/C）支撑。
该主张已被预注册检验否定（ghost θ 预测 lead PDM 的 Spearman 从 n=4 的 +1.00
掉到 n=6 的 +0.03），且右舵仅 8–10 个危险事件、bootstrap 显示名次概率接近随机。

v3 收缩到「外观诱发的一致失效模式」，只用四张表：
tab_geometry / tab_deltab / tab_negative / tab_speed，均由
`scripts/make_tables_v3.py` 从 results 直读生成。

这些文件保留供审计与可能的期刊版扩写，生成脚本是 `scripts/make_paper_tables.py`。
