# paper_icra_v6 —— 相对 v5 的变更

两版**数据与分析完全相同**（右舵 254 场景全量、六家含 Alpamayo 1.5），差别在**行文框架**与本轮新增的分析。

说明：v5 目录不是历史快照（此前没有做版本快照），而是把改写前的措辞重新应用到当前结果上，
用于对照两种讲法。表头措辞由 `scripts/make_tables.py` 的 `PAPER_STYLE=v5|v6` 开关控制（默认 v6）。

## 1. 行文：去掉投资/基金类比（v6）
ICRA 是机器人与网络方向的会议，原稿把"基金收益率、仓位、风控、顺周期性"作为主线比喻，读起来偏经管。
v6 保留临床体检的说法（exam / control / normal range / diagnosis / report），去掉金融术语：

| v5 | v6 |
|---|---|
| 投资人读基金收益率、配置资本 | 分数是结果指标，而结果可能"对得不是地方" |
| position size（仓位） | planned distance（规划开多远） |
| risk management（风控） | yielding（让不让） |
| procyclicality（顺周期性） | scaling（随危险缩放） |
| risk profile（风险画像） | 直接说这份报告回答哪几个问题 |

标题：`Reading the Risk Profile of End-to-End Planners` → `Counterfactual Exams for End-to-End Planners near Pedestrians`。

## 2. 摘要与结论按正面结论重组（v6）
v5 的摘要是"六家都不行"的口吻；v6 按五条正面主张排序：可靠的单向证明 → 跨域预测器 → 小样本的适用边界 → 数据预算 → 标准评测的盲区。

## 3. 新增：F 轴分解（表 IX，两版都有）
F 只有大小没有方向，单看它会把"乱动"误判为"避让"。拆成三部分：
- `F` 幅度、`I` 同一模型在无关改动下的位移（自身抖动地板）、`ΔS` 真正让出的间隙、`η = ΔS/F`
- 真避让 = F≥0.5 且 F>I 且 ΔS≥0.5，六家 246 场景里只有 **35/1476 = 2.4%**
- 动了的 121 格里，离更远 43、反而更近 42 —— **位移方向近乎随机**
- SimLingo 动得最多（62 格）却往行人凑更多（32:13，中位 −0.59 m），且 TTC 违规率最高
- `ρ(ΔS, a_req) = −0.37…+0.07`：有用分量不随危险增长
脚本：`scripts/f_decomp.py`、`scripts/avoid_sign.py`

## 4. 两条通式改为双向判定（两版都有）
前提不成立时预测相反结果，于是每个模型每个场景都有预测、没有空格。
十例：P-F 正向 54/55、反向 2/5；P-I 正向 51/51、反向 8/8。
大样本：P-F 95–98% / 33–100%，P-I 94–99% / 86–100%。

## 5. ⚠️ 撤回一条结论
此前报的"左舵暴露度 → 右舵 TTC 违规率 ρ=+0.99"是**六家共有 79 场景子样本的假象**
（当时 AutoVLA / Alpamayo 1.5 只跑了 80 个）。补到 246 场景后：

| 左舵体检项 | → 右舵 TTC 违规率 |
|---|---|
| 暴露度 | +0.77（不显著） |
| **特异度 SP** | **−0.94**（n=6 时唯一过 5% 显著线） |
| 光照 CFR | +0.37 |

结论改为：**跨域预测新域危险行为的是"轨迹稳不稳"，不是"反应大不大"**，与 F 轴分解自洽。
§IV-B 的 rank_consistency 用的是原图 260 场景的另一套口径（exposure = 0.94），论文中已说明差异。
