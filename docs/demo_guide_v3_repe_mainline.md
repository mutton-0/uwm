# Demo Guide v3 — RepE 式评价指标验证主线(本文件取代旧版 guide 全部章节)

> **唯一目标:证明"表征读数"这套评价指标本身有效**——即 RepE 式的 读取(reading)→ 语义验证 → 操纵(manipulation)三层分析,在 SimLingo × nuScenes 危险事件上闭环。
> 它是最终产品(上传模型 + 目标域 → 二维图评分与排名)的测量内核验证。
>
> **第一原则:SimLingo 是标本,不是考生。** 仪器验证的成功标准 = 读数正确反映标本的真实优劣,标本病得越清楚仪器越成功——模型分数低是结果,不是故障。两条护栏:①不为标本刷分(禁止换口径钓显著,账本+预注册防之);②不拿"标本弱"当万能借口(每个零结果旁必须站一个仪器侧阳性:$v_{brake}$ 标定 / 语言轴可提取 / 组均值排序正确)。报告纪律:每个读数写两行——仪器侧(效度依据)与标本侧(对 SimLingo 说明了什么),永远分开。**区分度是仪器的成绩单,绝对分是标本的病历。**
> **不做**:CARLA 场景捏造、in-domain 对照、Tier-L 放大、AV2 确证——全部挂起。

## 1. 主线:RepE 三层分析(全部在 nuScenes 目标域内)

对照 RepE 的方法结构:刺激对 → 提方向(LAT)→ 四重评估(correlation / **manipulation** / termination / recovery)。我们已有的工作只做到了 correlation 且被审计否掉语义;**本 demo 的核心增量是补齐 manipulation/termination,并用语义控制把方向钉死**。

### T1|重造方向:有监督探针 + 区域池化 + 几何平衡负例(~1.5 天)

1. **D2 负例挖掘**(现有挖掘管线改判据,~半天):"几何同分布但类别/上下文不同"的无害事件——同尺寸同位置的静物/停驻车辆(类别对比)、同目标走廊外时段(上下文对比)。禁止纯几何平衡(单帧模型的危险证据本就含几何,见 q_audit Q6 推论 2);
2. **区域池化缓存**(重新前向,GPU 分钟级):GT 框投影 → tile/patch 网格 → 框内 vision token。每层存 `region_mean / region_max / bg_mean / vision_mean(对照) / last_token(对照)`。只挂 vision token(对齐性 + causal 免疫 + 局部性,理由存档于旧 guide §12.5);
3. **方向提取(术语统一:"判别式",不再叫"有监督")**:S_dir 上以**程序化标签**(挖掘规则从 GT 几何自动派生,零人工标注)训练 L2 正则 logistic,取法向量 = 判别式方向;PCA-PC1(主成分式)保留作对照。两法共用同一配对设计——**方向质量上限由配对与负例设计决定,提取方式只决定能否吃满上限**(配对足够干净时两者收敛);**选层准则 = S_sel 上 AUC argmax**(ρ_TTC 已废,单帧无效);
4. **读数(S_test 报数,全部配标签置换 selectivity)**:
   - AUC(正例 vs **D2**)——几何被负例设计控住,这是主读数;
   - 类别特异性:同几何 行人 vs 静物 的投影差;
   - 上下文调制:同目标 走廊内 vs 外 的投影差。

### T2|Manipulation:steering 注入(demo 的灵魂,~1 天)

RepE 的效度真正来自这一层,我们至今没跑过:

1. clean 帧在 L\*(T1 选出)注入 $Z' = Z + \alpha\,\hat{v}_{hazard}$,α 以该层激活标准差为单位扫 {0.5, 1, 2, 4};
2. **读行为端**:规划目标速度变化 $\Delta v_{plan}$(与 b 同口径)——注入"危险方向"应诱发无端减速,剂量单调;
3. **对照三件套**:①同模长随机方向(应无效应,≥5 个随机种子);②负向注入 $-\alpha\hat v$(应反向或无减速);③特异性——横向轨迹与舒适度指标不应劣化(排除"注入=无差别搞坏");
4. **Termination(顺手,半天)**:ghost 帧投影剔除 $Z' = Z - (Z^\top\hat v)\hat v$,模型对危险的减速响应应减弱;加回去(recovery)应恢复。

**判定**:剂量单调 + 随机方向零效应 + termination 方向正确 ⇒ 方向因果地驱动行为,评价指标"理解分"成立。

### T1-L|语义配对臂:RepE 原生配方(SimLingo 专属,~1 天,优先级提到 T4 之前)

> 动机:RepE 的 LAT 刺激对本是**语言对**(只差概念词,逐 token 可控);视觉侧配对(时序切片/几何匹配)天然是脏的。SimLingo 有语言接口,干净配对直接搭。E1/E2 FAIL 后本臂承担**仪器自证 + 失效定位**两个职能。

1. **方向提取**:同一张图 × 配对 prompt("前方有行人即将横穿,非常危险" vs "前方道路空旷安全";5–10 组措辞变体,token 长度对齐)→ δ → **PCA**(配对干净,回到 RepE 无监督配方)→ $v_{danger}^{lang}$;读取位置 = **driving query token**(动作预测前的最后位置,同时看得到图像与 prompt);EVR₁ + 置换 selectivity + **语义特异性对照**(换一组非危险语义对,如天气词,方向应不同——排除"任意语义差"方向);
2. **仪器自证(部分替代 E3)**:steering 注入 $\pm\alpha v_{danger}^{lang}$ → 应现减速/加速,配随机方向与特异性对照。**通过 ⇒ 钩子/注入/读数整套仪器在本模型上被证明可用**,E3 外部模型依赖降级为 nice-to-have;
3. **核心读取实验(失效定位)**:**中性 prompt** 下的 clean/ghost 图像对,query token 激活投影到 $v_{danger}^{lang}$——"视觉危险事件是否激活危险概念"。四格判定:存在+可 steering+视觉激活 = 链路通(此前 FAIL 属读出位置/配对问题);存在+可 steering+视觉不激活 = **视觉→概念断**(OOD 退化的直接证据);存在+不可 steering = 概念→动作断;不存在 = 反查仪器;
4. **红线**:①评估打分时 prompt 永远中性——语言对只用于方向**定义**(离线刺激集),不进评分回路;②输出侧推理文本编辑仍属下一个工作,不复活;③本臂 VLA 专属,不进跨模型公共口径,SimLingo-base 为天然消融对照。

### T1-Q|寻轴 v2:读出位置扩展 + 行为定义参照轴(E1/E2 FAIL 后的站内主攻,~1 天)

> 战略:**站内寻轴穷尽之前不做 T3**(mmdet3d 环境不搏);T1-L steering 自证通过则仪器问题就地解决,T3 降为最后手段。支持"轴存在"的硬证据:行为对危险有微弱但显著梯度(A 类 b-AUC 0.555、S1 单调 p=0.031)——行为系统性 ⇒ 必有内部中介状态,问题是它住哪。

**术语澄清**:现缓存的 vision/region 池化已是融合骨干(24 层 LLM decoder)内 vision token **位置**的隐状态;扩展维度 = 同一 decoder 内的**其他位置**,非"要不要过 backbone"。

1. **缓存 schema v3,新增位置**(按优先级):①**driving query token**(逐 token + 均值;动作由此预测,行为中介态最可能在此,从未抓过);②全序列均值;③prompt 末位 token(配合 T1-L);④已有 vision 区域/背景池化转岗"感知端"读数(与 query 端对比分离"看没看到 vs 当不当回事");⑤ViT 内部层仅在全空时回头抓;
2. **方向来源加一路:$v_{brake}$ 行为定义功能向量**——标签 = 模型自身刹/不刹(b 高/低),query 位置提取。按构造必然存在(行为非随机时),steering 它应平凡通过 → 给 steering 机器提供**站内上界标定**;关键测试 = ghost 事件激活在 $v_{brake}$ 上的投影是否高于 clean(视觉危险是否亚阈值地推动刹车方向);
3. **夹角矩阵**:$\cos$($v_{danger}^{lang}$, $v_{brake}$, 视觉判别式方向) 两两报告——语言概念轴与行为轴近正交 = "概念→动作断"的几何证据;
4. **纪律**:位置×层×来源×池化是大网格——账本全程记账,S_sel 选格,**单一主格预注册**(建议:query_mean × $v_{brake}$ 投影差),S_test 只报一次。

### T2.5|Reasoning 观测通道(SimLingo 专属,轻量,~半天)

**定位:只观测,不干预。** 语言注入实验(编辑推理文本再续跑 waypoints)**移出本工作范围**——它测的是"推理→动作"链路而非真实感知(画面未变),属于另一个研究问题(推理链路因果分析),优先级低于 T4 的 3DGS(后者尚且只是可选项),留待**下一个工作专门立项**。本阶段 reasoning 的全部用途 = 下述观测读数进评分。

1. **编码器 = 关键词规则,不用裁判模型**:鬼探头词表封闭(行人/人/横穿/减速/刹车/小心/礼让…),正则匹配生成文本 → 语言响应标签;人工抽检 30 条验证编码器查准/查全(同 G1 抽检纪律,半小时),不引入第二个模型;
2. 读数:①语言响应率(正例 vs D2,几何控制沿用);②**语言×行为 2×2 一致性表**(语言提及 × b 达标,scene 级 bootstrap)——"说了没刹"=通路断,"没说"=感知丢;③(免费)**双通道 S 曲线**:语言响应率按剂量分箱与行为曲线并排,两条曲线的阈值错位直接定位链条断点(感知早到位而决策迟钝,或反之);
3. 纪律:VLA 专属通道,不进跨模型公共口径;语言读数属**相关档证据**(unfaithful CoT 风险),报告与 board.json 中须带此标注——因果升级(注入/删除推理)属下一个工作,本阶段不做。

### T3|仪器阳性对照:nuScenes 原生规划器(~1–2 天,与 T2 并行)

拿一个 **nuScenes 训练的开源规划器**(候选:VAD / SparseDrive,选 hidden state 好挂钩子的)走同一条 T1→T2 管线。它在目标域必然有危险表征——
- 它读数强、SimLingo 弱 ⇒ 仪器有效,SimLingo 的弱是模型属性(直接进二维图);
- 它也读不出 ⇒ 仪器有病,修仪器,其余结论全部挂起。
适配注意:多相机 BEV 模型输入用 nuScenes 原生 6 相机(帧都在);读出位置按角色对齐(BEV/融合特征层,全层扫描自选峰层);几何控制里 bbox 改用 BEV 框。接口沿用 `infer(...) -> planned_traj + 每层 hidden` 约定。

### T4|(可选,时间富余再做)3DGS 删除配对
DriveStudio 对 5–10 个 A 类 scene 做行人移除/静物替换,得到"同时刻同视角同几何"的完美对,复算 T1 读数作黄金对照。不阻塞 T1–T3。

## 2. 纪律(从 q_audit 继承,精简为四条)

1. **预注册**:T1 主读数 = AUC(正例 vs D2)@ region_mean,T2 主读数 = Δv_plan 剂量斜率——各一个,其余全标敏感性;
2. **账本**:对 S_test/truth 的每次计算先登记后执行;
3. **选层与报数分离**(S_dir/S_sel/S_test 三分沿用);
4. **三态判定**:PASS / FAIL / 不可估,功效不足报"不可估"。

## 3. 验收:什么叫"评价指标有效"

| 判据 | 标准 |
|---|---|
| E1 语义 | AUC(正例 vs D2) 显著,且回归控几何后**不消失** |
| E2 因果 | steering 剂量单调、随机方向零效应、termination 反向成立 |
| E3 仪器 | 阳性对照模型上 E1+E2 信号显著强于 SimLingo(或至少显著存在) |
| E4 行为挂钩 | 投影(或 steering 响应率)与 b 的关联,在阳性对照模型上显著 |

**E1+E2+E3 全过 ⇒ "理解分"指标获得效度,产品测量内核成立;SimLingo 自己读数弱不影响指标有效性——它只是二维图上的一个点。**

## 4. 第二轨:HTML 维护(与主线并行,轻量)

- **二维图轴修正**:X = 行为分(达标率±CI),Y = 理解分(E1 主读数,E2/E3 通过后启用);点 = 模型(单帧/多帧分组着色);四象限标注处方(高理解低行为=通路断、post-train 性价比最高,等);删除"域内/域外"轴;
- 管线每轮输出 `results/board.json`:`{model, temporal_input, behavior_score, behavior_ci, understanding_score, validity_flags:{E1,E2,E3,E4}}`——HTML 只读这个文件渲染,不手填数字;
- 页面标注数据版本与 commit,谁看都知道数字从哪来。

## 4.5 S 线|敏感性曲线版评估的可行性检验(与 T1–T3 并行,大部分零算力)

> 产品评估有两种候选形态:**读数式**(RepE 向量投影,T1–T3 在验)与**曲线式**(剂量-响应敏感性曲线,本节验)。两者最后同台比较,谁过效度关谁上产品(也可能互补共存)。

### S1|观察性 S 曲线(纯离线,现有缓存重分析,~半天)
- 用已有 2k 事件 + 缓存的 b:按**剂量代理**分箱——单帧模型用目标距离 d_long(TTC 不可测,Q6),多帧候选可用 TTC——画 **b vs 剂量** 曲线,scene 级 bootstrap 置信带;
- 读数:①单调性(isotonic 拟合 + Page 趋势检验);②**响应阈值**(b 达标率过 50% 的剂量位置)与斜率;③**小/大集曲线一致性**(500 集拟合的曲线是否落在 2k 集置信带内——V1 机制在曲线级的复用);
- 悬崖标注纪律沿用:突变点显式定位,不许被平滑掩盖。

### S2|受控 S 曲线(骑在 T4 的 3DGS 资产上,可选)
- 3DGS 时移阶梯(Δt 网格)= 概念轴的受控剂量,5–10 个 scene 各出一条场景内曲线;
- **零编辑对照强制先行**(伪影入账);
- 关键检验:**受控曲线与 S1 观察性曲线在阈值区是否吻合**——吻合则两法互证,观察性版(免编辑、免渲染)即可上产品,3DGS 只用于加密关键区间。

### S3|混合形态(等 T1/T2 出结果后免费解锁)
- 把 S 曲线的横坐标从外部剂量换成**内部投影量**(过了效度关的 $v_{hazard}$ 投影)——逐样本、免几何标注的剂量坐标;与 S1 曲线比预测力,赢了则读数式和曲线式合流。

### S 线验收(与 §3 E1–E4 并列)
| 判据 | 标准 |
|---|---|
| E-S1 可估性 | 曲线单调(或悬崖被定位),500 集版本落在 2k 集置信带内 |
| E-S2 互证 | 受控(3DGS)与观察性曲线在阈值区一致(仅当 S2 执行) |
| E-S3 **增量价值** | 曲线特征(阈值位置/斜率)对模型的区分或行为预测**显著优于单一达标率**——不优于则曲线式退化为 V1 的一个数,产品只保留读数式 |

E-S3 需要 ≥2 个模型(阳性对照模型即可凑齐),与 T3 共用资产。

### S1 实施自查清单(动手前逐条过)
| 坑 | 对策 |
|---|---|
| 剂量-场景混淆(近距事件多在密集城区,曲线反映场景构成而非敏感度) | 优先场景内纵向曲线(同事件随逼近的逐帧轨迹,场景共模);跨场景聚合前分层;终裁靠 S2 受控剂量 |
| 分箱自由度钓形状 | 箱边界预注册;isotonic 回归替代手工分箱 |
| 离散化造假悬崖 | 曲线用连续 b,达标率仅作报告口径 |
| 低剂量端删失(挖掘规则筛掉了极近距样本) | 该端标"覆盖不足",留 S2 的 3DGS 加密补 |
| 聚合悖论(场景基线不同,混合可反转趋势) | 先逐场景拟合、再聚合曲线参数 |
| 剂量测量误差(2Hz 插值)压平曲线 | 阈值估计报区间;敏感性分析 ±80ms |

### board.json 扩展
每模型追加:`s_curve: {dose_bins, response, ci, threshold, slope, monotonic}`、`language_channel: {response_rate, consistency_2x2}`(VLA 专属,可空);HTML 加每模型 S 曲线小图;二维图主轴暂不动,待 E-S3 裁决后再定 X 轴是否升级为曲线特征。

## 附录 A|T1-L 执行卡(当前最高优先任务,按此开干)

**Step 1|定义轴(语言配对,唯一用到危险 prompt 的地方)**
- 刺激集:~200 帧混合采样(clean/ghost/D2 都有,让方向由语言对比定义、不被图像内容定义);
- 每帧过两次:danger prompt("前方有行人即将横穿,非常危险…")vs safe prompt("前方道路空旷安全…"),5–10 组措辞变体、token 长度对齐;
- $\delta_i = h(\text{danger}) - h(\text{safe})$,读取位置 = **driving query token**(逐层);PCA → $v_{danger}^{lang}$,报 EVR₁;
- 对照:置换配对 selectivity;语义特异性(天气词对提 $v_{weather}$,应与 $v_{danger}$ 明显不同向,排除"任意语义差"方向)。

**Step 2|轴的因果自证(先于读取实验——steering 不过,读取不可解释;过了,仪器与轴一起认证)**
- 中性 prompt + clean 帧,注入 $\pm\alpha v_{danger}^{lang}$(α 按该层激活 σ 归一,扫 ±0.5/1/2/4);
- 主读数 = Δv_plan 剂量斜率;对照:同模长随机方向 ≥5 seed、特异性(横向/舒适不劣化)、termination(ghost 帧剔除应减弱减速)+ recovery;
