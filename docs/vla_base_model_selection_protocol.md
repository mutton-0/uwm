# 鬼探头 Target Domain:post-train 基座模型选型评估协议

> **任务**:从候选 VLA / e2e 模型中选出 post-train 预开发的 base model。
> **数据资产**:真实世界鬼探头场景集(real)+ 基于同批场景的 3DGS 重建仿真集(3dgs);post-train 后要求两域全场景集均表现良好。
> **方法学来源**:RepE/LAT(表征读取与控制)+ 本组 sim2real 诊断框架([sim2real_diagnosis_adaptation_plan.md](sim2real_diagnosis_adaptation_plan.md))的证据档位纪律。

---

## 1. 核心原则

**选型预测的不是"现在谁表现好",而是"post-train 之后谁天花板高、成本低"。** 当前行为表现正是 post-train 要改的对象,不能当主判据。

理论依据(RepE 核心发现):模型内部常已线性编码任务概念,即使输出错误——LAT 无监督读出精度可超过模型自身输出。翻译到选型:

- 内部已编码"低 TTC 危险"的候选,post-train 只需把读出接到动作上 → **便宜**;
- 内部未编码危险概念的候选,post-train 须从头学表征 → **贵且不确定**,benchmark 分再高也是高风险。

选型因此测五个 post-train 成本/天花板预测量:**语义奠基性(天花板)、感知-动作忠实度(通路成本)、域不变性(两域兼得能力)、失效集中度(定位修复成本)、行为倾向校准度(基线风格,新增)**,当前行为基线仅作低权重参考。

**核心定位声明(2026-08-28/29,论文叙事修订——决定所有后续实验设计的组织原则)**:**G(Grounding,语义奠基性)/ F(Faithfulness,感知-动作忠实度)/ I(Invariance,域不变性)/ C(Concentration,失效集中度)/ D(Disposition,附加维度)** 是**通用轴**,数量固定、不随场景类型增加而膨胀;鬼探头(以 $v_{hazard}$/$v_{brake}$/$v_{aggressiveness}$ 等向量实例化)是这些轴目前**最成熟的验证场景**,不是轴的定义本身。**命名规则(2026-08-29 定稿)**:轴字母对应各自理论谱系的英文术语首字母(Grounding/Faithfulness/Invariance/Concentration),不再用"概念可读性/Steering响应性"这类操作方法名——旧字母 R(Readability)与新定义"语义是否正确奠基"存在方向性矛盾(一个被 shortcut 驱动的表征可能"可读性"很高但"奠基"错误),已废弃;S(Steering)保留操作含义但轴名改叫 Faithfulness 以避免与既有的 $S_{dir}/S_{sel}/S_{test}$ 三分 split 记号混淆;**Localizability 未采用为 C 的新字母**,因为 "L" 与文档体系里无处不在的层号记号 $L$/$L^*$ 冲突,C(Concentration)与 Localizability 语义足够接近,保留原字母。论文/报告叙事一律遵循:**先给轴的通用定义,再注明"本场景下的具体测量方式是……"**,不得反过来用场景特定的向量名称定义轴。这条纪律的直接产出要求:①任何新场景类型(第二个场景、麦迪逊数据)复用同一套 G/F/I/C/D,不为新场景发明新轴名;②论文的核心证据是"公开榜单排名 vs 本框架排名 vs 真实 post-train 结果排名"三者对比(见 §6 验收 0),不是单一场景下的探针精度;③至少补一个轻量级第二场景类型(复用现有挖掘管线,更换触发判据即可,如"前车急刹"/"无保护左转冲突"),验证 G/F/D 结论在跨场景下依然自洽,这是回应"是否只是给鬼探头量身定做"的唯一实证方式。

**目标变量(评分卡要预测的对象,写死)**:

$$
Y_m = \lambda\,\Delta S_{real}(m) + (1-\lambda)\,\Delta S_{3dgs}(m), \qquad \lambda = 0.7\ (\text{建议值,业务可调})
$$

其中 $\Delta S_D(m)$ = 候选 m 在**固定 post-train 预算**(同数据、同训练步数、同配方)下,held-out 域 D 场景上行为安全分(响应达标率 / margin 达标率)的增量。本协议一切效度声明均指对 $Y_m$ 的预测。

**样本量登记(启动前必填)**:real 鬼探头场景数 $N_{real}$ = ___,3DGS 重建场景数 $N_{3dgs}$ = ___。据此做功效分析,倒推 §6 pilot 所需预测点数与 §3② 探针置信区间宽度;$N_{real}$ 未登记前,本协议所有排序结论均为条件结论。

## 2. 数据配对设计

不需要额外构建配对,三种配对天然存在或可低成本生成:

| 配对                                              | 构造                                                                                               | 提取的方向                          | 成本                                           |
| ------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------------- | ---------------------------------------------- |
| **P1 域配对** real ↔ 3dgs                  | 3DGS 由真实场景重建,天然同场景同几何、只差渲染 = do(appearance)                                    | $v_{domain}$(每层)                | 零(现成)                                       |
| **P2 时序切片** 探头前 ↔ 探头后            | 同一条记录内剪切:emergence 前后帧配对;探头后 TTC 逐帧下降构成有序刺激梯                            | $v_{hazard}$、$v_{TTC}$(有序版) | 零(剪切脚本)                                   |
| **P3 3DGS 编辑反事实** 有 ghost ↔ 无 ghost | 编辑 3DGS 场景移除/改变探头目标的出现时机后重渲染 = 真正的 do(ghost),real 数据不可能提供的平行世界 | $v_{hazard}$(最干净版)            | 低(编辑+渲染);产物可复用为 post-train 增强数据 |
| **P4 语言 condition 对**(附加)              | 成对 prompt("前方可能有行人窜出" vs 中性)                                                          | 语言调制方向                        | 低                                             |

**N 负例集(必配,防混淆)**:"危险出现"配对差同时含"危险"与"画面里多了个物体"两种信息,后者足以让感知强但不懂危险的模型拿高探针分。必须构造**无害出现负例**:目标进入视野但不入走廊、或入走廊但全程 TTC > 6s(P3 版:把 ghost 编辑为远距 / 护栏后 / 高 TTC 出现)。用途:①探针的困难负类——报 ghost-vs-benign 判别而非仅 ghost-vs-clean;②验证 $v_{hazard}$ 对无害出现的投影显著低于真危险。

**纪律**:

- 公共协议只用 P1–P3(视觉/时序配对),保证 VLA 与无语言输入的 e2e 候选可比;P4 仅作 VLA 候选加分项,测"指令可控性"这一 post-train 额外自由度,**不与视觉危险感知混算**。
- P2 同记录多帧仅用于方向提取(机制性操作),统计推断仍以独立场景为重采样单位(主计划 A.8 纪律)。
- 方向符号用小验证集校准(TTC 低端为正)。

## 3. 选型评分卡(六维:五个通用轴 + 行为基线)

对每个候选模型 m、其每个可读层 L(见 §4 层对齐规则)。**下列 ②–⑥ 各节标题格式为"通用轴名(本场景实例化方式)"——轴定义与鬼探头具体做法分离,便于移植到新场景。**

### ① 行为基线 B(权重低)

两域全场景集上:margin 分布、TTC 阈值违规率、事件锚定反应时序(t_emergence 对齐的减速起点)。

$$
B_m = 1 - \text{违规率}(\text{real}) \cdot w_r - \text{违规率}(\text{3dgs}) \cdot w_g
$$

### ② 语义奠基性 G(Grounding;通用轴;鬼探头实例化:$v_{hazard}$,主预测量,天花板)

**轴定义(通用,不依赖鬼探头;对应 Shortcut Learning, Geirhos et al. 2020)**:策略的内部表征是否因果地奠基于生成观测的任务相关实体,而非与之虚假相关的无关变量——这是 shortcut learning 现象在表征层面的具体表现。本场景下即:表征是否由"临近、突然显现的弱势道路使用者"这一因果实体驱动,而非画面大小/居中度这类偶然统计特征。任何新场景类型只需替换下方的配对刺激来源,读数公式与判据不变。

P2/P3 配对差向量做 PCA。记 $x_{ghost}$ = 危险在场帧(P2:探头出现后;P3:含 ghost 的渲染),$x_{clean}$ = 同记录/同场景的无危险配对帧(P2:探头出现前;P3:移除 ghost 的重渲染):

$$
\delta_i = Z_L(x_{ghost}^{(i)}) - Z_L(x_{clean}^{(i)})
$$

$$
v_{hazard} = \mathrm{PC1}(\{\delta_i\}), \qquad \mathrm{EVR}_1 = \text{PC1 解释方差比}
$$

读数(场景级三分 split:$S_{dir}$ 提方向 / $S_{sel}$ 选层 / $S_{test}$ 报数——**选层与报数分离,杜绝多层取 max 的乐观偏差**):

- **主读数 $\rho_{TTC}$**:ghost 帧投影值与 GT TTC 的 Spearman——有序梯度的所有帧都含目标,"画面里有没有东西"解释不了单调相关,天然抗上述混淆;
- **selectivity 校正**(Hewitt & Liang 控制任务):报 $\rho_{TTC} - \rho_{TTC}^{ctrl}$($\cdot^{ctrl}$ = 标签置换对照);
- 辅助:$\mathrm{Acc}$(ghost vs clean,**及 ghost vs 无害出现负例——后者才是硬指标**)、$\mathrm{EVR}_1$。

$$
G_m = \big[\rho_{TTC} - \rho_{TTC}^{ctrl}\big]\Big|_{L^*,\ S_{test}}, \qquad L^* = \arg\max_L \rho_{TTC}\Big|_{S_{sel}}
$$

> **修订(2026-08-04,依据 demo q_audit Q3/Q6)**:①$\rho_{TTC}$ 仅对**多帧输入**候选有效——单帧模型对目标运动全盲(TTC 含速度量),对其属结构性无效读数,单帧候选的 $L^*$ 改用 $S_{sel}$ 上 AUC(正例 vs 几何平衡负例)argmax;②探针正负对比必须**控成像几何**(bbox 面积/离心率)——负例集须几何同分布、仅类别/上下文不同,否则读出的是"大而居中的东西"不是危险;③G 报告为三项组合:**类别特异性**(同几何:行人 vs 静物)、**上下文调制**(同目标:走廊内 vs 外)、**行为联动**(投影→行为响应)。每个候选登记 `temporal_input`(单帧/多帧),G 分组比较、不跨组同表排序。

### ③ 域不变性 I(通用轴;鬼探头实例化:$v_{domain}$ 干涉角;两域兼得能力;对应 Invariant Risk Minimization, Arjovsky et al. 2019)

**轴定义(通用)**:经 G、F 验证成立的"奠基-动作"因果机制,在环境切换(此处为仿真到真实)下是否保持不变,而非仅是某一环境下的特定产物。**注意**:检验对象是 G→F 这条机制链条本身,不是 G 单独的跨域稳定性——两者可能分别断裂,详见 §3.5 闭环验证。

P1 配对逐层归一化激活差与方向干涉角:

$$
D_L = \frac{\mathbb{E}_i \|Z_L(x_{real}^{(i)}) - Z_L(x_{3dgs}^{(i)})\|_2}{\mathbb{E}_i \|Z_L(x^{(i)})\|_2}, \qquad \theta_L = \cos\big(v_{domain}(L),\, v_{hazard}(L)\big)
$$

读数:$D_L$ 小 = 模型天然视两域为同一场景,3dgs 上练的能力可迁回 real;$|\theta_L|$ 大 = 域漂移持续侵蚀危险读出(几何化的因果混淆),post-train 后仍需域抑制处理。

$$
I_m = 1 - D_{L^*} \quad (\text{扣分项 } |\theta_{L^*}|,\ L^* = \text{概念峰层})
$$

### ④ 感知-动作忠实度 F(Faithfulness;通用轴;鬼探头实例化:注入 $v_{hazard}$;主预测量,读出-动作通路连通性;对应 Causal Confusion in Imitation Learning, de Haan et al. 2019)

**轴定义(通用)**:策略的连续控制输出是否由 G 所奠基的同一组特征因果驱动,而不是经由另一条与正确行为在训练分布内偶然相关、但因果上独立的路径生成——这是 causal confusion 在控制层面的对应问题(该论文旗舰案例即自动驾驶模仿学习中的虚假因果捷径)。新场景只需替换注入的方向来源。

概念峰层注入 $Z' = Z + \alpha v_{hazard}$,扫 α。为消除跨架构响应风格差异,F 定义为**模型内无量纲的"通路利用率"**:

$$
F_m = \frac{\text{steering 诱发的减速响应(峰值)}}{\text{真实危险输入诱发的减速响应(同批场景均值)}}
$$

即"该方向能驱动出模型真实危险响应的几成"。报告**均值 + 逐场景分布(IQR)**,禁止只报点估计(steering 效应随输入分布方差极大)。
对照三件套:①同模长随机方向(应无效应);②**$v_{domain}$ 注入**(应不引起制动;引起了 = 危险/域方向纠缠,与 ③ 的干涉角互证);③**特异性检查**:注入后横向行为与 comfort 指标不应劣化(排除"注入 = 无差别搞坏模型"的解释)。负向注入应反向。
响应好 = 通路已连通,post-train 只需放大;无响应 = 通路断裂需重建,成本档位直接上调。

**开环验证不足以支撑忠实度声明,主验证升级为"行动层反事实测试"(2026-08-29,取代原有的 Bench2Drive 闭环依赖,见 §3.5)**。

### ⑤ 失效集中度 C(通用轴;鬼探头实例化:P1 配对 patching;定位修复成本;对应 Localization-for-Editing, Hase et al. 2023 / Meng et al. 2022)

**轴定义(通用)**:策略在分布迁移下的性能退化,是否可归因于网络中一个空间上集中、可辨识的失效机制(适合低成本定向干预),还是弥散分布的表征偏移(需更大范围重训练)。**注意**:定位到责任层不等于该层是最佳修复位点(Hase et al. 2023 的核心警示),C 的判定必须过 §3.5 的闭环恢复检验,不能只看开环 recovery。

P1 配对做快扫版 activation patching(逐层 recovery,主计划 A.4)。**口径写死**(Zhang & Nanda 最佳实践:corruption 方式与指标选择错了结论会反转):corruption 一律为**配对真实输入互换**(禁用噪声破坏),指标一律为**连续轨迹 recovery**(禁用二值化)。对退化样本:

$$
C_m = \text{top-2 层 recovery 占比} \Big/ \sum_L \mathrm{recovery}(L)
$$

集中(C 高)= 可定位 LoRA 低成本修;弥散 = 需全参/多点训练,成本与风险高。

### ⑥ 行为倾向校准度 D(Disposition;附加维度,非核心因果链成员——2026-08-28 明确降级)

**定位声明**:G→F→I→C 四轴构成一条完整、自洽的因果诊断链——模型看对了吗(G)→ 看对的东西驱动了动作吗(F)→ 这条链子换个域还成立吗(I)→ 不成立的话坏在哪、修起来贵不贵(C)。**D 不在这条链上**,它回答的是一个不同的问题(模型是否存在独立于具体刺激的持续性行为风格),不是"理解→动作→跨域→定位"叙事的必要环节。论文主线以 G/F/I/C 四轴呈现;D 作为探索性附加维度处理,不计入核心贡献,亦不参与 §3 判断矩阵与 §6 pilot 的主验收。

**待厘清的定义分歧(启用前必须先解决)**:目前存在两种不兼容的 D 定义——①持续性风格特质(与具体刺激无关的基线倾向,通过角色扮演式 prompt 提取,即 direction_vector_discovery_validation_plan.md B4 的原始设计);②连续动作序列内部的一致性/连贯度(动作间相关性是否有统一取向)。两者是不同的测量对象,启用 D 之前必须先选定其一并独立验证,不能混用。

提取方式沿用 [direction_vector_discovery_validation_plan.md](direction_vector_discovery_validation_plan.md) §1.5 B4(角色扮演式对比 prompt,如"谨慎风格驾驶" vs "激进风格驾驶")或 B5(大样本行为结果对比/精确匹配配对,见该文档)。**同样强制验证**:提取后必须过 steering 四件套 + 跨分布 held-out,不得因为"提取方式更像行为"就跳过验证——语言定义的倾向同样可能与真实行为解耦(T1-L 的教训)。

$$
D_m = \text{steering 效应量(同 F 的通路利用率定义)} \Big|_{v = v_{aggressiveness}} \quad (\text{若采用定义①})
$$

读数解释:$D_m$ 高且方向一致(注入"激进"分量→行为确实更激进)= 该特质真实存在且可操纵。**此公式仅在选定定义①(持续性风格特质)后生效**;定义②(动作序列一致性)需要另行设计读数,当前不预设具体形式。D 的产出**不进入主判断矩阵**,仅作探索性附录报告。

### 主输出:G×F 判断矩阵

**判断矩阵是本协议的主输出。** 标量加权分(任何一组权重都无先验依据、可被质疑)降级为附录粗排工具:粗排用五维等权归一化均值即可,不作最终决策依据,**不做 pilot 后权重回调**(2–3 个候选回调 5 个权重,方程欠定)。

|                            | steering 有响应                     | steering 无响应                                  |
| -------------------------- | ----------------------------------- | ------------------------------------------------ |
| **概念已编码(G 高)** | ✅ 理想候选:知识在、通路在,只差校准 | ⚠️ 通路断:中等成本,post-train 需接通读出→动作 |
| **概念未编码(G 低)** | ⚠️ 罕见,查方向提取是否失效        | ❌ 高风险:表征从头学,慎选                        |

## 3.5 闭环验证设计与可迁移方法论提炼(2026-08-28 初版,2026-08-29 重新设计——摒弃对 CARLA/Bench2Drive 的默认依赖)

> 目的:每个轴不能只靠开环读数自证——必须有一个**升级验证**才能宣称"这个轴衡量的正是它声称衡量的东西"。**2026-08-29 修订**:重新审视后发现,F(原 S)和 C 之前默认绑定 Bench2Drive/CARLA 闭环仿真,但这只是"先想到的一种实现",不是这两个轴定义**要求**的唯一实现——逐个轴重新匹配最贴合其理论定义的验证设计,优先复用项目已有资产,只有 G 和 F 的进阶版仍需要真正的闭环仿真,且降级为可选加强项而非必需项。每项设计同时提炼一条**独立于鬼探头场景的通用方法论建议(tip)**,是论文方法论贡献的核心产出物,优先级等同于数值结果本身。

### G 的验证:反事实操纵测试(Counterfactual Manipulation Test)—— 不变,本就不依赖 CARLA/Bench2Drive
**设计**:用 3DGS 编辑(P3)或几何匹配负例,分别操纵①因果相关特征(危险目标有无)、②无关混淆特征(物体大小/居中度,控制不变),各自观察 G 读数的响应幅度。
**判据**:①的操纵应显著改变 G 读数,②的操纵不应(或应远小于①)。
**可迁移 Tip 1**:仅靠相关性探针(在 clean/ghost 上训练分类器)不足以证明表征"理解"了某个概念;必须用反事实操纵(合成编辑或几何匹配负例)分别检验因果特征与混淆特征各自的响应幅度,前者应答、后者不应答,才能排除 shortcut learning——这是我们自己在 T1 上踩过的坑(几何混淆)反推出的必要条件,对任何声称"VLA 理解了某概念"的工作都适用。

### F 的验证:行动层反事实测试(Action-Level Counterfactual Test)—— 取代 Bench2Drive 作为主验证
**重新匹配的理由**:causal confusion(de Haan et al. 2019)最核心的可观测症状是"策略的动作是否跟着虚假特征走",这件事在**单帧、开环**条件下就能被直接观测,不需要先跑闭环——闭环仿真只用来捕捉"误差累积/复合"这一种更极端的次生症状,不是 causal confusion 的定义本身。
**设计(主验证,复用 G 的同一套 3DGS/D2 反事实基础设施,零新增基础设施)**:与 G 的测试完全对称,但读出对象从"内部表征"换成"最终动作"——分别操纵①危险目标有无、②几何混淆特征(大小/居中度,控制不变),观察**规划动作(减速量/转向量)**的响应幅度。
**判据**:①的操纵应显著改变动作,②的操纵不应(或应远小于①)——若动作对②也有显著响应,说明动作层面存在 causal confusion,即便 G 读数本身是干净的,忠实度判定也不能打高分。
**可迁移 Tip 2(重写)**:causal confusion 的判定不需要等到闭环仿真才能做——用同一套 G 阶段已有的反事实配对(危险 vs 几何匹配的无害负例),把读出对象从表征换成动作,就能低成本检验"动作是否被虚假特征驱动";这是比"先测开环剂量曲线、再等基础设施做闭环持续性验证"更直接、更省成本的因果混淆检验路径。
**可选加强项(原 Tip 2,降级为二级验证,非必需)**:若资源允许,可**额外**在 Bench2Drive 等闭环仿真中验证开环 steering 效应是否在真实多步 rollout 中持续(捕捉误差累积这一次生症状),但**这不是判定 F 是否成立的必要条件**——主判定完全由上述开环行动层反事实测试给出。

### I 的验证:跨域机制耦合一致性测试(Cross-Domain Mechanism-Coupling Test)—— 不依赖 Bench2Drive,CARLA 依赖已减重,且有更贴合项目终局的替代方案
**设计不变**:不分别测 sim 和 real 各自的 G,而是分别测 sim 和 real 各自的 **F(steering 效应量)**,在 G 读数相近的前提下比较两域 F 是否一致。
**判据不变**:G 跨域稳定但 F 跨域衰减(或反之)⇒ "感知"和"感知-动作耦合"是两个独立的、可能分别断裂的环节。
**可迁移 Tip 3**:域不变性判断不能止步于表征相似度(两域激活像不像);必须验证同一因果机制(方向注入→行为响应)在两域下的效应量是否一致——表征稳定不等于因果耦合稳定,这是两个独立需要验证的命题,对任何跨域鲁棒性声明都适用。
**依赖重新评估(2026-08-29)**:此轴**从未依赖 Bench2Drive/闭环仿真**——只需要两批**静态**帧(sim 域、real 域)算 $v_{domain}$,不涉及连续 rollout,之前把它和 F 的 Bench2Drive 依赖并列是不准确的。真正待决的是**用哪个域配对**:①CARLA 参考帧(~200 帧,小时级,demo 专属,SimLingo 的真实训练域,但这批数据不会被下游麦迪逊项目复用);②real↔3DGS(P1,麦迪逊项目本就要用的域配对,若 3DGS 重建(G5)已完成可直接复用,一份数据两头用)。**待你确认**:G5 的 3DGS 重建是否已经产出可用场景?若已产出,建议直接用 real↔3DGS 做本轴验证,跳过 CARLA 参考帧采集——这样验证结果和下游项目共享同一套资产,叙事上也更贴合"通用轴、非鬼探头专属"的定位;若 G5 尚未产出,CARLA 参考帧仍是成本最低的临时方案,但需在报告中注明该版 I 是"demo 专属代理验证",最终结论以麦迪逊阶段的 real↔3DGS 版本为准。

### C 的验证:训练无关恢复测试(Training-Free Recovery Test)—— 用项目已有的伪闭环方法论取代 Bench2Drive
**重新匹配的理由**:C 要验证的是"定位到的层patch 之后,退化的后果指标能不能恢复",这个问题的关键在于"后果指标要考虑多步预测/安全含义",不严格要求真实车辆动力学闭环——主计划(sim2real_diagnosis_adaptation_plan.md)Q1 一开始就定义了**伪闭环仿真**(固定 seed 开环推理 + PDM 式评分,含连续碰撞余量 margin)恰好是为这个目的设计的,不需要 Bench2Drive。
**设计(主验证)**:对定位到的层做 activation patching(real 侧替换为 sim 侧激活,主计划 A.4 已有机制),用**伪闭环 PDM 式评分/margin**(而非单纯轨迹 L2 recovery)重新评估该场景,观察后果指标是否恢复到接近 sim 侧水平。
**判据**:后果指标(margin/PDM 式 total)恢复 ⇒ 失效真正局域于该层;仅轨迹 L2 recovery 高但后果指标不恢复 ⇒ 还有其他分布式因素在起作用,定位结论需修正。
**可迁移 Tip 4**:"定位到责任层"和"修复该层就够了"是两个不同强度的主张;后者的验证不需要真实闭环仿真,但**必须换成后果相关的评分口径**(碰撞余量/安全评分),不能只看轨迹形状的 L2 距离恢复了多少——开环轨迹 recovery 高不能自动担保后果指标同样恢复,这是 Hase et al.(2023)"localization ≠ good editing site" 的具体检验版本,对任何"定位后做定向修复"的工作都适用。
**可选加强项(原方案,降级为二级验证)**:若 Bench2Drive 等真实闭环仿真可用,可额外验证真实碰撞率恢复情况,但不是必需项。

### 四条 Tip 的论文呈现方式
四条 tip 不依赖鬼探头场景成立,建议在论文中作为独立的**方法论贡献段落**呈现(例如"设计原则"或"经验教训"小节),与具体数值结果分开陈述——这把工作的贡献从"我们在某场景上测出了几个数"提升为"我们建立了一套诊断 VLA sim2real 失效的通用方法论,并给出四条可迁移的验证设计原则"。每条 tip 在鬼探头上的具体验证结果是**证据**,tip 本身才是**贡献**。

**本轮改动的总结**:四个轴里,G 从未依赖外部闭环基础设施;F 和 C 的主验证均已重新设计为复用项目已有资产(3DGS/D2 反事实、伪闭环 PDM 评分),**Bench2Drive 从"必需的闭环验证台"全面降级为"锦上添花的可选加强项"**;I 的 CARLA 依赖被拆穿——它其实只需要静态参考帧,不需要 Bench2Drive,且有 real↔3DGS 这个更贴合项目终局的替代选项待你确认。**结论:Bench2Drive 可以从当前计划里整体移除而不影响任何一条核心论文主张的可验证性。**

## 4. 跨模型可比性纪律(选型最大的坑)

1. **模型内归一化**:所有几何量取比值形式($D_L$ 除以层内总模长、EVR 为占比、探针取精度),禁止跨模型比较原始激活差/方向模长;
2. **干预只比行为端**:steering 效应量以物理单位报告(制动提前 ms、减速度 m/s²),不比 α 的数值;α 以"该层激活标准差的倍数"定义以对齐扰动强度;
3. **层按角色对齐,不按层号**:每个候选先全层扫描找自己的概念峰层 $L^*$(探针精度 argmax),跨模型比峰值;报告须附各模型的层剖面曲线,防止单点侥幸;
4. **读取位置对齐管线**:统一取"融合后、动作头前"的表征;架构差异大的候选(如离散 token 动作头 vs 扩散头)在报告中单列,不强行同表排序;
5. **同一刺激集**:所有候选用同一份 P1–P3 配对集与同一 held-out 划分。

## 6. Pilot 验收(评分卡本身的干预档验证)

评分卡是预测器,预测器须校验,否则选型结论停在相关档。**统计设计要点:模型级 n=2–3 无检验功效**(n=3 时 Spearman ≥ 0.5 的随机通过率为 1/2),预测点必须扩到**模型 × 场景簇**粒度:

- 选评分卡排名差异大的 2–3 个候选,**同数据、同预算、同配方**各做一次小规模 LoRA post-train;
- 收益按场景簇分别结算(cut-in / VRU / 日 / 夜 / TTC 深浅,≥5 簇),预测目标为簇级 $Y_{m,c}$ → 2–3 模型 × 5–6 簇 = **10–18 个预测点**;
- **验收 0(核心论文主张,先于验收 1–3,必须做)**:候选池至少包含若干**有公开榜单分数的模型**(如 UniAD/VAD/SparseDrive 系,nuScenes 开闭环榜单可查分;Alpamayo 等无公开榜单条目的私有模型不适用此项)。三线对比:①公开榜单排名;②本协议 G/F/I/C/D 综合画像排名;③实测 $Y_{m,c}$ 排名。**论文头号证据 = ①②的排序在部分候选对上明显不一致,而②③一致**——即"无脑选榜单最优不代表 post-train 种子最优,本框架能纠正这个偏差"。此项不成立(①②③三者高度一致,或②③也不一致),需如实报告,不得回避;
- **验收 1(排序)**:簇级预测 vs 实测的 Spearman,置换检验 p < 0.05;
- **验收 2(增量价值——本方法的存在性证明)**:嵌套回归 / 偏相关——评分卡(去 B)对 $Y_{m,c}$ 的预测须**显著优于 B(当前行为基线)单独预测**;不显著 ⇒ 如实报告"机制指标无增量价值"(可发表的负结果,不是失败);
- **验收 3(基线对比)**:与 **LogME / LEEP / H-score** 同台——机制评分卡须在预测精度或无标签适用性上至少一项胜出,否则回答不了"为什么不用现成可迁移性估计";
- 失配案例逐条记录;**不做权重回调**(欠定),判断矩阵的定档规则可按失配证据修订;
- pilot 副产品:最优候选的因果峰层 = 正式 post-train 的 LoRA 位点初值。

**闭环 3DGS 评测的系统性偏差(效度威胁,必须处理)**:闭环评测中,正确做横向规避的模型会驶离录制轨迹,离轨视角的 3DGS 渲染质量退化 → 输入变差 → 评分被压;保守不避让的模型反而全程看到高质量渲染。**这不是噪声,是系统性偏袒保守模型,方向恰与选型目标相反。** 对策:①闭环评测附离轨渲染质量门控(ego 偏离录制轨迹超一个车道宽的时段,该段评分标记不可信);②或闭环只结算与保守性无关的读数(如反应时刻),规避类读数一律开环结算;③开环协议(本文件 P1–P3 与 demo 手册 G5)沿录制位姿渲染,不受此偏差影响。

### A.2 Pilot 流程(1–2 周量级)

1. **提方向 + 探针(验 G)**:按异常时间戳剪 $x_{ghost}/x_{clean}$ 对(DoTA ~100 段 + 负样本 ~100 段,或 nuScenes ~50 事件)→ 提 $v_{hazard}$ → held-out 探针精度;
2. **行为读出相关(开环)**:行为响应量 = emergence 后 1s 内规划速度降幅;核心验证 = 逐段 corr(投影幅度, 行为响应量);PIE 上加 corr(投影时序, 人类减速时序);
3. **开环 steering(验 F)**:$x_{clean}$ 帧注入 $+\alpha v_{hazard}$,规划轨迹应现无端减速;扫 α 出剂量曲线 + 随机方向对照;
4. **行动层反事实测试(验 F,§3.5 主验证)**:同一组 $x_{ghost}/x_{clean}$ 对及几何匹配负例对,读出对象换成规划动作,检验动作是否只对真实危险特征响应、不对几何混淆特征响应;
5. **闭环确认(可选加强项,非必需)**:top 候选上 Bench2Drive VRU 路线,steering 注入下的实际刹停率变化。

### A.3 验收标准

①探针精度显著高于随机且跨候选有区分度;②投影-行为相关在场景级 bootstrap 下显著;③steering 剂量单调、随机方向无效应;④行动层反事实测试通过(真实危险特征驱动动作、几何混淆特征不驱动)。前三条过 ⇒ 评分卡 G/F 两个主维度获行为端背书;第④条过 ⇒ F 的因果混淆排除得到加强,正式选型(§5)开跑。
