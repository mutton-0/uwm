## 0. 目的与成功判据

**验证命题**:我们提出的表征读出指标(危险方向探针精度 R、投影-行为相关、域暴露 D/干涉角),能否用**小目标域(500 case)** 就有效估计模型在**大目标域(~10k case)** 上的真实表现。

**设计**:SimLingo 为 CARLA 训练 → 目标域取非 CARLA 的 nuScenes;场景类型 = TTC 突变(突然插入的 VRU;不足则以**邻车近距 cut-in** 为主力类,已获批准)。500 case 上算指标与分数估计 → 与 10k case 上同口径"真值分数"对比趋势一致性。

**最终产出物**(全部回传):
1. `mining/events_all.jsonl` + 挖掘统计报告(事件数、类型分布、TTC 分布直方图)
2. `cache/`(激活与输出缓存,格式见 §6)
3. `results/metrics_500.json`(R、探针精度、投影-行为相关、D_L、干涉角、分数估计+CI)
4. `results/truth_10k.json`(大集真值分数,分层)
5. `results/consistency_report.md`(§8 验收逐条判定 + 图)
6. `report.md`(§9 模板)

## 5. G1|TTC 突变场景挖掘(1–2 天,纯 CPU,只用 metadata)

### 5.1 逐帧 TTC 计算

对每个 sample(2Hz 关键帧;**用 devkit 的框插值补到 12Hz sweeps**,否则 TTC 曲线太粗):

- **ego 走廊**:自车坐标系下,横向 |y| < 2.0 m、纵向 0 < x < 50 m;
- 对走廊内每个标注目标:closing speed $v_c$ = ego 速度在连线方向分量 − 目标速度分量;$v_c > 0.5$ m/s 时 $\mathrm{TTC} = d_{long}/v_c$,否则记 ∞;
- 帧级 TTC = 走廊内所有目标的 min。

### 5.2 事件定义(带具体阈值,可按分布回调)

| 类型 | 判据 | 备注 |
|---|---|---|
| **A. VRU 突现** | pedestrian/cyclist 类目标从走廊外进入走廊,且进入后 1s 内 TTC < 3s | 首选类,预计稀少 |
| **B. 近距 cut-in** | vehicle 类目标横向速度指向 ego 车道、由邻道进入走廊,进入时 $d_{long}$ < 20 m 或 TTC < 4s | **主力类**(已确认可全用此类) |
| **C. 通用 TTC 骤降** | 帧级 TTC 在 1s 窗口内下降 ≥ 2s 且降后 < 3s | 兜底补量 |
| **D. 无害出现(负例,必挖)** | 目标进入视野但不入走廊;或入走廊但全程 TTC > 6s | **防混淆对照**:探针必须能区分"危险出现"与"画面里多了个东西";量级与 A+B 相当(Tier-S 至少 20 个) |

每个事件记录:`{scene_token, t_emergence(进入走廊时刻), object_token, object_class, ttc_curve, x_clean_frames(t_emergence 前 1.5~0.5s), x_ghost_frames(t_emergence 后 0~1s), day/night, ego_speed}`。同一 scene 多事件允许,但后续 bootstrap 以 **scene 为重采样单位**。

### 5.3 产出与门控

- 输出 `events_all.jsonl` + 统计报告(A/B/C 各多少、TTC 分布、日夜分布);
- **G1 通过标准**:总事件 ≥ 10,500(10k 大集 + 500 小集);A 类不足 500 属预期,报告注明后以 B 类为主;总量不足则放宽 5.2 阈值(每次放宽记录在案);
- 划分:`split_500`(分层随机:按类型×日夜配比与全集一致)与 `split_10k`(其余全部),**两集不相交**;
- 人工抽检:随机 30 个事件可视化(框+TTC 曲线叠图),确认挖掘语义正确率 ≥ 80%,否则回调走廊/阈值参数。

## 6. G2|批量前向与缓存(1–2 天,GPU)

对 split_500 ∪ split_10k 的每个事件,取 $x_{clean}$ 与 $x_{ghost}$ 各 1–2 帧前向,缓存到 h5:

```
cache/{event_id}.h5
├── clean/hidden_L{0..N}   # 每层 hidden:保存 (a) vision-token 均值池化 (b) 末 token,两种各一向量
├── clean/waypoints, clean/pred_speed
├── ghost/hidden_L{0..N}, ghost/waypoints, ghost/pred_speed
└── meta(json 字符串:事件字段 + 预处理配置哈希)
```

CARLA 参考帧同样过一遍(只需 clean 语义)存 `cache/carla_ref.h5`。

**注意**:①逐帧独立前向、固定 seed;②峰层确定后如需 token 级分析再补抓,首轮只存池化向量控制体积(~10k 事件 × 2 帧 × 24 层 × 2×2048 float16 ≈ 40GB,可接受;不够则只存 1/2 层间隔);③断点续跑:以 event_id 判存在跳过。

**G2 通过标准**:缓存完整率 ≥ 99%,失败清单列明原因。

## 7. G3|指标计算(1 天,可与 G2 流水)

全部在 **split_500** 上进行(10k 只算 §7.4 的行为分,不碰激活——这正是"小集出指标、大集只验行为"的实验设计):

### 7.1 危险方向与探针读数 R
- 500 事件按 **scene 级三分**:$S_{dir}$(50%,提方向)/ $S_{sel}$(25%,选层)/ $S_{test}$(25%,报数)——**选层与报数分离**,杜绝几十层取 max 的乐观偏差;
- $S_{dir}$:$\delta_i = h_L(ghost_i) - h_L(clean_i)$,逐层 PCA → $v_{hazard}(L)$、EVR₁;
- $S_{sel}$:逐层算 $\rho_{TTC}$(ghost 帧投影 vs GT TTC 的 Spearman),**峰层 $L^*$ = argmax**;
- $S_{test}$ 报最终读数:**主读数 = $\rho_{TTC}(L^*)$ 的 selectivity**($\rho_{TTC} - \rho^{ctrl}$,ctrl = 标签置换对照——有序梯度所有帧都含目标,"有没有东西"解释不了单调相关);辅助 = Acc(ghost vs clean)与 **Acc(ghost vs D 类无害出现)——后者才是硬指标**,$v_{hazard}$ 对 D 类投影应显著低于真危险;
- 全部读数附置换对照。

### 7.2 投影-行为相关
- 行为响应量 $b_i$ = ghost 帧与 clean 帧规划输出的减速程度:$b_i = \bar{v}_{plan}(clean_i) - \bar{v}_{plan}(ghost_i)$(waypoints 差分速度均值;若模型直接出目标速度则用它);
- 核心读数:$\rho$ = Spearman(held-out 投影幅度, $b_i$),scene 级 bootstrap ≥1000 次给 CI。

### 7.3 域暴露与干涉角
- $v_{domain}(L)$ = PCA/均值差(CARLA 参考帧 vs nuScenes clean 帧,各 ~200);
- $D_L$ = 跨域激活均值差模长 / 层内激活均值模长(**归一化,禁止报原始模长**);
- 干涉角 $\cos(v_{domain}(L^*), v_{hazard}(L^*))$。

### 7.4 行为分数(500 估计 vs 10k 真值同口径)
- 逐事件"响应达标" = $b_i > b_{min}$(建议 $b_{min}$ = 0.5 m/s,报告敏感性:0.25/0.5/1.0 三档都算);
- **模型 TD 分数 = 响应达标率**;split_500 上给出点估计 + scene 级 bootstrap 95% CI(分层:B 类/A 类、日/夜);
- split_10k 上算同口径达标率 = "真值"。

### 7.5 (可选)可迁移性基线预演
对 G2 缓存特征 + 行为标签计算 **LogME**(回归版)与 H-score,记录其与 7.1/7.2 指标的排序关系——为正式选型协议的"机制评分卡 vs 现成可迁移性估计"基线对比做预演;demo 阶段只记录、不判定。

## 8. G4|一致性验收(核心交付)

| # | 判据 | 通过标准 |
|---|---|---|
| V1 | 500 估计 vs 10k 真值(总分) | 10k 真值落在 500 估计的 95% CI 内 |
| V2 | 分层趋势 | 各层(类型×日夜×TTC 深浅箱)上,500 与 10k 的达标率排序 Spearman ≥ 0.8 |
| V3 | 探针有效性 | $S_{test}$ 上 $\rho_{TTC}$ 的 selectivity 显著(置换检验 p<0.05)**且** Acc(ghost vs D 类无害出现)显著 > 0.5 |
| V4 | 读出预测行为 | 7.2 的 ρ 显著非零;加强版:500 上拟合 logistic(投影→达标),在 10k 上 AUC ≥ 0.65 |
| V5 | 域信号存在 | $D_L$ 曲线非平凡(某层显著高于噪声基线),干涉角报数值 |

**解释框架**:V1+V2 过 = "小 TD 估计大 TD"成立(协议 §附录A 的行为端验证);V3+V4 过 = 表征读出与行为挂钩(评分卡 R 维度获得背书);V4 加强版过 = 读出可作**无标注预测器**(最强结论)。任一不过,按判据逐条报告失败形态(不许只报"不显著",要附分布图)。

## G5|(扩展)DriveStudio 3DGS 反事实:行人出现时机剂量阶梯

> 可选但高价值;在 G1–G4 主线跑通后启动,与主线结论独立成段报告。

**工具**:DriveStudio(`github.com/ziyc/drivestudio`,OmniRe 系),原生支持 nuScenes;动态行人为 SMPL 驱动的独立高斯节点,位姿序列按时间索引——**编辑出现时机 = 给该 actor 位姿序列加时间偏移后重渲染**。

### G5.1 场景选择与重建
- 从 G1 的 A 类(VRU 突现)事件中选 **10–20 个 scene**:优先行人可见时长足够、自车持续逼近的(否则时移改变不了遭遇 TTC);
- 每 scene 训练重建(GPU 小时级),渲染相机 = nuScenes CAM_FRONT 原内参(与 G2 前向管线一致)。

### G5.2 三组渲染产物
| 产物 | 内容 | 用途 |
|---|---|---|
| **零编辑对照**(强制先行) | 不动任何 actor 直接重渲 | ①GS 伪影系统误差基线:对比模型在真实帧 vs 零编辑帧的输出差,后续编辑档读数扣除它;②免费的 P1 域配对(real↔3DGS),提 $v_{3dgs}$ 域方向 |
| **行人移除** | 删除 ghost actor 节点 | 同时刻同视角的完美 $x_{clean}/x_{ghost}$ 对(P3),提 $v_{hazard}$ 最干净版 |
| **时机阶梯** | 行人位姿序列时移 Δt ∈ {−1, −0.5, 0, +0.5, +1}s | 输入级 do(t_emergence):每档过模型,读规划减速响应 → **行为端 TTC-响应 S 曲线** |

### G5.3 读数与验收
- **输入级干预曲线**:遭遇 TTC(随 Δt 变化)vs 模型减速响应,应单调(TTC 越小响应越强)或标出失效区;
- **两级干预互证**:输入级(本节)证明模型对视觉危险时序有响应,激活级 steering(G3/协议 §3④)证明响应经过 $v_{hazard}$ 方向——两级方向一致才构成完整机制链;
- **配对提纯对比**:P3 版 $v_{hazard}$ 与 P2(时序切片)版的余弦相似度,高 = 时序切片配对足够干净,后续可省重建成本。

### G5.4 纪律
1. 行人**只做相位平移,不做路径外推**——只在被观测过的轨迹上时移(无观测监督的位形高斯质量无保障),|Δt| ≤ 1s;
2. 零编辑对照未过(伪影引起的输出变化 ≳ 编辑效应)则本节结论全部降级为不可用,如实报告;
3. 光影为烘焙,时移后影子与环境不再物理一致,报告声明;
4. 本节样本量小(10–20 scene),只出机制性结论(单调性、方向一致性),不做统计推断。

### 12.2 修改项(M1–M6,按优先级)

**M1|In-domain 阳性对照(第一优先,先于 Tier-L)**
SimLingo 官方 CARLA 数据(或 Bench2Drive VRU 场景)上跑**同一条管线**(挖掘→δ→探针→b)。裁决:in-domain 探针强、行为强 ⇒ nuScenes 弱信号 = OOD 表征退化(sim2real 主结论,V5 域方向升主线);in-domain 也弱 ⇒ 读数方法有病,修方法,Tier-L 缓行。它同时为多模型对比提供读数上界标尺。

**M2|Tier-L 预注册条款(写死后不许动)**
1. 主读数**唯一**:长间隔 AUC(**A 类** vs D,**控 bbox 大小**);B/C 类、其余口径全部降为敏感性(汇总 b-AUC 0.520 vs A 类 0.555 = C 类在稀释信号);
2. 确证集 = Q2 的未触碰 scene;
3. **分析账本制度**:对确证集的每一次计算先登记后执行(杜绝"16 种组合换一个 p=0.001");
4. clean/ghost 间隔作正式变量跑 {0.5, 1.0, 1.5}s(远程侧原提议,保留),但其解释权归 Q3 的判别检验;
5. **V4 判据修订**:报数集预注册为确证集本身(配账本),废除"只看 S_test"旧规(n=129 的 S_test 与 n=1673 truth 读数矛盾属小集噪声)。

**M3|G2 缓存 schema v2:目标区域 token 池化(最可能抬升 AUC 的一改)**
- **只对 vision token 做**,三层理由入档:①对齐性——vision token 在两条件间逐位置可对齐,语言 token 长度内容都会变,δ 无定义;②**因果免疫**——causal attention 下 vision token(prompt 锚定一致 → 绝对位置一致)的隐状态看不见其后生成的语言,语言路径变异被结构性隔离(last_token 口径吸收语言差异噪声,这是两种池化选层分歧 L*=8 vs L*=20 的候选解释);③局部性——行人只占几个 token,全局均值稀释信号两个量级;
- 映射:GT 3D 框 → 投影 → 过 resize/crop 变换 → tile/patch 网格 → 框内 token(外扩 1 patch 容错);
- **每层每帧存五个向量**:`region_mean / region_max / bg_mean / vision_mean(对照) / last_token(对照)`;
- **红利分工**:$v_{hazard}$ 从 region δ 提,$v_{domain}$ 从 **bg_mean** 提——危险信号与域风格信号从此不共享 token,干涉角估计摆脱"全都混在全局池化里"的污染;
- 需重新前向,与 Tier-L / M1 的 G2 合并跑。

**M4|多模型与 M1 并行**:SimLingo-base 先(近零适配 + P4 对照)。注:Tier-M 实测 d(指令速度)/d(prompt 速度)=0.725,本身就是"语言条件化直接驱动驾驶输出"的证据,SimLingo vs base 对比报告单列一节。

**M5|3DGS 配对提纯保持在列**,并带资格测试纪律:零编辑对照先行、$\delta_{3dgs}$ 误差棒、伪影-危险交互专项。价值定位更新:一次性同时消掉"间隔权衡"(同时刻同视角)与"bbox 混淆"(同一行人、只差有无)。

**M6|语言响应率读数(免费红利,SimLingo 专属)**
生成文本已在推理路径里产出,**别扔**:对 ghost 帧生成文本做危险关键词编码 → "语言响应率"。与减速响应 b 构成 2×2 诊断:**语言提及 + 未减速 = 感知在、通路断**(对应选型协议判断矩阵"概念已编码 × steering 无响应"格);**语言未提及 = 感知层丢失**。按协议纪律单列,不进跨模型公共口径。
