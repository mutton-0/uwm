# 具身智能侧（LIBERO / π₀.₅）的结论汇总

按驾驶域论文的口径重整：**每条结论配上它的零假设、效应量与被否定的替代解释**。
数值真源逐条标注，全部可回溯到 `results/*.json` 的逐 rollout 记录。

---

## 一句话

**F 轴的操作（遮挡目标、看行为是否崩）在具身域可测，并测出一个干净的因果效应；
它给出的模型排序被一个 509 任务的独立基准以 p=3.9e-14 复现。
但它的"单视角"定义在操作域是错的——多相机冗余让 3/4 的格子读成假阴性。**

---

## 1. 立得住的

### A. 遮挡在操作域能测出真的因果效应

| 臂 | OpenVLA-OFT / libero_object |
|---|---|
| clean | **10/10** |
| 遮挡目标 1.0× | **0/10** |
| 同面积无关遮挡 | **10/10** |

配对精确 McNemar **p = 0.002**。对照臂全干净（四格全部 10/10，p = 1.0），
且对照臂的**时间平均遮挡面积反而更大**（0.67% vs 0.51%）——控制是**更强**的干扰而非更弱，
它依然毫发无损。所以崩溃可以读作因果的，不是"贴了个灰方块"的伪影。

两个最容易的替代解释都被数据排除：

- **"没盖对"**：目标掩码身份经 geom 集合比对，**IoU = 1.0000**（不依赖任何命名约定）
- **"面积不够"**：spatial 的 1.0× 遮挡面积（1.45% 帧）是 object 1.0×（0.51%）的近 3 倍，
  2.0× 达 5.82%——是击垮 object 所需面积的 **11 倍**——而 spatial 纹丝不动。
  **面积与效应之间没有单调关系。**

### B. 一个驾驶域看不到的结构性发现：多视角冗余

补跑的 `occ_both` 诊断臂（同一物体在**第三人称 + 腕部**两个相机里都涂掉）：

| 格子 | 仅第三人称 | **双相机** | McNemar |
|---|---|---|---|
| OpenVLA / object 1.0× | 0/10 | 0/10 | — |
| OpenVLA / spatial 1.0× | 10/10 | **0/10** | p = 0.0020 |
| OpenVLA / spatial 2.0× | 10/10 | **0/10** | p = 0.0020 |
| pi0.5 / object 1.0× | 9/10 | **0/10** | p = 0.0039 |
| pi0.5 / spatial 1.0× | 9/10 | **0/10** | p = 0.0039 |

**八条 `occ_both` 臂，八条全是 0/10。**

含义很直接：

> 驾驶域的 F 轴建立在**单个前视相机**上，遮住就是遮住了。
> 操作域的标准 VLA 输入是**多视角冗余**的，同一个语义量在两个传感器里各有一份拷贝。
> 此时"遮住目标在主视角的投影"测到的不是"目标是否因果必需"，
> 而是"**该视角的目标信息是否不可替代**"。这两件事在驾驶域碰巧重合，在操作域分开了。

**这不是 F 轴的失败，是移植时必须补的一个算子定义。**

### C. F 轴给出的模型排序被独立基准复现

预测（在跑 LIBERO-Plus 之前就成立）：原版 LIBERO 上两模型几乎打平（clean 20/20 vs 19/20），
但 F 轴说 pi0.5 明显更鲁棒（object 遮挡：0/10 vs 9/10）⇒ 在扰动更丰富的基准上两者应当分开，
且 pi0.5 在上。

LIBERO-Plus（509 任务 × 7 扰动维度 × 2 模型 = 1018 rollout，**扰动里没有"遮挡目标"这一项**，
故为外推检验而非自我复现）：

| 任务 | OpenVLA-OFT | pi0.5 | 配对 McNemar |
|---|---|---|---|
| object (n=242) | 0.698 | **0.888** | p = 3.8e-11 |
| spatial (n=267) | 0.933 | **0.989** | p = 7.3e-4 |
| **合计 (n=509)** | **0.821** [0.79, 0.85] | **0.941** [0.92, 0.96] | **p = 3.9e-14** (b=6 / c=67) |

**流水线正确性有外部校验**：本次 OpenVLA-OFT 在七个维度上复现了官方榜单画像，
合计 69.8 vs 70.0（五个维度落在几个点内）。这基本排除了"扰动没生效"这类静默失败。

## 2. 不能下的结论（写在前面，不留给读者自己发现）

### D. "F 轴泛化到具身智能"——本 pilot 支持不了

样本是 **2 任务 × 2 模型**，每臂 n=10，任务是各挑 1 个而非随机抽样。
四个格子里三个零效应，唯一的效应来自一个格子。
**以 n=4 格子的规模，无法区分"F 轴在操作域普遍有效"与"恰好在这一格命中"。**

### E. 两个模型定义不出预测力

两点必然"排得出序"。要把 F 轴升级成部署排序的预测器，**至少需要 3 个模型**。

### F. 任务特异性的对应是 n=2 的观察，不是统计证据

| 任务 | F 轴是否分离两模型 | LIBERO-Plus 差距 |
|---|---|---|
| object | **是**（0.0 / 0.9） | **+19.0 pt** |
| spatial | 否（1.0 / 0.9） | +5.6 pt |

形状漂亮——F 轴不只预测"谁更鲁棒"，还预测"在哪个任务上更能拉开"。
但这是 **n=2 的对应关系**，顶多算下一轮值得验的观察。
而且 spatial 那格 93.3/98.9 都贴近上限，差距小**可能是被天花板压的**。

### G. 机制没有被证实，只有方向对上

F 轴测的是**遮挡**；pi0.5 拉开差距最大的两格是 Camera Viewpoints（100.0 vs 52.4）和
**Robot Initial States**（64.3 vs 31.0）——后者**根本不是视觉扰动**（改的是机械臂初始位姿）。
F 轴没有任何理由预测非视觉维度。

更保守也更可能的解释：**pi0.5 整体上就是更鲁棒的模型，F 轴抓到的是这个总体性质的一个切面**，
而非"遮挡鲁棒性因果地决定了视角/位姿鲁棒性"。

### H. 尺度扫描没有产出可用信号，且设计本身有问题

四条曲线三条非单调，**没有任何尺度间对比达到显著**。三个格子都在 1.5× 下陷、2.0× 回升。

更要紧的是一个**已被测量而非猜测**的混淆（`scripts/p2_box_overlap.py`）：随尺度增大，
框里装的东西性质变了——libero_object 上框内目标占比从 1.0× 的 **82.9%** 掉到 2.0× 的 **20.7%**，
桌面背景升到 64.6%，并开始吃掉邻近干扰物 `milk_1`（6.9% → 14.5%）。

**所以 s 不是"同一种干预的剂量"**：1.0× 近似"只删目标"，2.0× 是"删目标 + 删一片上下文 + 部分删干扰物"。
把这三点连成剂量-反应曲线本身就是过度解读。**这一设计需要重做，不是"数据点少了点"。**

### I. 天花板效应严重

四个 clean 全部 9–10/10。在 SR≈1.0 处做删除实验，向下有动态范围，**向上没有**，
且 n=10 时 Wilson 下界最好也只到 0.72。
**12 条臂里那 11 条"没有下降"只能说"没测到 ≥ 某量级的下降"，不能说"没有下降"。**

### J. 跨模型 clean 成功率不可比

各自沿用各自官方约定（seed 0 vs 7、resize vs resize_with_pad、chunk 8 vs replan 5）。
**可比的只有每个模型自己的 clean → 遮挡 相对变化。**

### K. 与官方榜单不矛盾，但也没得到它的独立支持

榜单上 π₀（54.6）低于 OpenVLA-OFT（70.0），看似相反；但**榜单里是 π₀，本次跑的是 π₀.₅**，
榜单未收录。所以只能说"在榜单未覆盖的模型上，F 轴的排序被独立基准证实"，
不能说"推翻了榜单"。

## 3. 与驾驶域的对照

| | 驾驶域 | 具身域 |
|---|---|---|
| 遮挡能否测出因果效应 | 能（$b$ = +0.23，lead 场景） | **能**（10/10 → 0/10，p=0.002） |
| 单视角是否足够 | 是（只有前视一路） | **否**（多相机冗余，3/4 格子假阴性） |
| 剂量-反应 | 未做 | **失败**（非单调，且 s 改变了干预性质） |
| 排序预测力 | **被预注册检验否定**（n=4→6 时 ρ 从 +1.00 掉到 +0.03） | **方向对上**（p=3.9e-14），但只有 2 个模型 |
| 主要瓶颈 | 部署侧危险事件仅几十个 | 天花板效应 + 任务/模型数太少 |

两域共同的教训是同一条：**一个在小样本上看着完美的排序对应，加到 n≥3 才知道真假。**
驾驶域加到 n=6 就塌了；具身域目前只有 n=2，**尚未经受这个检验**。

---

## 4. 下一轮最该做的三件事

1. **补第 3 个模型**（两点排不出预测力）
2. **把 `occ_both` 升为默认算子**，单视角版本降为诊断臂
3. **重做剂量设计**：用语义化的干预（遮目标 / 遮目标+干扰物 / 遮上下文）替代几何尺度 s，
   并挑 clean SR 在 0.6–0.8 的任务以避开天花板
